# 图标源素材

`lightnote-icon.svg` 是 LightNote 的完整纯色方形品牌母版，`lightnote-icon-foreground.svg` 是供 Android Adaptive Icon 使用的透明前景母版。图形仅使用粗壮、几何化的白色 `LN` 缩写，采用类似专业创意应用图标的高识别度处理，不复制任何第三方品牌轮廓或商标。

生成约束：单一居中图形、无文字、无设备模型、高对比度、兼容圆形和方圆形桌面裁切。

运行 `npm run icons` 会由矢量母版生成 `icon-master.png`、不同密度的启动与自适应图标、单色主题及启动屏资源。修改图形时应更新 SVG 母版后重新生成。
