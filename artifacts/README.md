# 统一交付产物目录

每批修改的最终交付文件统一存放在本目录下按北京时间命名的 `YYYYMMDD-HHmmss/` 子目录，详细要求见根目录 [AGENTS.md](../AGENTS.md) 的“统一产物目录与按平台交付”。

```text
artifacts/
├── README.md
└── YYYYMMDD-HHmmss/
    ├── README.md           # 本批改动、平台范围、版本、部署说明及验证边界
    ├── SHA256SUMS.txt      # 本批交付文件的SHA-256
    ├── api-版本-架构.tar.gz # 涉及后端发布时生成
    ├── web-版本.zip        # 涉及业务Web发布时生成，按需包含安卓签名更新目录
    ├── website-版本.zip    # 涉及独立官网发布时生成
    └── android-版本.zip    # 涉及安卓安装发布时包含APK、架构及签名说明
```

上述包名为结构示例，不代表各包已经生成；仅放置本批实际需要发布的平台文件。文档批次也创建时间目录，以说明记录无运行平台需要发布，不生成空安装包。其他PC、iOS、小程序等平台按实际发布方式补齐。

只有本公共说明提交Git，时间目录及其产物均被忽略。不得在此存放真实用户数据、访问凭据、私钥或生产秘密配置。现有模块构建目录无需因此迁移；后续交付从本目录提供最终产物。
