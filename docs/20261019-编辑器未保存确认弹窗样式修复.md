# 编辑器未保存确认弹窗样式修复

## 改动目的

修复编辑器退出时“放弃未保存的更改”确认框贴在左上角、缺少面板布局的问题。

## 主要内容

- 在 Web 应用入口显式导入 Element Plus MessageBox 样式。`ElMessageBox.confirm` 是服务方法调用，不会被模板组件的按需样式解析器自动处理；样式导入对全站同类确认框生效。

## 验证方式及结果

- 在 `frontend/apps/web/` 执行 `pnpm run build`：类型检查与 Vite 生产构建通过。
- 检查生产 CSS，确认输出包含 `.el-message-box` 规则。
- 执行 `git diff --check`：通过。

## 尚未验证及限制

- 未在浏览器中实际打开编辑器确认框做视觉交互检查；构建会继续提示 HEIC WASM bundle 超过 500 kB。
