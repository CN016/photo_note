# 作品集接口基础

## 本批内容

新增作品集创建、列表、详情、单张图片上传及读取、分享令牌启用与撤销、按令牌读取作品集和照片的基础接口。作品照片保存在公开目录，并尝试解析完整图片属性；用户已明确授权公开原图和 GPS 等属性。所有管理入口从会话取得空间和创建者，公开入口从分享记录恢复空间。

## 验证与限制

- `go test ./internal/service ./internal/store ./internal/httpapi ./cmd/api -run '^TestPortfolio'`：通过；包括作品集创建和分享令牌单元测试，store、httpapi 无匹配测试。
- 本批仍不构成完整作品集功能：前端、修改删除、公开文件清理、照片标签与排序、灵感库复制、策划关联、统计、二维码均未完成。
- 未执行独立 PostgreSQL 迁移和隔离测试、浏览器和设备验证、构建镜像或部署。000025 迁移须经备份后按顺序执行。
