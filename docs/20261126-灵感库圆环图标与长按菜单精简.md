# 灵感库圆环图标与长按菜单精简

## 改动目的

将灵感库颜色筛选入口调整为明确的空心圆环，并移除图片长按菜单中的关联策划内容，让“复制图片”成为第一项且当前唯一的图片操作。

## 主要内容或涉及范围

- 颜色筛选入口不再使用渐变填充图标，改为 3px 空心圆环；激活状态继续继承当前主题色，与搜索、标签和人数图标保持一致的视觉重量。
- 图片长按与桌面右键共用新的单项菜单构造器，菜单立即显示“复制图片”，不再请求关联策划、不再显示项目标题、分页、加载、重试或错误行。
- 剪贴板不可写时仍显示一条禁用的“复制图片”，避免出现空浮窗；点击可用项继续沿用原有图片复制和失败提示流程。
- 删除灵感库中不再使用的“关联策划”“暂未用于策划”“无法读取关联策划”中英文文案。

- Web `pnpm typecheck`：通过。
- Web `pnpm test`：43 个测试文件、181 项测试通过；新增测试确认复制图片是第一项、菜单仅有一项且不再包含关联策划。
- 中英文 `gallery` 语言键集合一致，共 165 个键。
- 生产 Web 构建通过，转换 4559 个模块；生成版本 `2026.11.26-r2`、发布号 `1795685259789` 的 Android 签名 Web 更新，`minShellCode=15`，RSA-SHA256 验签与 ZIP 摘要校验通过。

## 尚未验证或已知限制

- 未连接 Android、iOS 或微信小程序真机，空心圆环的实际渲染、长按触发和剪贴板写入仍需对应设备验收。
- 关联策划入口仅从灵感库图片长按菜单移除，策划页面和既有策划接口未修改。
