# 安卓图片导出 Activity 交接

## 改动目的

彻底移除 Web 长等待后误报导出失败的路径。Web 将图片交给当前 Activity 后立即进入成功返回流程，相册写入的最终结果由 Activity 原生 Toast 通知。

## 主要内容或涉及范围

- 新增 `exportImageToAlbum` 原生桥接。Android 图片导出不再复用同步 `exportFile` 请求等待最终相册写入。
- Web 把图片交给 Activity 后立即按 `accepted` 返回，不等待原生 Promise；关闭图片属性浮层并回到当前图片详情。
- Activity 异步解码 Base64、写入系统相册，并通过原生 Toast 显示“下载成功”“下载失败，请重试”或权限拒绝提示。
- 定时状态反馈不经过 WebView 请求链路，因此页面导航、组件卸载、Gecko 回调延迟或临时文件清理失败都不会再产生 Web“文件导出失败”。
- Android 9 权限弹窗期间不保留包含 Base64 大对象的 Call，降低内存占用。
- Android 壳升级为 `1.5.3`、安装版本 18，Web 最低壳版本 17；APK 内置最新 Web，官网下载页同步切换 1.5.3。

## 验证方式及结果

- Web `pnpm typecheck`：通过。
- Web `pnpm test`：45 个测试文件、190 项测试通过；新增测试使用永不回包的 Activity Promise，确认 Web 仍立即返回 `accepted`，并调用 `exportImageToAlbum`。
- Web 生产构建：通过，转换 4561 个模块；生成 `2026.11.26-r6`、发布号 `1795704337103`、`minShellCode=17` 的签名热更新，验签和 ZIP 摘要通过。
- Android `assembleDebug`、`lintDebug`：通过。
- 三个 ABI APK 均为 `versionName=1.5.3`、`versionCode=18`，APK Signature Scheme v2 校验通过。
- 独立官网构建和 1.5.3 APK 摘要校验通过。

## 尚未验证或已知限制

- 当前没有连接 Android 真机或模拟器，未执行实际导入、异步相册写入、原生 Toast 和返回详情的设备验收。
- Web 返回图片详情发生在 Activity 接收任务后，而不是照片最终写入后；最终结果完全以 Activity Toast 为准。
- APK 为调试签名，正式商店分发必须使用外部正式签名材料重新构建。
