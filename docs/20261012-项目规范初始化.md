# 项目规范初始化

## 改动目的

为支持 PC、Web、Android、iOS 和微信小程序的图片与文本编辑软件建立首版协作规范和目录约定。

## 主要内容

- 在仓库根目录新增 `AGENTS.md`，约定前端、后端、跨平台设计、安全隐私、代码协作和验收要求。
- 建立 `frontend/`、`backend/`、`docs/` 三个顶层职责目录。
- 规定每批项目改动都在 `docs/` 中生成以 `yyyymmdd` 开头的 Markdown 改动记录。

## 验证

- 检查目录结构和规范文档内容。
- 本次仓库尚无应用代码或构建配置，因此未运行构建或测试。

## 限制

- 具体技术栈、平台子目录、构建命令和测试工具需在项目实现方案确定后补充。
