# 灵感图锚点字号与导出返回

## 改动目的

按手机详情页反馈缩小图片锚点文字，并让 Web 在照片导出成功后回到进入照片前的页面，而不是停留在详情页或属性浮层。

## 主要内容或涉及范围

- 锚点标题基准字号由 14px 调整为 12px，详细描述由 11px 调整为 10px；详情、编辑画布、全屏查看、列表缩略图和导出像素共用同一组基准常量。
- 锚点标签宽度估算同步按 12px 标题计算，避免实际字号变小后仍按旧宽度提前换行；用户原有全局显示比例和单锚点 `label_scale` 调整继续生效。
- 普通图片导出时，属性面板会在图片详情之后追加 `?panel=properties` 历史记录。导出成功后识别这条内部记录并回退两层，直接回到进入照片前的页面。
- 水印模式已经先关闭属性记录，导出成功后只回退一层；没有可回退历史时以灵感库兜底。路由收尾异常不会覆盖已经成功的下载提示。

## 验证方式及结果

- Web `pnpm typecheck`：通过。
- Web `pnpm test`：46 个测试文件、192 项测试全部通过。
- 新增测试覆盖普通属性面板回退两层、水印和直接打开属性地址回退一层、锚点 100% 基准下标题 12px/描述 10px 的标签宽度，以及导出画布字号。
- Web 生产构建通过，转换 4562 个模块；现有大分块提示不影响构建成功。
