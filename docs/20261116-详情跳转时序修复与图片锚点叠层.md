# 详情跳转时序修复与图片锚点叠层

## 目的与范围
修正上一批详情预加载未真正阻止默认路由跳转的问题，并按用户要求将列表锚点从文字列表改为图片内叠层。仅修改共享Web前端。

## 主要改动
- 原来的RouterLink冒泡点击处理晚于组件内部navigate执行；改为点击捕获阶段preventDefault，默认跳转先被阻止，详情工作图下载、解码及编辑效果渲染完成后，才读取来源坐标并主动导航。
- 列表删除图片下方逐条锚点文字，缩略图内显示锚点圆点和备注标签；整图备注继续显示在图片下方。
- 仅在图库启用缩略图编辑变换及锚点叠层；复用编辑核心的旋转、裁切坐标映射，并补偿object-fit:cover的居中裁剪，裁剪外锚点不展示。ResizeObserver在布局变化时重新计算位置，卸载时断开观察。
- 缩略图小画布仅临时解码、渲染，编码完成后释放；对象URL继续沿用原有请求代次、替换和卸载回收规则。不新增依赖，不改后端、数据库、原生桥接或语言键。
