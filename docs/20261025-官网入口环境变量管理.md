# 官网入口环境变量管理

## 改动目的

根据用户提供的 Web 地址 https://photo.016imcn.love 开通官网访问按钮，并统一使用环境变量管理各平台入口。

## 主要内容

- `.env.example` 填入用户提供的公开 Web 地址；本机被忽略的 `.env` 同步设置该值，不提交本地配置。
- 官网域名继续使用 `VITE_SITE_URL`，各客户端使用 `VITE_WINDOWS`、`VITE_MACOS`、`VITE_ANDROID`、`VITE_IOS` 前缀，加 `_STATUS`、`_VERSION`、`_ARCHITECTURE`、`_DOWNLOAD_URL` 管理发布信息。
- 发布状态必须为 available，且版本、架构及有效 HTTPS 地址齐全才显示下载链接；未填写的平台继续展示即将推出。
- 更新官网 README、AGENTS.md 与设计维护说明，明确这是构建时配置，更新后需重启开发服务或重新构建部署。

## 验证方式及结果

- `pnpm --dir website build`：通过，包括类型检查、中英文键检查、配置边界检查及生产构建。
- 新增四个平台的环境变量映射和发布开关检查，通过；原有空配置、不安全地址、发布信息不完整检查通过。
- 本地 Chromium 检查生产预览下载页：导航与 Web 卡片均显示打开 Web 版，两个链接均为 https://photo.016imcn.love/；客户端下载链接数量为 0。
- `git diff --cached --check`：通过；本机 `.env` 确认被 Git 忽略。
