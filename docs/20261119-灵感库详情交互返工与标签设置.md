# 灵感库详情交互返工与标签设置

## 改动目的

按照参考图重新调整灵感库详情页，使移动端图片成为顶部沉浸式主体，并统一操作栏、标签设置和所有临时浮层的 iOS 透明磨砂质感。

## 主要内容

- 移动端详情移除顶部占位，图片舞台从视口顶端开始，固定为 2:3 无边框渲染框。
- 图片按自身比例优先占满长边或宽边；未覆盖区域使用同图低分辨率裁切后模糊铺底，避免背景拉伸。
- 点击图片、双指放大或键盘 Enter/Space 可进入全屏预览。全屏使用当前渲染图的像素快照，不包含锚点、标签等页面叠层。
- 图片备注下方改为独立的横向标签设置行；底部操作栏不再提供“标签”和“编辑”入口，进入编辑由锚点、调整、备注操作直接触发。
- 已设置标签支持长按 500ms 删除，并提供成功/失败提示、Delete/Backspace 键盘删除和明确的读屏标签。
- 标签行尾部“更多”打开悬浮玻璃面板，可搜索、新增、选择或取消标签；标签保存继续复用现有 `PATCH /api/v1/inspirations/{business_id}` 标签名称流程。
- 返回/更多按钮、底部操作栏、标签设置面板、图片详情工具浮层、属性/确认弹层、选择下拉、消息提示和页面 tooltip 统一为透明磨砂玻璃材质。
- 中英文 `editor` 命名空间同步增加全屏预览、标签新增、长按删除提示和空列表文案。

## 验证方式及结果

- `pnpm.cmd --dir frontend/apps/web typecheck`：通过。
- 390×844 Chromium 移动视口检查：顶部无空白，2:3 舞台贴顶且无横向溢出；浅色/深色主题下操作栏均能看出透明材质。
- 浏览器交互检查：点击/键盘进入全屏预览成功，预览中页面锚点不可见；标签“更多”玻璃面板可打开、新增标签成功；长按标签后标签从当前详情和服务端响应中删除。
- axe 检查：0 个 violation；剩余 incomplete 仅涉及图片叠层和渐变背景下的自动颜色对比度无法判定。

- 未在真实 iPhone、Android、微信小程序容器及 Safari/WebKit 上完成视觉、长按和双指手势验收。
