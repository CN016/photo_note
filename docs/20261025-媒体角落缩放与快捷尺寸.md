# 媒体角落缩放与快捷尺寸

## 改动目的

在选中媒体右下角提供可直接拖动的尺寸手柄，并按用户确认的关系增加“小图模式＝1/3 宽、原始比例＝100% 宽”两个快捷按钮。

## 主要内容

- 灵感图片和附件节点共用尺寸交互模块；角落手柄使用 Element Plus 图标及 tooltip，不改变资源引用或原始文件。
- 角落拖动按原始对角线投影调整百分比宽度，保留既有纵横比及 30%–100% 边界。拖动期间实时预览、松手后提交一次；Esc、pointercancel 或捕获丢失时取消草稿，卸载时释放监听与指针捕获。
- 快捷“小图模式”使用精确 `100 / 3` 百分比，使三张媒体可以自然同排；“原始比例”对应 100% 正文宽度，保持原媒体纵横比，并非原始像素大小。
- 快捷按钮、滑杆和角落缩放共用文档 width/layout 字段；百分比按当前语言格式化到最多一位小数，按钮提供当前选中态。
- 手柄可用方向键微调，Shift 加速，Home/End 跳到最小/最大宽度。触屏设备提供 44px 手柄，手机尺寸预设另起一行，避免操作条溢出。
- 保留撤销重做和保存流程，无后端、API 或文档版本变更。

## 验证方式及结果

- `pnpm typecheck`：通过。
- `pnpm build`：通过（包含 `vue-tsc --noEmit`）；既有编辑器依赖仍存在大 chunk 提示。
- 中英文 projects JSON 共 103 个键，键集合一致且无重复；`git diff --check` 通过。
- 本地 Chromium 真实组件、模拟私有图片接口：真实鼠标角落拖动将 50% 缩到 36%，拖动中 JSON 仍为 50% 且更新数为 0，松手后变为 36% 且仅更新一次；撤销恢复 50%。
- 快捷按钮实测：小图模式 JSON 为 `33.333333333333336`、显示 33.3%；原始比例为 100% 且 layout 为 original；序列化后重新加载保留小图尺寸。
- Esc 中止拖动后宽度保持原值，更新数为 0；只点击角落手柄不产生尺寸变更。Shift+右方向键增加 5 个百分点，附件手柄 End 键设为 100%。
- 390px Chromium 视口检查无横向溢出，尺寸预设与原有操作条分为两行。
