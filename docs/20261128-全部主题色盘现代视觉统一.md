# 全部主题色盘现代视觉统一

## 改动目的

将现代视觉调整从默认绿色扩展到全部浅色色盘和暗色主题，避免切换主题后重新出现高饱和光斑、厚重玻璃和粗糙阴影。

## 主要内容

- 绿色、青色、蓝色、金色四套浅色色盘统一使用中性近白表面、轻描边、低强度阴影和 10px/14px/22px 圆角层级。
- 四套浅色主题都改为平滑线性背景，环境光降低透明度并加大模糊半径。
- 各色盘保留各自色相，但主操作色、弱文字和状态色统一降低饱和度。
- 暗色主题改为低饱和暖黑绿材质，移除高饱和蓝紫光斑和厚重玻璃阴影。
- 主题切换圆点同步改为更柔和的绿色、青色、蓝色和金色。
- 弱文字颜色经过加深，所有浅色色盘继续满足 WCAG 4.5:1 普通文本对比度。

## 验证方式及结果

- Web `pnpm typecheck`：通过。
- Web `pnpm test`：48 个测试文件、196 项测试全部通过。
- 对比度测试覆盖四套浅色色盘的正文、弱文字、主按钮和状态文字。
- 样式测试确认现代视觉层覆盖 green、aqua、blue、gold 与 dark。
