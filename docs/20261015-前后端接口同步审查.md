# 前后端接口同步审查

## 改动目的

核对近期后端接口变更与 Web 前端现有调用，修正会影响服务可用性判断的路径差异，并同步灵感图文件大小字段。

## 主要内容

- 后端 `GET /healthz` 位于 `/api/v1` 前缀之外。前端由 `VITE_API_BASE_URL` 推导根路径健康检查地址，开发代理和部署说明同步覆盖 `/healthz`。
- 健康检查解析后端成功封套中的 `data.status`，并保留最近一次成功检查得到的 `data.version`，维护页用中英文显示该版本。
- 前端灵感图类型兼容 `file_size` 的字节数或空值，并在列表展示服务端编辑副本的存储大小；历史记录或旧服务未返回该字段时不显示。
- 公开配置接口和标签清空语义暂不需要前端改动：当前前端没有运行时公开配置契约或标签管理入口。

## 验证方式及结果

- 本机后端 `GET /healthz` 返回 HTTP 200，响应包含 `data.status=ok`、`data.version=1.0.0`；`GET /api/v1/healthz` 返回 HTTP 404，确认前端原健康检查地址错误。
- `frontend/apps/web` 执行 `pnpm build` 成功，包含 `vue-tsc --noEmit` 和 Vite 生产构建。

## 尚未验证的内容或已知限制

- 未运行单元测试，也未在浏览器或移动设备上做本次变更的手工界面验收。
- 后端目前没有配置 CORS 中间件；跨域直连仍需后端允许前端来源，或由部署侧提供同源反向代理，并转发 `/api/v1` 与 `/healthz`。
- Vite 构建提示 HEIC WASM 相关 chunk 大于 500 kB；构建成功，本次未调整图片解码依赖或分包策略。
