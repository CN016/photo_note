# 作品集编辑与照片删除基础

## 改动

新增作品集标题、说明、标签和策划关联的事务更新，标签及策划在当前空间和创建者范围内核验。新增作品照片及公开文件的删除接口：文件删除失败保留记录供重试，文件已不存在时可继续删除记录。后端版本 4.4.1。

## 验证与限制

- `go test ./internal/httpapi ./internal/service ./internal/store`：通过。
- 事务及文件删除未在独立 PostgreSQL 数据库及真实存储上联调；若文件删除成功后数据库提交失败，重试可继续删除记录，但记录在此期间可能显示失效图片。
- 作品集模块仍未完成：前端、作品集删除、照片标签排序、灵感库复制、统计、二维码和完整隔离测试等尚未实现；未构建或部署镜像。
