# 取景台官网设计与维护

## 定位与信息结构

面向摄影爱好者与摄影工作者，以“收藏灵感，整理日常”为主线。首页依次展示产品定位、界面示意、灵感库/拍摄策划/档期/计划/账本/消息能力、使用流程、常见问题及使用入口。下载页集中展示 Web 入口和客户端发布状态。

官网独立位于 website/，与 frontend/apps/web/ 的业务应用分开构建；不读取用户数据，不复制编辑器逻辑。产品能力以现有业务实现为依据，原生客户端不能因为目标平台目录存在就宣称已发布。

## 视觉与交互

采用淡蓝白背景、深蓝灰文字、蓝色操作按钮，结合画册式排版和模拟创作工作台。展示场景为本地 CSS 抽象画面，不是真实摄影作品；界面明确标注演示内容。无外部字体与图片请求，无用户素材。

布局按桌面、平板、手机响应；手机导航可折叠；使用原生 details 提供 FAQ 展开，键盘焦点清晰。动效仅轻量反馈，并支持 prefers-reduced-motion。图标采用 Element Plus 官方图标包，不自制品牌图形。

## 文案、配置与后续发布

website/src/i18n 按 common、home、download 拆分中英命名空间。语言偏好独立存储，存储失败仍可使用。切换语言同步页面标题、description 与 Open Graph 文案。

Web 地址与官网域名使用公开构建配置；版本状态集中在类型化配置。未配置 Web 地址显示入口待开放；未发布的客户端显示即将推出，微信小程序显示规划中。发布条目必须具备版本、架构和有效 HTTPS 地址后才出现下载链接。新增架构可扩展发布数据与展示，不应让一个下载按钮冒充全部架构。

当前只提供首页与下载页，按独立域名根路径部署，不依赖 SPA 路由回退。不包含支付、统计追踪、订阅表单或安装包托管。正式部署、客户端安装和真实 Web 服务可用性需另外验证。
