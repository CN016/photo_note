# 后端 V1 设计与规范

## 改动目的

确定 Go、Gin、GORM、PostgreSQL 和 Redis 的后端 V1 设计，并把通用数据库字段、业务 UUID 关系、无外键约束及 SQL 脚本归档要求加入项目协作规范。

## 主要内容

- 更新根目录 `AGENTS.md`：为项目自建业务表规定 `id`、唯一 `business_id`、`created_at`、`updated_at`；禁止数据库外键；规定业务 UUID 关联和 `backend/migrations/` SQL 归档规则。
- 新增 `docs/backend-design-v1.md`：描述后端分层、配置/用户/标签/灵感图表、索引、token/Redis 生命周期及 V1 HTTP API 契约。
- 采用 `UUID[]` 保存灵感图标签业务 ID并建立 GIN 索引；明确服务层所有权校验和删标签时的引用清理。
- 规定用户密码仅存 Argon2id 哈希，token 使用安全随机值并在每次使用时由 Redis 校验。
