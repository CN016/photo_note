# 全局色盘可读性、玻璃统一与移动策划详情修复

## 改动目的

- 让四套全局浅色色盘不只改变背景，也保证正文、弱文字、主操作色和状态文字在玻璃表面上清晰可读。
- 补齐列表筛选、编辑工作区、台账和流程面板等次级框体的玻璃材质，减少页面内普通半透明块与玻璃岛之间的割裂。
- 将灵感图详情右上角“图片属性”从独立模态框改为锚定玻璃浮层，消除框套框、材质断层和遮罩割裂。
- 修复移动端进入拍摄策划详情后页面整体不可见的问题。

## 主要内容

- 浅色主题统一加深 `--ink`、`--ink-soft`、`--muted`、主操作色、成功、警告和危险文字令牌；玻璃绿、青、蓝、金四套色盘分别提高小字号文字的对比度。
- 新增色盘 WCAG 对比度单元测试，覆盖正文、弱文字、主操作文字、主按钮文字、成功、警告和危险状态。
- 为画廊筛选、灵感工具板、上传面板与卡片、工作台卡片、流程概览、工作流快捷入口、台账筛选和指标卡、计划空态、项目文档、资源框和作品集照片补充轻量玻璃层。
- “图片属性”改为与按钮锚定的非模态 `el-popover`，与其他图片工具共用玻璃材质；同时移除独立对话框样式和多余 tooltip，避免蒙层与内部矩形边界。
- 项目编辑页底部导航容器改由全局选择器隐藏。此前 scoped `:global(.project-editor-route) .mobile-navigation-bar` 在移动端编译成 `.project-editor-route { display:none }`，会把带该路由类名的 `body` 本身隐藏。
- 新增外壳一致性测试，防止移动端项目详情再次引入会隐藏 `body` 的 scoped 全局选择器，并确保图片属性继续使用玻璃浮层。
