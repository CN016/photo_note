# 策划默认阅读模式和图片浏览

## 目的及内容

- 为策划增加 `default_read_only`，记录下次打开时的默认模式；切换会随正文修订保存，不作为授权控制。旧客户端更新时省略字段会保留已有值，旧数据默认为编辑模式。
- 编辑页右上角切换阅读和编辑；阅读状态下禁止正文、标题和资源编辑，单击图片按正文顺序打开浏览器，支持前后按钮、方向键及左右滑动。灵感图复用原有工作图、编辑变换和锚点坐标，显示可见锚点；GIF 图片附件也参与浏览。
- 新增 PostgreSQL 迁移 000026 和启动字段检查，后端版本提升至 4.6.0，更新 API 文档及中英文文案。

## 验证及限制

- `npm run typecheck`、`npm run build` 通过，构建包含签名 Android Web 热更新资源。
- `go test ./internal/service ./internal/store ./internal/database` 通过；独立临时 PostgreSQL 17 依次执行迁移至 000026，确认字段默认 false 且非空，`go test -p 1 -count=1 ./internal/store ./internal/database` 通过，包括现有租户集成测试和启动检查。后端 service 测试覆盖旧客户端省略字段和显式 true/false。
- 使用隔离浏览器和模拟数据验证只读/编辑切换、图片单击、锚点显示、前后按钮和模拟触摸滑动；没有连接真实用户数据。
- 未验证真实 PC 文件系统剪贴板、Android/iOS 真机触摸、线上部署及实际用户数据；未验证微信小程序和 PC 原生壳。部署前备份数据库并按顺序执行迁移，服务不会自动迁移。
