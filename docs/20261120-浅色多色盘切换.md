# 浅色多色盘切换

## 改动目的

在现有浅色玻璃主题基础上增加可一键切换的浅色色盘。用户可保留默认玻璃绿，或切换为 `#4BC0AD` 清透青、`#F6C358` 暖金色和 `#67AEDC` 清透蓝。色盘入口只展示颜色图案，不展示色名文字。

## 主要内容

- 主题状态拆分为明暗模式与浅色色盘两层，分别持久化到 `photo-nini.theme` 和 `photo-nini.light-palette`。
- 当前玻璃绿保留为默认色盘；新增清透青、暖金、清透蓝三套色盘。点击任意色盘会直接进入对应浅色主题；从深色模式点击色盘也会恢复到浅色。
- 每套色盘的页面背景只在自身色相内由主色向浅色过渡，不再混入暖米色或其他色相。
- 无色透明玻璃材质、磨砂噪点、边缘高光和文字层级在全部浅色色盘中保持一致。
- 新增 `PaletteSwitcher`，使用四个 44px 颜色圆点作为选择器；色名只通过 `aria-label` 提供给读屏，不在界面展示文字。
- 色盘入口加入桌面侧栏/移动抽屉的偏好区和“个人中心”的界面偏好卡片。

## 验证方式及结果

- 使用 Chromium 逐个点击四套色盘，确认 `data-palette`、页面主背景和主操作色同步更新。
- 验证清透青、暖金色、清透蓝在刷新后保持，并验证深色模式下点击色盘会回到对应浅色主题。
- 验证颜色按钮计算样式分别为 `#4BC0AD`、`#F6C358`、`#67AEDC`，界面不显示色名文字。
- 在 1440px 桌面和 375px 移动视口检查个人中心与抽屉偏好区，色盘按钮保持 44px 触控目标且无横向溢出。
- axe WCAG 2A/2AA 自动检查为 0 项违规。
- `npm run typecheck`、`npm test` 和 `npm run build` 通过。
