# 灵感库单条件搜索

## 改动目的

收敛移动端灵感库搜索入口，移除文本搜索框与筛选按钮之间的重复边框和独立人数按钮，并让文本、色系、标签、人数通过同一个搜索条件菜单切换。色系搜索需要支持任意选色，标签需要区分 AI 与人工来源，人数需要覆盖有人、无人、精确人数和范围。

## 主要内容

- 新增搜索条件面板：默认文本搜索，点击筛选图标菜单可在文本、图片色系、标签、人数之间单选切换；页面一次只显示并提交一种搜索条件。
- 色系条件使用可点击、可用方向键调整的色环，并提供黑、白、灰快捷色。后端把十六进制色值保存为查询参数，按图片 `color_palette` 前三种代表色的加权 RGB 距离排序，不新增数据库列。
- 标签在单行横向列表中展示，并提供全部、人工、AI 来源筛选；标签 API 按 `auto_tags` 与 `tag_ids` 推导 `manual/ai/mixed/unused` 来源，列表请求可用 `tag_source` 限定标签分配来源。
- 人数支持 `people_mode=present/absent/exact/range`；旧的 `people=0/1/2/3+` 继续兼容。
- 移动端减少灵感库顶部留白；图片缩略图同时去除 `.gallery-image-frame` 外层与 `.thumbnail-frame` 内层的描边、背景和矩形阴影，仅保留图片圆角、焦点轮廓和图片本身。
- `InspirationLibraryTools` 移除与搜索面板重复的标签、人数、颜色和空镜筛选入口，保留每日目标、热力图、日期和策划浏览。

## 验证方式及结果

- `gofmt`；`go test ./internal/service ./internal/httpapi ./internal/store` 通过。
- 临时启动隔离 PostgreSQL 17 与 Redis 7.4 容器，顺序执行 `backend/migrations/000001` 至 `000030` 全部迁移；设置独立 `PHOTO_NINI_TENANT_TEST_DSN` 后，`go test ./internal/store -run '^TestInspirationLibraryPostgres$' -count=1 -v` 通过。测试覆盖任意十六进制色按前三代表色排序、人数范围、标签 AI/人工来源推导以及 AI any/all 与人工标签筛选。
- `TestInspirationColorDistanceExpression` 验证排序表达式只使用前三代表色并拒绝非 `#rrggbb` 输入。
- 前端 `npm run typecheck` 与最终生产构建通过；`npm test -- --run` 通过，共 35 个测试文件、145 项测试。
- 中英文语言包解析和键集合检查通过，29 组语言文件无差异。
- 使用真实 API 和临时浏览器记录验证：移动端 390×844、320×700 与桌面 1440×1100 均无横向溢出；文本、色系、标签、人数菜单可切换；色环选蓝色后蓝色图片排在首位；AI 标签筛选、人数 2 至 4 范围结果与 API 返回一致。
- 浏览器检查浅色和深色主题；内外缩略图容器 `border-width` 均为 `0px`、`box-shadow` 均为 `none`、背景透明。移动端首屏副导航顶部为 8px，搜索框顶部为 62px，已压缩截图中的大块空白。

## 尚未验证或已知限制

- 尚未对生产库和生产数据运行 `EXPLAIN`；当前隔离库结果只证明 SQL 语义和功能，不证明大数据量性能。
- 浏览器使用桌面 Chromium 的设备视口模拟，不等同于 Android/iOS 真机验收；未验证真实触屏色环拖动手感。
- 同一张图片人工选择了与 AI 同名的标签时，现有数据把这次确认合并为 AI 来源，无法区分重复的人工确认。
- 色距排序使用加权 RGB 距离，不是 CIELAB/CIEDE2000；它按前三种代表色选择最近色，不代表视觉感知完全一致。
