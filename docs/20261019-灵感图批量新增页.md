# 灵感图批量新增页

## 改动目的

简化灵感图新增流程，支持一次选择多张图片并在提交前预览；每张图片仍独立保存为一条灵感图记录。

## 主要内容

- `/inspirations/new` 改为批量预览、移除和上传页面；已保存灵感图的详情与编辑路由保持不变。
- 复用现有单图文件上传与灵感图创建接口，逐张显示阶段状态；失败项可重试，成功项不会再次提交，已上传的文件 key 会在当前页面重试时复用。
- 保留前端从原始 `File` 读取文件大小、最后修改时间及 EXIF/IPTC/XMP 属性，并将属性、原始图片 key 和工作图片 key 按现有创建流程交给后端。后端仍从原始图片异步解析并合并图片属性。
- 批量创建时继续自动生成颜色画像并写入默认编辑文档，保留原单图新增后进入详情时触发的分析结果。
- 为新增页增加独立的中英文文案命名空间。

## 验证方式及结果

- `npm --prefix frontend/apps/web run build`：通过；Vite 提示现有 HEIC WASM bundle 超过 500 kB。
- `npm --prefix frontend/apps/web test`：通过，6 个测试文件共 21 项测试。
- i18n 中英文键集合检查：通过，16 个中文命名空间均有对应英文文件且键集合一致。
- `git diff --check`：通过，无空白错误。
- 浏览器冒烟测试打开新增路由后被重定向至登录页；隔离浏览器没有登录态，未实际选择或提交图片。

## 尚未验证的内容与限制

- 已登录状态下的多图选择、部分失败重试及回到图库流程未做浏览器端到端验证。
- 后端异步 ExifTool 属性解析代码未改动，但本次没有运行时数据库和文件存储环境来验证解析结果。
- 现有 API 按单张图片创建记录，批量页面顺序调用接口；上传接口限制单文件大小，图片内容校验与压缩仍由后端现有异步处理链路完成。
