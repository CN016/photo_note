# 移动端列表菜单入口与关闭动画

## 改动目的

- 为移动端列表页增加明确的菜单入口，让用户不依赖右滑手势也能展开完整导航。
- 修正点击抽屉外遮罩关闭菜单时遮罩和抽屉瞬间消失的问题，使关闭过程与打开、拖动保持一致。

## 主要内容

- 在移动端列表页左上角增加独立悬浮菜单按钮，使用 Element Plus `Expand` 图标和现有抽屉状态；图标由列表线与展开箭头组成，36px 视觉层置于 44px 触控热区内，不形成整行顶栏。按钮显示未读提示，并补齐 `aria-controls`、`aria-expanded` 状态。
- 菜单入口只在 `drawerListRoutes` 覆盖的列表与概览页面显示；独立交付页继续使用原有左上角入口，桌面布局不增加该按钮。
- 抽屉外遮罩保持挂载并通过透明度过渡关闭；菜单面板使用相同 220ms 曲线滑出。拖动期间继续关闭过渡以保持跟手，系统减少动态偏好下沿用全局禁用动画规则。
- 移除已被页面样式隐藏的旧顶栏菜单按钮，避免出现重复入口。
