# 可逆窗口动画与图片详情工具栏

## 目的

修复列表打开详情尚未完成时返回导致的顶部闪跳，改为 macOS 风格的弹性窗口展开及原轨迹倒放；精简图片详情，并分别适配桌面与移动布局。

## 实现

- 共享详情开合使用同一条 GSAP Timeline，起点由 Flip.fit 根据真实点击框计算，采用 0.7 秒 `back.out(1.35)` 弹性展开。中途返回暂停后从当前进度 reverse，完整展开后也倒放同一轨迹；反向途中再次打开会取消旧关闭回调并继续正放。
- 进入期间保留原列表文档高度，避免 KeepAlive 将列表移出文档后浏览器把滚动位置夹到零；最后一个过渡结束才释放高度与滚动锚定保护。
- 接入 Vue enter-cancelled / leave-cancelled，取消旧列表离场 Tween；完整窗口重新固定时保留时间线内部 Tween，避免返回动画被 killTweensOf 清除。会话变更清理动画和保护状态。
- 图片预览读取与解码期间允许返回，卸载版本号丢弃迟到结果；保存中仍阻止离开，加载期间的空间切换仍被拦截。原保存/标签/颜色写入等待及未保存编辑确认继续保留。
- 详情左上角纯返回箭头，保留可访问名称；移除可见标题说明和文件名。右上角三个点打开属性浮窗，尺寸、颜色画像、EXIF、GPS 与扩展属性按需显示。
- 标签、锚点列表/大小和旋转/裁切/RGB 各在独立工具浮窗显示；裁切、旋转与锚点添加回到画布执行。
- 底部编辑 Dock 提供编辑/取消、标签、锚点、调整，编辑中显示撤销、重做、保存和实际操作反馈。手机替代通用底部导航，桌面保留侧栏并使用悬浮 Dock；详情不显示会遮挡三个点的全局消息按钮。
- 标签下拉挂载到所属工具对话框，避免被滚动正文裁切，补充可访问名称与标签文字对比度。
- 手机列表维持两列大图。769px 以上按照至少约 210px 的卡片宽度自动增加列数；宽屏去除原列表最大宽度限制。实测 1024px 三列、1440px 五列、1920px 七列。
- editor 中英文新增相同键；没有新增依赖、后端变更或数据库迁移。

## 验证

- `pnpm test`：25 个文件、109 项通过（新增 5 项动画生命周期回归）。最后调整重新执行 `pnpm exec vitest run src/motion/navigationMotion.test.ts`，5 项通过。
- 最终 `pnpm build`：Vue/TypeScript 检查、Vite 生产构建与 Android RSA-SHA256 签名 Web 热更新生成通过。保留既有 500kB chunk 提示。
- `git diff --check` 通过；editor/gallery 中英文递归键集合一致。
- 本地 Chromium + 合成图片/API：40 张图库、1600px 位置，在进入后 40/90/180/350/650ms 返回，各次列表帧与整个中断区间均保持 1600px，列表节点不变，临时定位框与高度保护均被清理；950ms 完整打开后返回的所有列表帧也为 1600px。
- 真实浏览器 history.back：90ms 中断，1300px 返回帧均保持 1300px。减弱动态效果下新详情 80ms 返回保留 1400px 且无残留锁。
- 实测收回过程外框宽度连续变化：完整打开后返回采样 112 帧、65 种取整宽度；验证并非直接移除详情或仅淡入淡出。倒放中再次打开的生命周期由单元回归覆盖。
- 新详情合成接口流程：进入编辑、旋转、撤销、裁切拖拽及确认、打开锚点工具、在画布新增并保存锚点、保存编辑后退出编辑状态；标签创建并确认写入合成记录通过。
- 320/390/768/1024/1440/1920px 列表和详情无横向溢出；手机详情无通用底部导航；PC 无消息按钮与属性按钮重叠。截图检查手机编辑、属性/标签浮窗及 PC Dock/多列列表。
- 中英文工具名称与属性标题切换通过；暗色英文属性浮窗及详情 axe 0 违规；图库主体 axe 0 违规。标签下拉 axe 0 违规，其 aria-active-descendant/controls 存在性另行人工核对通过；展开下拉时的部分对比度自动检查为 incomplete，未宣称全量审计。

## 交付边界

需要发布业务 Web 与复用页面的 Android 签名 Web 热更新，交付包/清单/摘要放入本批根目录 artifacts 时间目录，不覆盖前批包。其他 PC/iOS/小程序原生壳、Android 原生代码、独立官网、后端与数据库未修改，不制造空包。

以上为本地浏览器和合成接口验证，未进行真实后端端到端、其他业务共享详情路由逐一验收、Android/iOS/PC 壳或微信小程序真机验收；未推送、上传或部署。macOS 风格为现有 GSAP 动效实现，不是调用 macOS 原生窗口 API。
