# 策划触屏拖放与全端构建复核

## 目的与问题定位

解决上一轮 1.0.1 真正未覆盖的入口与手势问题：顶部横幅实际属于 GlobalMessageButton，隐藏页面 AppHeader 不会隐藏它；媒体默认 NodeView 会继续让兼容 mousedown 进入 ProseMirror，重新聚焦正文；Tiptap blur 命令会异步清空 DOM 选区，而原生 draggable 与 Pointer/Touch 并行处理会取消长按状态。

## 主要修改

- 策划编辑路由不渲染全局消息横幅，普通页面保持原入口。
- 资源节点使用明确的 stopEvent 边界，媒体点击自行选择节点并同步撤去正文焦点；不再使用异步清空选区的 blur 命令。保留拖放与复制剪切管线。
- 移动端在 schema 和节点 DOM 两层关闭原生媒体 draggable。采用单一 Touch 手势与文档级非被动监听，避免节点选中、图片加载或 Vue 重绘后丢失移动事件。桌面仍保留鼠标原生拖放。
- 长按 350ms 后出现跟手镜像，实时按同父级可视块计算插入线与中英文落点提示。小图按水平边界，整行附件/段落按垂直边界。拖到视口边缘自动滚动并刷新落点。
- 短滑动继续滚页；松手才提交完整块搬移事务；取消、失焦、卸载时撤销预览并释放全部监听，不改变文档。
- 安卓版本升至 1.0.2 / versionCode 3，同时同步 npm 锁文件中的根包版本。没有后端、数据库或项目 JSON 格式变更。
- 增加事件边界、平台识别与几何落点测试，以及 `frontend/apps/web/tests/manual/project-editor-touch.html` 和同目录回归脚本。该页只用于 Vite 开发环境，使用合成数据并替换页面内的资源读取，不使用凭据，不进入正式构建入口。
