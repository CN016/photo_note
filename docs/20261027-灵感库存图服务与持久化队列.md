# 20261027 灵感库存图服务与持久化队列

## 目的与范围

实现已确认的每日存图目标、历史计数、提醒、热力图数据及六维浏览查询，为异步人物和颜色分析建立可恢复的持久化队列。后端版本4.1.1升级4.2.0，迁移000023新增目标、每日活动、处理任务及图片画像字段和索引，中文表/字段注释、UUID关系和无外键约束遵循项目规则。

采用原生musl ONNX Runtime的既有Alpine基础镜像，API容器管理一个Python常驻进程，共享Nano模型，压缩2并发、识别最高10并发、推理内部线程数1。Compose文件保持不变。模型输入仅来自FileService授权字节，子进程不继承数据库/Redis凭据。补充Pillow进行受限解码及EXIF方向处理，保留第三方来源与许可。

接口与配置详情见 [inspiration-library-api-v1.md](inspiration-library-api-v1.md)，运行时复用见 [AI说明](../backend/ai/README.md)。目标当前日生效、删除不扣历史数、失败不当作空镜、图片替换和旧租约比较均在服务/数据库层实现。

## 验证

- 独立PostgreSQL17测试库，执行完整迁移；额外独立schema验证从000022增量升级000023，跨北京时间午夜回填、历史target=null、中文注释与无外键通过。
- `PHOTO_NINI_TENANT_TEST_DSN`已设置到独立测试库执行 `go test ./...`，真实数据库测试实际运行，非跳过；覆盖个人、两个组织、同组织不同用户、缺失上下文、旧租约、替换代次、超时恢复、失败重试、未知人数、分页组合筛选、删除不扣数、当日目标更新、零存图和停机日期沿用历史目标、提醒幂等与一次确认。
- 独立schema验证两个启用Webhook渠道各产生一个outbox，重复发布不重复建任务；未向外网真实机器人发送消息。
- 容器内Python测试验证黑白灰和红绿蓝分区、占比合计、纯白图真实模型空镜输出及损坏图拒绝。
- 实际API完成10张公开COCO图片的授权上传、保存、异步压缩/识别、查询及目标进度；人物输出依次2/0/0/0/0/1/0/2/4/12。人工样例检查的有人/无人方向合理，未宣称精确人数标注评估或全量准确率。
- 最终4.2.0 API容器限制2核、2GiB、禁额外swap；5轮各10张已压缩图片同时释放，均观测到10个识别租约同时进行，结果全部落库约1.69~2.67秒，低于10秒。此次容器cgroup峰值333582336字节（约318MiB），资源限制实读2147483648字节、quota/period=200000/100000。完整结果另见交付验收记录与benchmarks JSON。

## 限制

10秒为当前独立测试环境、无既有积压、已压缩样本的实际验收结果，不包含上传压缩，不能推导为任意图片/数据库故障下的硬实时承诺。人物检测可能漏检或重复，空镜表示未检出人物。未部署生产库；历史已删除图片计数不可恢复。Alpine linux/amd64验证，其他CPU架构和原生移动/桌面壳未做构建与真机验收。完整上游ORT测试因基础构建禁用未运行；业务调用和本批专项测试已运行。
