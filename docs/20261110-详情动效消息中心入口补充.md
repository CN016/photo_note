# 详情动效消息中心入口补充

## 改动目的

补全消息中心通知卡片进入灵感图或交付任务详情时的共享元素动效。消息中心同样有“从卡片到详情”的视觉来源，不能只按一级列表父路由识别。

## 主要内容

- 详情路由父入口从单一路径改为多路径：
  - 灵感图编辑支持 `/inspirations` 和 `/messages`；
  - 交付任务支持 `/delivery` 和 `/messages`。
- 新增单元测试，验证消息卡片进入详情时输出 `shared-forward`。

## 验证方式及结果

- `pnpm exec vue-tsc --noEmit`：通过。
- `pnpm exec vitest run src/motion/routeMotion.test.ts`：6 项测试通过。

## 尚未验证

- 未使用真实消息记录在 Android、iOS、PC 或微信小程序真机验证消息进入详情及返回；仍使用共享 Web 路由规划和浏览器动画验证。
