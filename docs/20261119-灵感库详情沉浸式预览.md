# 灵感库详情沉浸式预览

## 改动目的

让灵感库详情更接近移动端图片浏览体验，图片在顶部优先铺满可用长边，并在固定 2:3 预览框中保持完整显示。

## 改动范围

- 移动端详情移除常规顶部留白，返回和更多操作悬浮在图片上方；图片预览框使用 2:3 比例且无边框。
- 图片按原始比例完整显示，未占满的空间由同图低清预览模糊填充；背景预览最长边限制为 240 像素，降低额外内存开销。
- 详情图片下方显示文件名、图片备注和标签；底部工具栏改为更透明的磨砂玻璃样式，并避开移动端底部导航。
- 编辑模式继续使用原有画布尺寸、裁切和锚点逻辑。中英文详情说明键保持一致。

## 验证方式及结果

- `pnpm.cmd --dir frontend/apps/web build`：最终版本通过，包含 `vue-tsc --noEmit`、Vite 生产构建及签名 Android Web 更新包生成。
- `git diff --check`：通过。

## 尚未验证与限制

- 未在真实 Android/iOS 设备、微信小程序容器或不同浏览器上进行视觉与触控验收；桌面和移动端的实际运行效果仍需浏览器/设备复核。
- 未修改原生壳或后端，因此不生成 APK、iOS、小程序或 API 镜像包，也无需数据库迁移。
- 未部署或上传 Web 与 Android 更新资源。
