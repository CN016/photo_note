# 安卓相册入口与主体缩放

## 目的与发布范围

修复纯图片上传误开文件管理器，以及安卓整页放大导致顶栏、底部导航一起变大的问题。Android 壳升级到 **1.1.3 / versionCode 7**；交付 Android 三架构调试安装包、业务 Web（含签名热更新）和独立官网下载包。后端仍为 4.2.1，本批无后端代码、镜像或数据库迁移变化。

## 主要改动

- 统一 `MediaPicker` 识别 MIME、扩展名及逗号分隔声明，补齐 HEIC/HEIF、常见图片及视频格式。任何未知或非媒体声明仍按文档处理，避免把 PDF/Office 附件误送入相册。
- 审计灵感图批量上传、图片编辑入口、注册/个人头像、反馈截图、管理回复图片、项目封面、项目灵感图导入、计划封面及项目图片/视频上传。纯媒体走 AndroidX Photo Picker；不支持 Photo Picker 的旧系统走相册 `ACTION_PICK`。项目文档附件和账本 JSON/CSV 导入保留 `ACTION_OPEN_DOCUMENT`。
- 保持原来的授权 URI 读取和私有缓存复制流程，不申请整库相册权限，不改变服务端格式、大小及归属校验。旧系统相册可能只能返回单张，回调兼容单选与多选。
- 新增共享 `ContentZoom`，安卓普通页面主体提供 1～3 倍双指缩放及主体内横向浏览；顶栏、底部导航、独立页脚、全局反馈入口和 body 弹层留在主体之外。账本页脚移出主体。旋转/分屏引起宽度变化时恢复 1 倍，切换页面不沿用旧坐标。
- APK 内限制原生整页缩放，防止 Gecko 抢占手势；普通浏览器、PC/iOS/小程序不进入该安卓分支。布局变更先等待 `nextTick`，避免首轮尺寸观察重置刚开始的手势。
- 图像编辑页的保存栏移出缩放边界；裁剪、标注模式及资源手柄保留独立操作，不抢占其手势。项目文档通过固定代码指定正文容器缩放，未搬动第三方组件 DOM，顶部标题与底部格式工具栏不参与缩放。公开预约页和维护页也仅包装正文，品牌栏、页脚保持原尺寸。
- 安卓异步创建 Gecko 会话后补齐当前 Activity 前后台状态，防止 `onStart` 早于异步初始化时遗漏绘制/触控激活。
- 没有新增用户可见文案或修改登录凭据存储、图片识别规则。

## 实际验证

- `pnpm --dir frontend/apps/web test`：15 个测试文件、70 项测试通过，包含重载登录恢复、空间隔离和图片资源交互。
- Android 构建包含 Web `vue-tsc --noEmit`、Vite 构建、签名热更新生成、三 ABI `assembleDebug` 和 `lintDebug`，均通过。官网独立构建通过。
- Android 9 / API 28 / x86_64 模拟器：最终完整原生测试 **18 项通过**，另在强停后新进程验证会话凭据恢复 **1 项通过**。
- 新增相册测试覆盖图片 MIME + `.heic/.heif`、纯扩展名、视频/混合媒体、文档/未知类型；真实 Gecko 图片输入带 HEIC 声明后打开相册，并取消返回，未落到 DocumentsUI。
- UIAutomator 注入安卓双指触控，调试扩展只读取生产主体组件布局：主体放大约 2.13 倍，视口 scale 为 1，414px 页面未撑宽；合成固定顶/底区域宽高保持原值。该项覆盖真实 Gecko 和系统触控投递，不代表实体手机验收。
- Chromium 412px 组件测试：主体 384×900 → 768×1800，顶栏 412×60 和页脚 412×64 不变；缩回 1 倍后横向滚动归零。真实项目文档组件正文 410px → 820px，固定格式工具栏仍为 412×51，页面宽仍为 412px，文档文本保持不变。
- RSA-SHA256 更新签名验证通过，热更新 ZIP 和逐文件 SHA-256 校验通过；最终三类 ZIP 执行完整性校验并生成校验清单。
- 早期回归暴露过测试扩展权限、首帧就绪及整页原生缩放问题；修复后以上述最终通过结果为准，失败日志保留在本批产物 logs 中。

测量摘要见 [安卓相册与主体缩放验证](benchmarks/20261027-android-gallery-content-zoom.json)。最终测试 APK 更新后另复跑 Gecko 相册用例 1 项通过。

## 限制与部署

- Android 实体 ARM 手机、厂商相册、多图实际选取/云相册下载、软键盘与所有编辑器操作未做真机验收。旧系统缺少可处理相册 Intent 的应用时不会偷偷回退文件管理器。
- Android 16 / API 36 模拟器启动尝试未成功完成，本批不能宣称现代系统 Photo Picker 已实机验收；分流代码已编译，实际运行覆盖的是 Android 9 相册分支。
- iOS、PC 原生壳和微信小程序未构建/运行；普通浏览器只验证了组件布局，未逐页回归全部业务流程。现有大 JS 分块、AGP 对 compileSdk 37.2 的支持提示仍存在。
- 安装包为 **Android Debug 调试签名**，不是正式发布证书。覆盖安装须与现有签名一致，不要卸载或清除数据；本批未改登录状态存储。
- 将 Web ZIP 解压内容部署到 photo 站点根目录，保留完整 `android-updates/`；将官网 ZIP 部署到 www 站点；Android 覆盖安装对应 ABI 的 1.1.3 APK。相册原生修复必须安装新 APK，仅热更新 Web 不够。
- 未上传站点、未部署生产环境。最终包、发布号、源码提交及 SHA-256 见本批根目录 `artifacts/<北京时间>/README.md` 和 `SHA256SUMS.txt`。
