# 灵感库双列大图与返回状态保留

## 目的

灵感库以图片浏览为主，压缩移动端顶部与检索区域，消除从详情返回时先到顶部再跳回原位置的闪动。

## 改动范围

- 图片列表固定双列，移除可见文件名、标签、收藏日期和副本大小，原数据及详情功能不变。
- 手机端去除列表和统计顶部额外留白，缩小搜索与筛选区域。图片总数右侧增加 Element Plus 人物图标按钮，默认隐藏人数，可切换为图上角标；切换不改变图片高度。
- 单指左滑从图片列表进入拍摄统计，右滑返回列表。纵向位移超过阈值、多指、表单、图表和已缩放内容不触发切页。
- 使用 Vue KeepAlive 保留图库组件、缩略图、分页、筛选、人数开关和缩放状态；返回时在绘制前即时恢复位置。保留现有 GSAP Flip 共享元素动画。
- 修复详情退出动画结束时先恢复文档流引发的滚动锚定；先移除固定定位的详情再清理样式，移除原 260ms 延迟滚动校准。
- 缓存按用户、会话、组织及会话版本隔离；进入上传或其他业务页面时释放，返回重新获取列表。离开图库时暂停轮询，详情返回后仅后台刷新已打开记录，不清空现有列表。关联策划返回时保留原关联菜单恢复能力。
- 增加 gallery 中英文同键文案，无新增依赖、后端/API/数据库变更。

- `git diff --check`：通过。gallery 中英文递归键集合一致。
- Chromium 使用本地 Vite 和合成 API/图片数据验证，未调用生产业务数据：40 张图、1600px 位置进入详情返回，列表根节点及卡片节点保持同一引用；118 个动画帧采样均为 1600px，返回结束仍为 1600px。
- 动画 100ms 时中途返回，1200px 位置与原节点保持；减弱动态效果时，120 个返回帧均为 1600px。
- 左右横滑分别进入统计/回到列表，列表节点复用；纵向与双指动作均未切页。人数开关 40/0 个角标切换，中英文按钮分别显示“显示人数”/“Show people count”。
