# Web 图标与 Webhook 品牌标识

## 改动目的

统一 Web 界面图标来源，改善侧栏品牌入口和导航图标，并让 webhook 渠道使用可辨认、可追溯的官方品牌素材。

## 主要内容

- 将 @element-plus/icons-vue 声明为 Web 端直接依赖，替换侧栏、主题切换、反馈入口、编辑器、账本、日程、登录、预约和消息中心中的手写 SVG 与字符图标。
- 用 Element Plus 图片图标替换应用中原有的 n. 文字标识；没有发现独立的 Photo Nini 官方 Logo 文件。
- 将企业微信、钉钉和飞书官方 App Store 图标下载到 Web 公共资源目录，用于消息投递状态、渠道卡片和渠道选择项；保留原始图片并记录来源与商标说明。
- 在 AGENTS.md 增加图标来源规则，要求优先使用 UI 组件库图标，并对品牌素材记录官方来源或开源许可。

## 验证方式及结果

- 执行 pnpm build：vue-tsc --noEmit 与 Vite 生产构建均通过。
- 搜索 Web 源码中的 SVG 标记与图标字符：未发现手写 SVG 残留；账本中的正负号保留为金额类型标记。

## 未验证内容与限制

- 未进行浏览器交互和真机响应式视觉验收；本次只验证 Web 端类型检查和生产构建。
- 构建仍报告已有 HEIC WASM 资源 chunk 超过 500 kB 的提示；本次图标改动未调整图片解码资源。
- Photo Nini 没有独立官方 Logo 素材，当前使用 Element Plus 图片图标作为产品入口标识；它是界面图标，不代表已确认的正式品牌 Logo。
