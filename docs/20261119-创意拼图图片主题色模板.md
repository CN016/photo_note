# 创意拼图图片主题色模板

## 改动目的

参考用户给出的图片与文字分区效果，为拼图增加单图配色模板，减少手工挑选主题色的步骤，并允许调整图片块和纯色块的位置。

## 主要改动

- 在拼图版式中增加“图片 + 主题色”模板。选择模板后可上传一张 PNG、JPEG 或 WebP 图片；图片在本地解码，并复用 `frontend/packages/image-processing` 的有界采样分析提取 Top 5 颜色，不上传原图或像素数据。
- 画布默认上下各半显示图片与纯色块。点按任一块或点击“交换上下位置”按钮都可切换位置；更换图片会重新识别颜色。
- 展示识别出的 5 个颜色按钮，并提供系统颜色选择器供自定义；选择会即时更新画布，并随拼图导出。
- 将模板颜色、顺序、图片 Blob 保存到现有 IndexedDB 草稿，继续复用 Konva、导出和双语文案机制；没有新增依赖或后端接口。

## 验证方式及结果

- `pnpm --dir frontend/apps/web build`：通过；Node 堆内存限制为 2 GB，该命令包含 `vue-tsc --noEmit` 类型检查。
- 使用单个本地浏览器和样例图检查：模板进入状态、5 个识别色板、选中色板、自定义颜色输入、导出按钮启用；浏览器无运行时错误。
- Web ZIP 与 Android Web 热更新 ZIP 完整性检查通过；Android 更新清单 RSA-SHA256 验签通过，432 个资源 SHA-256 与更新 ZIP 内容一致。
- 未运行全量测试套件，以控制电脑资源占用。点按画布换位逻辑已纳入构建，但没有在最终构建后重复运行浏览器操作；真实移动设备、桌面登录流程和线上部署未验证。

## 兼容性与平台范围

- 影响：业务 Web 与基于共享 Web 的 Android 热更新；没有后端数据结构或 API 变化。
- 未涉及：PC、Android 原生壳、iOS、小程序壳、独立官网。
- 颜色分析受浏览器图片解码与画布读取能力影响；无法读取的图片会显示错误并保留当前编辑状态。
