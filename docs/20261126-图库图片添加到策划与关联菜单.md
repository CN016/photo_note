# 图库图片添加到策划与关联菜单

## 改动目的

恢复并扩展图片长按菜单：复制图片固定在首项，第二项允许把当前图片加入任一现有策划，第三项开始直接展示该图片已关联的策划名称。

## 主要内容或涉及范围

- 图片长按和桌面右键菜单固定为“复制图片”“添加到…”，随后展示已关联策划名称；加载和失败状态不改变前两行位置。
- “添加到…”读取当前用户全部策划并排除已关联项目，以子菜单供用户选择。选择后读取目标策划最新正文与修订号，在正文末尾插入 `inspirationImage` 节点并保存；若原本以空段落结尾，图片插在该段落之前，保留继续输入位置。
- 添加由现有项目保存事务同步 `project_inspiration_usages`，不直接改关系表，继续执行资源归属、正文版本和组织/用户隔离校验。修订号冲突时自动重新读取一次，再保存。
- 已关联策划使用既有分页接口完整读取，点击后仍以临时阅读模式打开策划；从策划返回时恢复图库筛选、滚动和原菜单。
- 新增添加成功、重复、项目列表失败、关联列表失败和添加失败等中英文反馈。
