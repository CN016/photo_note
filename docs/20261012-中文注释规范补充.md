# 中文注释规范补充

## 改动目的

明确数据库字段说明和源码注释统一使用中文，并使现有 V1 建表 SQL 符合该要求。

## 主要内容

- 在 `AGENTS.md` 中规定：建表 SQL 为每张表和每个字段编写中文 `COMMENT`；新增或修改的业务代码需要准确、充分的中文注释。
- 更新 `backend/migrations/000001_create_v1_schema.sql`，为四张表及全部字段添加中文说明，涵盖字段用途、格式、业务 UUID 关系和安全限制。

## 验证

- 静态核对迁移中四张表的所有字段均有中文 `COMMENT ON COLUMN`，每张表均有中文 `COMMENT ON TABLE`。
- 执行 `git diff --check` 检查改动空白格式。
