# 灵感图详情编辑态与颜色分析

## 改动目的

让已保存的灵感图默认以只读详情展示，编辑工具在用户主动进入编辑后出现；同时以原图生成可持久化的颜色画像，并让备注锚点在图片上更易识别。

## 主要改动

- 灵感图详情只展示图片、备注锚点、颜色画像和“编辑”入口。既有图片进入编辑后显示旋转、裁切、RGB、锚点、撤销/重做和保存控件；取消或离开页面遇到未保存更改时先确认丢弃。新建流程保持编辑态。
- 锚点采用更通透的深色半透明圆角文字标签（50% 不透明度）和灰色描边、黄色中心圆点。按图片坐标选择标签朝向，为边缘圆点预留留白，并保留键盘焦点和触控命中区域。
- 新增共享锚点显示大小设置，范围为 70%–150%，按 5% 调整并写入浏览器本地存储。图片圆点、标签、备注列表编号与文字共用该比例；锚点按钮仍保留至少 44px 的触控区域。
- 编辑态支持拖动锚点和使用方向键移动；坐标按当前旋转与裁切反算到原图坐标，拖动结束只写入一条可撤销历史。备注列表和备注编辑框都可删除锚点，删除也能撤销恢复。
- 新增有界像素采样画像算法：透明像素按白色合成，保存前五种代表色、其他颜色占比、平均亮度和平均饱和度；所有百分比按百分之一精度分配，合计为 100%。画像版本为独立的 `version`，存于 `data.color_analysis`；分析来源保持原图，图片调整不重算画像。
- 新建记录转到详情后自动分析；旧记录在缺少当前版本画像时自动补算并经现有 `PATCH data` 保存。画像保存与编辑保存串行；分析或保存失败不阻断详情查看，提供本地化错误和重试入口。
- 补齐编辑页中英文文案及响应式样式；详情态的移动端反馈按钮避开颜色画像内容。未新增后端接口、数据库迁移或后端版本变更。

## 验证方式及结果

- `pnpm exec vitest run ../../packages/image-processing/src/colorAnalysis.test.ts`：通过，5 项用例覆盖纯色、双色占比、透明区域合成、前五色与其他占比合计及无效像素输入。
- `pnpm run build`：通过，`vue-tsc --noEmit` 与 Vite 生产构建均完成。Vite 对现有 HEIC WASM bundle（约 2.04 MB）超过 500 KB 的 chunk 给出体积提示。
- 编辑页中英文 JSON 键集合对比：通过，双方均为 72 个顶层键。
- `git diff --check`：通过。
- 使用本地模拟 API 在 Chromium 检查详情与编辑交互：详情态只有编辑入口；锚点大小改为 105% 后写入本地存储，刷新仍保留且圆点尺寸同步变化；拖动后位置更新且未误开备注，方向键移动产生撤销历史；删除后可撤销恢复；保存并重新加载后锚点和画像仍可读取。
- 390×844 窄屏检查：详情和编辑态的文档宽度均为 390px，没有横向溢出；编辑态显示三项变换工具、删除入口和移动说明。详情页键盘焦点、编辑入口及丢弃确认已检查。

## 尚未验证与限制

- 浏览器交互使用本地模拟 API 和 SVG 样例，不代表真实后端、数据库 JSONB 持久化或生产网络条件已验证；新建上传到详情的完整流程未在浏览器中走通。
- 当前检出只包含 Web 前端，PC、Android、iOS 与微信小程序壳未作构建或真机验证。
- 未对移动端大图内存峰值和真实设备触控表现作专项测量。
