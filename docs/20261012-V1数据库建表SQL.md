# V1 数据库建表 SQL

## 改动目的

将后端 V1 的 PostgreSQL 建表和索引定义保存为项目内可审阅、可版本管理的 SQL 文件。

## 主要内容

- 新增 `backend/migrations/000001_create_v1_schema.sql`，创建配置、用户、标签和灵感图四张表。
- 四张表都包含自增 `integer` 主键、唯一业务 UUID、创建时间和修改时间。
- 添加配置 key、手机号、业务 UUID 唯一索引；标签和灵感图的 `user_id` 索引；灵感图 `tag_ids` 的 GIN 索引。
- SQL 未创建外键；标签数组存储标签业务 UUID，关联校验由服务层完成。
- 更新 `docs/backend-design-v1.md`，说明已有初始迁移脚本但尚未执行。

## 验证

- 静态检查建表字段、索引定义和迁移脚本事务边界。
- 检查 SQL 文件不包含外键声明，并与 `AGENTS.md` 的通用字段和无外键规则一致。
- 未连接 PostgreSQL 执行脚本，未运行服务构建或应用测试。

## 未验证内容与限制

- 需在后续实施中使用目标 PostgreSQL 版本执行迁移，并检查实际 schema、GIN 查询计划及 GORM 字段映射。
- UUID 由服务端生成；当前脚本未提供数据库 UUID 默认值。
