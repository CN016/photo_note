# 灵感图图片属性与地图查看

## 改动目的与范围

改善灵感图详情中已保存图片属性的可读性，限制属性区域高度，并为有效 GPS 坐标提供地图入口。仅调整共享 Web 展示，不修改元数据采集、API、数据库或历史数据。

## 主要内容

- 常见扩展属性按中英文名称展示，识别部分拍摄与色彩枚举，并对同名来源去重；原始属性保留来源、完整键值与复杂内容展开。
- 常见数字按语义格式化，未知值原样显示；属性区域固定高度滚动，长键和值可换行。
- 存在合法经纬度时可在新窗口打开 OpenStreetMap 定位；点击后坐标会发送给该地图服务。

## 验证与限制

- 图片属性展示单元测试 3 项通过；中英文语言键集合一致。
- Web 构建包含 TypeScript 检查；构建与签名更新结果以本批交付说明为准。
- 未验证真实 GPS 样片、地图服务可用性、安卓真机和其他平台；地图覆盖与定位精度取决于图片坐标和第三方地图服务。未部署线上。
