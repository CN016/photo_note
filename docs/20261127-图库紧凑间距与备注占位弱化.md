# 图库紧凑间距与备注占位弱化

## 改动目的

五列图库缩小圆角后，原有缩略图间距仍偏大；照片备注占位文案也比用户正文更粗更大。调整两处默认视觉层级。

## 主要内容

- 五列图库移动端图片间距调整为 4px，桌面调整为 6px。
- 图库默认列数仍为 5 列，缩略图圆角保持 3px。
- 图片备注占位文案调整为 12px、字重 400、72% 弱化颜色，用户输入的备注正文保持原字号和对比度。

## 涉及文件

- `frontend/apps/web/src/views/GalleryPage.vue`
- `frontend/apps/web/src/views/galleryGridLayout.ts`、`galleryGridLayout.test.ts`
- `frontend/apps/web/src/views/EditorPage.vue`

## 验证方式及结果

- Web `pnpm typecheck`：通过。
- Web `pnpm test`：47 个测试文件、194 项测试通过。
- 新增测试确认默认五列、3px 圆角、桌面 6px 间距和移动端 4px 间距。

## 尚未验证

- 未连接移动真机检查不同设备像素比下的最终间距观感。
