# 作品集数据结构基础

## 目的与范围

建立独立作品集、照片和拍摄策划关联的数据结构。照片使用独立公开副本，允许保留原始文件元数据；数据按空间及创建者隔离。分享记录仅保存令牌摘要。

本批仅提供数据模型、版本化迁移、租户表登记和启动结构检查，未实现作品集接口、上传、分享、页面或文件生命周期，不构成可用的作品集功能。后端版本递增为 4.3.0。

## 验证与限制

- `go test ./internal/model ./internal/store ./internal/database`：通过。
- `git diff --check`：通过。
- 未在独立 PostgreSQL 数据库执行迁移和组织隔离集成测试；未进行部署及平台验收。
- 新版本启动前需先备份数据库并按顺序执行 `backend/migrations/000025_portfolios.sql`；不要将本批基础结构视为完整功能部署。
