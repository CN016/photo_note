# 灵感图详情手势与自动保存

## 改动目的

将灵感图详情页从依赖底部操作栏的编辑方式调整为图片优先的沉浸式交互：详情态默认不显示底栏，整图备注直接以正文形式编辑并自动保存，单击图片添加锚点，双指放大时图片连续跟手展开到全屏。本批仅修改共享 Web 前端，不涉及后端接口、数据库或原生桥接。

## 主要内容

- 详情态移除固定底部操作栏和为其保留的底部空白；完整旋转、裁切、色彩与显式保存工具仍可从图片属性中的“编辑图片”进入。
- 图片说明区域改为小红书式纯文字备注，不显示输入框边框、底色、阴影或字数框。点击文字后使用无边框多行文本控件原地编辑，失焦、继续输入或离开页面时通过串行保存队列自动写回 `data.image_note`。
- 备注保存成功和失败统一在页面顶部通知。保存队列按提交顺序执行，并始终合并当前颜色画像、锚点和备注，避免画像自动写回与后续备注/锚点保存互相覆盖；迟到响应不会使用旧文档覆盖继续编辑的内容。
- 详情态单击图片中的任意位置立即建立锚点草稿并打开备注输入，不再把单击解释为全屏。新增、修改或删除锚点后自动保存，并从顶部反馈成功或失败。
- 双指手势开始时同步复制当前真实渲染画布到全屏层，手指移动期间直接更新 GPU 合成变换、背景遮罩与目标位置；达到全屏后保留大图查看层并显示关闭按钮。未达到阈值时沿原轨迹收回，页面滚动锁和临时画布在关闭后释放。
- 图片属性保留键盘和桌面端“全屏查看”入口；双指查看快照限制长边 1600 像素，只在内存中存在，不持久化或重新上传。
- 新增中英文图片备注占位、自动保存状态、锚点保存状态、全屏查看和图片编辑文案，并新增双指几何单元测试。

## 验证方式及结果

- `pnpm typecheck` 通过。
- `pnpm test` 通过：36 个测试文件、149 项测试（已先同步到最新 `master` 提交后复跑）。
- `pnpm build` 通过：Web `5.0.2`、发布号 `1795270037854`；生成 Web 完整资源和 Android RSA 签名 Web 热更新资源。既有大分块提示仍存在。
- Web 交付 ZIP 共 441 个条目，Android 热更新 ZIP 共 4 个条目；使用 APK 内置公钥复核 `latest.json` 的 RSA-SHA256 签名成功，清单资源字节数与 SHA256 均和实际更新 ZIP 一致。最终包与截图证据位于 `artifacts/20261121-220734/`。
- Chromium 390×844 合成接口与图片验收：详情态无 `.image-edit-dock`；备注输入控件计算样式为无边框、无阴影；多行正文自动保存后顶部显示“备注已自动保存”，保存载荷同时保留颜色画像；模拟失败时顶部显示“备注保存失败，请稍后重试”，本地草稿不丢失。
- 单击画布打开锚点输入，保存后画布显示锚点并自动写回；最终载荷同时包含颜色画像、整图备注和锚点。
- 合成双指事件移动过程中图片缩放值与手指距离同步，背景随进度变黑；达到阈值后进入全屏层、锁定页面滚动并显示关闭按钮，关闭后恢复详情画布；低阈值手势回弹后不残留全屏层或滚动锁。
- Chromium 1440×900 验收无横向溢出，详情态同样不显示底部操作栏。合成快照与照片不入库、不提交。

## 尚未验证及限制

- 浏览器验收使用页面内合成鉴权、灵感图记录和 SVG 图片，不等同于真实后端端到端、线上环境或真实私有照片。
- 双指手势通过 Chromium TouchEvent 模拟，尚未在 Android/iOS 真机、PC 壳或微信小程序容器验证触控频率、系统手势冲突和内存峰值。
- 本批未部署站点，未上传 Git 远端。发布范围仅为共享业务 Web 与 Android 签名 Web 热更新；独立官网、API、数据库、PC/iOS/Android 原生安装包和微信小程序均未修改。
