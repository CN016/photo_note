# 工作台统计与全局跟手菜单

## 目的与范围
将工作台从菜单集合调整为当前空间模块统计，把手机端全局菜单统一到跟手左侧抽屉。仅涉及共享Web应用，不新增依赖、后端接口或数据库变更。

## 主要内容
- 工作台通过现有鉴权API读取灵感图/策划/作品集/交付数量、进行中计划、未读消息和所选月份档期/正式账本记录。提供卡片、表格和条形图三种查看方式；可切换统计月份、刷新及点击对应统计进入模块。
- 收入、支出及结余单列为所选月份人民币统计，金额按分累加并按当前locale格式化。不同范围在每项中标明；失败项显示不可用而非零，其他项仍展示。批次代次与账号/组织/会话范围检查阻止迟到回写。
- 所有已登记列表及概览路由在单指右划时按位移进度展开左侧菜单，达到阈值松手展开，否则回弹；抽屉内左划可关闭。详情、编辑及公开页面不接管手势；表单、滑杆、横向滚动容器、弹层、双指操作和已缩放内容保留原交互。菜单按钮提供不依赖手势的入口。
- 菜单顶部头像及昵称复用现有私有头像缓存，展示完整模块入口、空间切换与退出；管理菜单沿用账号角色判断。中间菜单可滚动，语言和浅暗主题切换固定在底部。语言选项留在抽屉内部，避免被遮罩覆盖。
- 手机移除原底部五项导航，恢复紧凑顶栏作为抽屉入口；桌面保留既有固定侧栏及页面布局，触屏右划时同一份菜单可作为模态抽屉展开。独立交付列表加入菜单入口，交付详情和公开交付维持原有独立交互。
- 抽屉提供遮罩、Escape关闭、Tab焦点循环、关闭焦点恢复和滚动锁定，打开时路由主体及全局顶栏inert；路由或会话变化关闭抽屉，卸载移除事件监听。遵循系统减少动态效果设置。
- common/workbench同步补充中英文同键文案；没有把内部实现说明加入产品页面。

## 交付与限制
需发布业务Web及Android签名Web热更新，根目录artifacts本批北京时间目录提供两个用途明确ZIP、签名清单、README与SHA256SUMS。无数据库迁移。未涉及独立官网、API镜像、PC/Android/iOS原生安装包或微信小程序分发。
没有新增后端聚合接口：作品集、交付、计划及当月账本/档期通过原有列表计算，超大数据量的性能尚未基准测试。统计展示模式本次仅保存在页面会话内，不声称跨设备保存。浏览器验收使用合成API替身，未连接真实用户数据、未执行真实后端端到端、各平台真机、上传部署或线上验收。
