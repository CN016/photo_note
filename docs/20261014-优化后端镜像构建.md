# 优化后端镜像构建

## 改动目的

为线上 Docker 构建提供可配置的 Docker 基础镜像代理与 Go 模块代理，减少从默认上游拉取镜像和依赖的等待时间。

## 主要改动

- `backend/Dockerfile` 支持通过构建参数指定 Go 构建镜像、运行时镜像和 `GOPROXY`。
- `backend/docker-compose.yml` 默认使用 DaoCloud Docker Hub 代理和 `goproxy.cn`，并允许部署时通过 shell 环境变量覆盖。
- 更新后端部署说明中的 API 端口和数据持久化路径，并说明构建代理配置方法。

## 验证方式及结果

- 验证 Docker Compose 配置解析及构建参数展开。
- 检查补丁格式和改动记录。

## 尚未验证的内容

- 本次未执行容器镜像构建，也未测量部署服务器使用各镜像源的实际下载速度；速度取决于服务器网络和镜像源可用性。
