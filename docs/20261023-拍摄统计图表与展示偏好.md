# 拍摄统计图表与展示偏好

## 改动目的

让拍摄属性和收藏趋势提供多种可切换的图表，并在当前用户资料中记住每张卡片的选择。

## 主要内容

- 十项拍摄属性默认显示环状比例图，可分别切换饼图、玫瑰图、横向条形图、纵向柱形图、矩形树图、雷达图和散点图。相机、镜头及色彩空间按接口返回的前五项计算占比，界面明确说明统计范围。
- 收藏趋势默认柱形图，可切换折线图、面积图、横向条形图、棒棒糖图、阶梯折线图和散点图。图表使用按需加载的 Apache ECharts，切换控件使用 Element Plus。
- `000022_user_statistics_chart_modes.sql` 新增用户 `extra` JSONB 列，偏好仅位于 `extra.statistics_chart_modes`；新接口按用户和卡片原子更新单个键，保留根对象中的其他数据。无效或未知模式按页面默认值展示。
- 后端版本升级到 4.1.0；补充接口文档与中英文页面文案。

## 验证方式及结果

- `go test ./...`：通过；未配置独立测试库的数据库集成测试按现有条件跳过。
- `pnpm typecheck`：通过。
- `pnpm test`：8 个测试文件、27 项测试通过。
- `pnpm build`：通过；ECharts 所在统计页 chunk 大于 Vite 默认 500 kB 提示阈值，按路由加载。
- 新增接口测试覆盖有效模式、非法字段、嵌套对象保留及现有资料字段不变。
