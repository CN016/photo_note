# 创意拼图模块

## 目的

为业务 Web 增加适配桌面与触控设备的本地拼图入口，优先复用社区成熟的画布交互库，避免自建渲染、裁切和触控引擎。

## 改动

- 新增 `/collage` 页面和中英文命名空间，并加入应用侧边栏；平台范围为共享 Web，安卓壳通过现有 Web 热更新资源同步页面。
- 画布使用 MIT 许可的 Konva 10.9.1；模板格、图片圆角裁切、拖动与高分辨率导出由 Konva 场景图负责。Vue 负责页面布局、照片列表和设置。
- 支持最多12张 PNG、JPEG、WebP 图片，提供方格、人像、横幅、主次版式，正方形/竖版/横版画布，照片间距、背景色、次序调整以及 PNG/JPEG 导出。
- 原图 Blob 与设置保存在本机 IndexedDB，不上传服务端；使用平台文件导出适配器，安卓沿用系统保存/分享并遵守32 MiB单次导出限制。
- Konva 通过页面懒加载；生产构建生成约207 KB（gzip约64 KB）的独立拼图路由分块。
