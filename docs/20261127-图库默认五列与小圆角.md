# 图库默认五列与小圆角

## 改动目的

灵感图列表进入时默认照片过少、缩略图圆角过大，导致单张照片可见面积偏小。调整为进入列表即显示五列，并缩小缩略图圆角。

## 主要内容或涉及范围

- 图库默认列数统一为 5 列，桌面和移动端不再按 4 列或 2 列初始化。
- 窗口尺寸变化和双指缩放继续以 5 列为基准，并保留原有列数吸附档位。
- 图库缩略图圆角固定默认为 3px，详情页、作品集和其他非图库图片容器不受影响。
- 将默认列数、圆角及列数吸附逻辑提取为可测试模块。

## 涉及文件

- `frontend/apps/web/src/views/galleryGridLayout.ts`、`galleryGridLayout.test.ts`
- `frontend/apps/web/src/views/GalleryPage.vue`

## 验证方式及结果

- Web `pnpm typecheck`：通过。
- Web `pnpm test`：47 个测试文件、194 项测试全部通过。
- 新增测试确认默认列数为 5、缩略图圆角为 3px，并覆盖列数吸附和非法缩放值。
- Web 生产构建通过，转换 4563 个模块。
- 生成 `2026.11.27-r3`、发布号 `1795756020085` 的 Android 签名 Web 更新，验签和摘要校验通过。

## 尚未验证或已知限制

- 当前没有连接 Android、iOS 或微信小程序真机，未执行最终设备上的五列视觉和触控点击验收。
- 五列是默认值，用户仍可通过双指缩放调整列数；本批未新增独立的列数设置项。
