# 原图质量导出与下载成功反馈

## 改动目的

提升导出图片清晰度，在保存完成时明确显示“下载成功”，自动回到图片详情，并修复图片实际保存成功后仍提示导出失败的问题。

## 主要内容或涉及范围

- 导出不再使用最长边 1800px 的编辑预览作为像素源。无旋转、裁切、调色、锚点和水印时，直接保存原始文件字节，保留原始分辨率、编码质量与文件元数据。
- 有可见编辑时优先读取文档中的 `source_image_key` 原图；原图已被后台清理或暂不可读时，回退到当前工作图。导出解码安全边长为 8192px，常见 24MP、48MP 照片保持原尺寸，JPEG 重编码质量提高到 0.96。
- 普通导出成功统一显示“下载成功”。成功后自动关闭图片属性浮层，回到当前图片详情页；水印导出同时退出临时水印模式。
- 将“生成导出媒体”“平台保存”“成功后页面收尾”拆成独立阶段。只有媒体生成失败或平台明确返回保存失败时才提示导出失败；成功后的浮层、路由或动画收尾异常不会覆盖成功结果。
- 通用导出入口新增可选成功文案，其他业务页面继续使用原有默认提示。

## 验证方式及结果

- Web `pnpm typecheck`：通过。
- Web `pnpm test`：44 个测试文件、186 项测试通过。
- 新增测试覆盖无编辑时直出原图、独立原图 key 优先、回退工作图、格式保留，以及原图导出安全边长。
- 中英文 `editor` 语言键集合一致，共 236 个键。
- 生产 Web 构建通过，转换 4560 个模块；生成版本 `2026.11.26-r3`、发布号 `1795697090682` 的 Android 签名 Web 更新，`minShellCode=15`，RSA-SHA256 验签与 ZIP 摘要校验通过。

## 尚未验证或已知限制

- Android、iOS 和微信小程序真机尚未执行原图导出、相册写入、成功提示和自动返回验收。
- 历史图片的 `source_image_key` 可能已被后台清理；此时只能从当前工作图导出，无法恢复当时已删除的原图字节。
- 超过 8192px 安全边长的超大图片会按比例降采样；Android 原生桥仍限制单次导出文件不超过 32 MB。
- 没有视觉编辑时直接导出原图字节；执行旋转、裁切、色彩调整、锚点或水印后属于重新编码图片，不保证保留原始 EXIF 等全部元数据。
