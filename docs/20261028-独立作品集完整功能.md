# 独立作品集完整功能

## 改动目的和内容

完成独立作品集管理、公开照片、标签和策划关联、上传或从灵感库复制、照片标题及排序、拍摄参数统计、二维码和链接分享。支持网格和瀑布流展示、个人空间与组织创建者隔离，公开页面无需登录。按用户确认，图片及其 EXIF 包括 GPS 和设备序列号允许公开；关联策划仅作者可见。

公开链接仅保存随机令牌摘要，重置或撤销使旧链接失效；公开图片直链在撤销分享后仍可访问。删除时清理公开副本，清理失败保留数据库记录以便重试。标签和策划删除时同步清除作品集引用。新增二维码依赖 `qrcode`（MIT）和类型声明，使用 Element Plus 图标及中英文语言资源；Docker 构建上下文排除本机上传目录。后端版本递增至 4.5.0。接口和部署说明见 [作品集 V1 接口与分享](portfolio-api-v1.md)。

## 验证及限制

- 本机独立 PostgreSQL 16 临时实例依次应用 `000001` 至 `000025`；作品集真实数据库测试覆盖个人空间、两个组织、同组织不同用户、跨空间策划关联、标签及策划删除清理、分享重置与撤销、标签和策划删除清理，以及文件失败重试。
- 真实 PostgreSQL 和临时文件存储接口测试覆盖创建、上传、复制本人灵感图、拒绝其他用户、公开读取完整属性、分享撤销、公开图片直链和删除清理。
- `go test ./...` 在独立 PostgreSQL 测试环境通过；Web 属性及公开地址定向测试通过，中英文键集合与 Web 类型检查通过。
- 浏览器本地模拟数据：公开页中英文切换、照片详情与 GPS 地图入口、窄屏、管理页编辑、网格/瀑布流切换、灵感图选择和二维码生成；真实生产服务及真实设备未验证。
- 未部署生产；Android 真机、PC 壳、iOS 及微信小程序未验证。大图、海量照片、真实网络中断和生产存储清理故障仍需环境验收。
- 打包及具体部署结果以本批 `artifacts` 中的 README 为准。上线前备份数据库并顺序执行尚未应用的迁移，不能仅部署镜像认为数据库已升级。
