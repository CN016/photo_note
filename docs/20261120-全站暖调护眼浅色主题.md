# 全站暖调护眼浅色主题

## 改动目的

调整业务 Web 全部页面的浅色视觉，使页面背景从左侧 `#ABC896` 鼠尾草绿开始向右逐渐过渡到更暗的暖米灰，降低整体亮度和冷白刺激。同步收敛玻璃材质、文字、按钮、状态色和图表配色，满足低饱和、暖调、护眼和简约雅致的要求。

## 主要内容

- 在全局主题令牌中新增全屏浅色渐变，统一登录、注册、维护、公开预约、公开作品集、公开交付及全部登录后页面背景。
- 将全站暖白玻璃、悬浮导航、弹层、表单、表格和卡片材料从冷白蓝调整为暖米白，并降低饱和度滤镜强度。
- 将主强调色从亮蓝调整为低饱和深鼠尾草绿，统一按钮、焦点环、链接和选中状态；同步调整成功、警告、危险等语义色的明度与饱和度。
- 更新灵感图详情专用主题、图表分类色、封面占位和账本导出报告配色。
- 保留图片全屏查看、编辑器画布等以图像内容判读为优先的深色场景；暗色主题保持既有结构。
