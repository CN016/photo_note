# 响应式前端一期

## 改动目的

在 `frontend/apps/web/` 建立共享 Vue Web 应用，提供响应式账号页、灵感图列表与编辑工作区，并实现中英文、明暗主题和后端不可达提示。本批只新增前端代码，没有修改后端接口或实现。

## 主要内容

- 使用 Vue 3、TypeScript、Vite、Vue Router、Pinia 和 Vue I18n。登录、注册、灵感图列表、编辑器、维护页及公共文案分别提供 `zh-CN` 与 `en-US` JSON。语言与明暗主题选择保存在浏览器本地。
- 新增构建变量 `VITE_API_BASE_URL`。所有 API 请求和健康检查均使用该根地址；地址必须以 `/api/v1` 结尾，构建产物在构建时注入，修改地址后需要重新构建。开发环境通过 Vite 代理到 `VITE_DEV_API_PROXY_TARGET`；生产环境可使用同源反向代理，跨域直连要求后端配置 CORS。示例配置位于 `frontend/apps/web/.env.example`。
- 登录与注册使用手机号和密码；注册增加昵称，客户端按 E.164、密码 8–128 字符、昵称 1–64 字符校验。Access Token 只存于内存，Refresh Token 持久化；请求遇到 401 时串行刷新并重试。
- 灵感图工作区支持分页列表、鉴权读取图片、图片预览、90 度旋转、归一化裁切、RGB 偏移、锚点备注、撤销和重做。图片选择后原始文件保持不变，预览限制为最长边 1800 像素。
- 当前后端创建记录时会压缩 `image_key` 指向的文件。前端因此分别上传原始文件和独立 JPEG 工作副本：记录的 `image_key` 指向工作副本，编辑数据中的 `source_image_key` 指向原图。创建失败重试时会复用已上传的两个 key。V1 没有文件删除接口，关闭未完成保存的页面可能遗留已上传文件；成功保存的新图占用两份文件存储。
- 页面首次导航检查公开 `/healthz`；页面 `load`、`pageshow`、窗口重新获得焦点和文档重新可见时再次检查。检查有 5 秒超时，并发事件复用同一请求。服务不可达时进入中英双语维护页；重试或服务恢复后返回当前标签页之前访问的路径。
- 新增 HEIC/HEIF 预览解码适配与按需加载的 WASM 回退，并在 `public/licenses/` 保留第三方许可文本。当前构建中的 WASM 分块约 2.04 MB（gzip 约 713 KB），仅 HEIC 回退路径加载。

## 验证方式与结果

- `pnpm typecheck`：通过。
- `pnpm test`：通过，2 个测试文件、4 项编辑文档/预览尺寸测试通过。
- 设置 `VITE_API_BASE_URL=https://api.example.com/api/v1` 后运行 `pnpm build`：通过；Vite 提示 HEIC WASM 分块超过 500 KB，已采用懒加载并保留提示。
- 设置 `VITE_API_BASE_URL=/api/v1` 与 `VITE_DEV_API_PROXY_TARGET=http://127.0.0.1:18089` 后运行 Vite 开发服务；通过代理读取本地模拟 API 的 `/healthz`，浏览器未出现 CORS 错误。
- 用本地模拟 API 和 Chromium 浏览器检查离线进入维护页、焦点/`load` 触发离线跳转、`pageshow` 恢复原路由、手动重试、登录、注册字段校验、浏览器刷新后 Refresh Token 恢复、列表空状态、明暗主题和中英文切换。
- 在 375、768、1024、1440 像素视口检查登录、注册、列表、空编辑页、已载入图片编辑页和维护页，未发现页面宽度溢出。浏览器检查只使用桌面 Chromium 模拟视口。
- 用本地生成的 JPEG 和模拟 API 检查图片预览、锚点增改删、锚点清除与撤销、旋转、裁切、裁切区域外锚点隐藏/撤销恢复、RGB 调整及撤销重做。新图保存流程分别上传原图和 JPEG 工作副本；创建失败后重试未重复上传；重新打开记录后通过原图 key 加载。已有记录保存只发送编辑数据 PATCH，没有重新上传文件。
- 注释检查、双语 JSON 键检查、`git diff --check`：通过。每个页面的中英文资源键数量一致：公共 31、登录 21、注册 22、列表 16、编辑器 52、维护页 9。

## 尚未验证与限制

- 本地模拟 API 验证不等于真实后端联调；本轮没有连接真实服务，也没有运行后端测试。
- 当前后端路由未安装 CORS 中间件；如果生产前端与 API 使用不同源，需在部署反向代理中统一来源，或后续由后端添加受控 CORS 规则。本轮未修改后端。
- 未在 iOS Safari、Android Chrome、PC Chrome/Edge 真机或实际设备上验证，也未测量大图解码峰值内存。
- 本轮浏览器编辑验证使用 JPEG；HEIC/HEIF 依赖的实际文件兼容性、目标设备解码能力及 LGPL 组件分发要求仍需单独验收。预览尺寸上限不限制底层解码的峰值内存。
- 列表和编辑核心单元测试覆盖模型、坐标转换与预览尺寸；认证并发、刷新令牌竞争和真实服务错误仍需集成环境验证。
