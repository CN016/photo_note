# 灵感库颜色匹配按相近色占比排序

## 改动目的

修正颜色筛选排序忽略颜色占比的问题，避免图片中仅少量出现的相近色决定整张图的排名。

## 改动范围

- 后端颜色匹配分数按最多五种代表色分别计算“全图占比 × 归一化加权 RGB 相似度”，累加后降序排列；不再只按前三种代表色的最近距离排序。
- 更新灵感库 API 说明，既有历史颜色画像可直接参与排序，不需要重算或数据库迁移。
- 后端版本从 4.13.0 提升到 4.13.1。

## 验证方式及结果

- `go test ./internal/store -run 'TestInspirationColorDistanceExpression|TestInspirationLibraryPostgres' -count=1 -v`：排序表达式单元测试通过；PostgreSQL 集成测试因未配置独立 `PHOTO_NINI_TENANT_TEST_DSN` 跳过。

## 尚未验证内容

- 未用独立 PostgreSQL 测试库执行集成排序断言；未构建容器镜像、部署或线上验收。
