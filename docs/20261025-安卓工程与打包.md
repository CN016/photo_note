# 取景台 Android 9+ 工程与内置浏览器打包

## 改动目的

建立可重复构建的安卓平台壳，复用现有 Web 界面与生产 API。按用户补充要求，最终随 APK 分发独立 GeckoView 内核，避免旧系统 WebView 导致应用不能运行；不要求用户先更新系统网页组件。

## 主要内容

- Android 工程位于 `frontend/apps/android/native/`，应用名“取景台”、包名 `love.imcn016.photo`、版本 `1.0.0` / 安装版本 1。原选包名中的数字开头段不合法，建包时已修正；尚不存在旧安卓正式包迁移问题。
- 最低 API 28 / Android 9；目标 SDK 36；GeckoView `158.0.20261021001945` 需要编译 SDK 37.2，使用 JDK 21、AGP 9.3.1、Gradle 9.5.0。提交 Wrapper、官方 SHA-256、npm 锁文件与 Gradle 依赖锁。
- Web 构建资源作为固定 ID 的内置扩展页打包，向生产配置的单一 HTTPS API 主机授予网络权限。保留既有 API、登录和组织隔离逻辑，不修改后端 CORS、数据库或后端版本。
- 生产页面到原生的消息按扩展 ID、当前会话、顶层 frame 和扩展根来源校验；外部地址交给系统浏览器。关闭远程调试、浏览器控制台输出、明文连接与系统备份/迁移；附带 Mozilla 许可证和精确源码定位。
- 平台适配层统一文件导出；账本 JSON、UTF-8 CSV、PNG 图表接入系统保存/分享。SAF 创建文件、只读 URI 授权，不申请全盘存储权限。取消有独立结果，失败有双语反馈，防止重复导出。
- 原生单文件导出上限 32 MiB；分享缓存按批次隔离，后续导出清理超过一天的批次。没有后续操作时不保证主动到期删除，系统也可清理缓存。
- 文件输入使用系统选择器；系统栏与键盘由原生容器避让。返回键与浮层、输入焦点、路由守卫及首页回到系统衔接，Web 主题同步系统栏样式。
- imagegen 生成原创蓝白“取景框、摄影风景、灵感光点”透明位图，保存源素材及说明，生成各密度、自适应、圆形入口、单色主题和启动屏资源。业务界面继续使用既有 Element Plus 图标。
- 构建脚本执行环境检查、共享 Web 构建、扩展资源同步、Android 编译与 Lint，分别输出 ARM64、ARMv7、x86_64 安装包及 SHA-256。正式签名只预留外部环境配置，不生成生产密钥、不上架。

## 交付与限制

- 安装包位于本地忽略目录 `frontend/apps/android/artifacts/`；ARM64 约 130.1 MiB、ARMv7 约 125.2 MiB、x86_64 约 136.6 MiB。三个包均内置完整的对应架构 Gecko 内核；普通手机优先选择 ARM64。构建产物、临时日志和模拟器材料不提交 Git。
- 当前只交付调试签名测试包。未进行正式密钥签名、发布优化、商店上架或后台部署；后端无改动。
- Android 16 / API 36 镜像已安装，但在当前 Windows 环境的硬件加速与软件加速尝试均停留 adb offline，未完成其运行验收。Android 9 的实测不能代替 Android 16 或 ARM 真机验证。
- 尚未验证真实账号登录、多个组织切换、真实上传/下载、HEIC 与复杂附件预览、实际编辑器高分辨率导出、持续内存峰值、ARM64/ARMv7 真机及其他平台。4096² 合成画布成功不等于大型真实项目或移动设备内存验收通过。
- AGP 9.3.1 提示其测试范围止于 SDK 37.1；本批按 Gecko 要求用 SDK 37.2 完成编译和 Lint，未抑制该提示。Web 仍有既有的大 chunk 提示，Gradle 有未来版本弃用提示，均不作为运行验证结论。
- 浏览器内核由 APK 更新维护，不运行时下载内核或热更新网页。后续内核升级必须回归启动、授权、文件、图片、内存和最低系统，并同步依赖锁与源码许可信息。

构建、安装、签名环境变量和兼容边界详见 `frontend/apps/android/README.md`。
