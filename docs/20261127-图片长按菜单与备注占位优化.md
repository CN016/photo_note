# 图片长按菜单与备注占位优化

## 改动目的

优化图片备注输入的占位提示，并为单张灵感图和灵感图列表补充长按图片操作，减少进入属性面板才能保存图片的步骤。

## 主要内容

- 整图备注占位文案前增加 `| `；进入编辑状态后占位文案继续保持 12px、常规字重和弱化颜色，用户输入正文仍使用正常字号。
- 单张灵感图详情长按图片弹出底部操作面板，提供保存图片、复制图片和删除图片。
- 详情“保存图片”直接调用属性面板同一导出函数，保持原图质量、文件命名和平台相册保存行为一致。
- 详情“复制图片”复制当前渲染画布为 PNG，不重新请求图片或改写文档。
- 详情“删除图片”先确认，再调用现有 DELETE 接口；删除成功返回列表，被策划引用或删除失败时保留当前页面并显示错误。
- 灵感图列表长按菜单增加“下载图片”首项，下载当前工作图并使用 Android 相册直存与明确成功提示。
- 自定义底部操作面板接入系统返回键关闭逻辑。
