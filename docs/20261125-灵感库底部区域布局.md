# 灵感库底部区域布局与缩放边界

## 改动目的

固定并收紧灵感库图片列表之后的底部内容区域，避免页面缩放影响工具面板和页脚。

## 改动范围

- 将 Android 双指页面缩放容器收至图片网格，加载更多、存图目标与筛选面板、页脚不再随该容器缩放。
- 缩小图片列表与加载更多、筛选面板和页脚之间的留白，并减少手机端主内容底部填充。
- 图片网格继续使用既有列数缩放交互。

## 验证方式及结果

- `npm run build`：通过，包含 `vue-tsc --noEmit` 和 Vite 生产构建；Android 签名 Web 热更新包已生成。

## 尚未验证内容

- 未在 Android 真机上验证双指缩放边界和底部视觉效果；未部署及线上验收。
