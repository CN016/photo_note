# 侧边栏头像与消息角标缓存优化

## 改动目的

避免页面切换时重复下载用户头像和立即刷新消息角标，减少侧边栏闪烁与重复请求。

## 主要内容

- 新增共享 Pinia store 缓存当前账号头像对象地址、未读数和最新通知基线。缓存只驻留于当前页面内存，不写入本地持久存储；头像文件变化、账号退出或鉴权失效时释放对象地址。
- 侧边栏重新挂载时优先复用缓存；仅首次进入或账号变化时拉取头像与消息数据。整页刷新会重建 store，头像请求使用 `cache: reload` 获取新文件。
- 未读数由一个全局 30 秒轮询维护，并复用通知分页响应中的 `unread_count` 和最新通知，取消原先独立的角标请求。消息中心的列表刷新、单条已读和全部已读会同步共享角标；较早开始的响应不能覆盖更新后的已读数量。
- 个人中心复用侧边栏头像缓存；头像上传保存成功后直接用本次上传的字节更新缓存，避免再下载一次。

## 验证方式及结果

- 在 `frontend/apps/web/` 执行 `pnpm run build`：`vue-tsc --noEmit` 和 Vite 生产构建通过。
- 执行 `git diff --check`：通过。

## 尚未验证及限制

- 未进行登录后的浏览器交互验证，页面切换、跨账号登录、退出和消息已读效果仍需在真实会话中确认。
- Vite 构建提示 HEIC WASM bundle 超过 500 kB；构建成功，该体积提示与本次缓存改动无关。
