# 安卓系统通知与后台 HTTP 监听

## 目的与范围

按用户要求默认开启安卓系统通知，并增加后台原生 HTTP 轮询。无新增应用开关、推送服务商、后端接口、配置或迁移。Android 壳升级至 1.3.0 / versionCode 9，沿用 debug 调试签名交付。

## 主要实现

- 原生 dataSync 前台服务与低重要性常驻通知，30 秒检查现有消息接口；网络失败指数退避到 300 秒，恢复后回到 30 秒。
- 首次成功读取建立基线，不重放历史。后续最新 UUID 变化且存在未读时合并显示通用系统提醒；未读归零取消提醒。点击只打开鉴权消息中心，不接收任意 URL。
- 默认启用；Android 13+ 自动申请系统通知权限，拒绝后保留站内消息、不反复弹窗；用户仍可在系统设置控制通知。
- Web 与后台原生共用 Keystore 凭据、刷新串行锁和会话代次。后台刷新不依赖 Web 定时器；Access Token 不落盘。切换空间核对完整会话标记后用原生最新 Refresh Token 提交，避免后台轮换造成旧凭据失效。退出与撤销停止监听；旧空间结果不得生成提醒。
- 新桥接受现有扩展 ID、顶层、本机会话来源限制。旧 APK 探测不到新桥接时回退原 HTTP 刷新，仍可接收共享 Web 热更新。
- 原生渠道/提示补齐中英文，无新增 Web 可见文案或依赖。业务 Web、Android 三 ABI APK、签名热更新和分发 APK 的独立官网需随批交付；后端、PC、iOS、小程序无新增平台包。

## 平台限制

Android 15+ dataSync 前台服务后台累计有 24 小时内 6 小时时限，到期调用 stopSelf，不伪造 remoteMessaging 类型、不无限拉起；再次打开应用尝试恢复。省电、Doze、厂商限制、强停、进程回收及网络均影响后台时效，不承诺永久在线。未申请开机自启监听、电池豁免、唤醒锁或精确闹钟。

参考：[Android 前台服务时限](https://developer.android.com/develop/background-work/services/fgs/timeout)、[前台服务类型](https://developer.android.com/develop/background-work/services/fgs/service-types)。

- Vitest 定向 14 项通过：原生刷新桥接、旧 APK 的 HTTP 回退、跨空间迟到响应、上传刷新、空间切换及平台导出回归。

- 三 ABI APK 均通过 apksigner verify、ZIP 完整性和内置发布号核对。原生中英文资源 20 个键集合一致。
- 独立官网 `pnpm build`（类型、语言、配置检查）通过；本地预览下载校验通过：两份 ARM APK 的 HTTP、MIME、长度、SHA-256、摘要文件和不存在文件 404，官网分发版本为 1.3.0 / 9 / debug。
- `git diff --check` 通过。AGP 对 compileSdk 37.2 的既有提示及 Web 大分块提示保留。
