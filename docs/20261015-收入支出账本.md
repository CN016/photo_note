# 收入与支出账本

## 改动目的

将 `E:\work\WWW\jz.html` 中的营收日历能力整合到 Photo Nini 共享 Web 应用，提供收入和支出记录、可恢复草稿、分析和导入导出，并确保记录按当前登录用户隔离。

## 主要内容

- 新增 `/ledger` 页面和桌面月历、窄屏按日列表、日期详情与编辑底部面板；可记录日期、时间、类型、人民币金额、分类、收付款方式、标记和备注。
- 新记录先在服务端建立草稿；编辑正式记录时单独保存待应用快照。字段变化经 400ms 防抖并按记录串行保存，草稿修订号阻止迟到写入覆盖；只有完成后才更新正式字段和统计。删除需确认。
- 提供搜索、收支/分类/方式/标记/最低金额筛选，复制昨日结构，按星期和日期趋势、分类/方式汇总、月度与年度对比、年度热力图、洞察、最近记录以及月报和对比 PNG 导出。
- JSON/CSV 导入先预览再合并；本应用业务 UUID 只更新当前用户对应记录，旧营收格式作为收入新增，缺失记录不删除。JSON/CSV 导出只包含已完成记录。
- 页面文案分别维护于 `frontend/apps/web/src/i18n/ledger.zh-CN.json` 和 `ledger.en-US.json`，共享导航文案加入公共语言包。`AGENTS.md` 增加每页双语 JSON、键集合一致和禁止硬编码可见文案的规范。
- 原参考 HTML 原样复制到 `docs/references/ledger/jz.html`。
- 新增 `ledger_records` PostgreSQL 表和按用户/日期索引；金额使用整数分，草稿使用 JSONB 与修订号。迁移包含表和全部字段的中文注释，不建立外键。由于工作区已有 `000008_user_phone_feedback.sql`，本功能迁移使用 `000009_create_ledger_records.sql`。应用需手动执行迁移；后端版本升至 `2.1.0`。

## 接口

账本接口均要求 Bearer Access Token，并根据 token 中的用户业务 UUID 访问数据：

- `GET /api/v1/ledger/records?from=YYYY-MM-DD&to=YYYY-MM-DD`：查询日期范围内正式记录并恢复当前用户全部草稿。
- `POST /api/v1/ledger/records`：建立新草稿。
- `PATCH /api/v1/ledger/records/{business_id}/draft`：以 `revision` 保存完整草稿快照。
- `POST /api/v1/ledger/records/{business_id}/complete`：校验修订号并应用草稿。
- `DELETE /api/v1/ledger/records/{business_id}`：删除本人记录或草稿。
- `POST /api/v1/ledger/import`：事务式合并最多 1000 条完整记录。

API 金额是两位小数的十进制字符串；响应不包含自增 `id` 或 `user_id`。
