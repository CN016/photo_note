# 全局右键菜单基础设施

## 改动目的与范围

统一业务 Web 的桌面右键入口，为图库和策划提供可组合的菜单基础设施。手机普通文本保留系统长按选词。

- DOM 处理器从具体节点向页面逐级匹配，单一浮层承载菜单及子菜单；支持视口避让、滚动、Escape、方向键、Enter 和 Shift+F10。
- 普通页面复制，输入框按能力提供剪切、粘贴、全选；密码框禁用复制和剪切，只读输入禁用修改。
- 平台适配层提供剪贴板能力查询及文本、图片读写；只在用户操作时调用，失败反馈不包含内容或私有地址。
- 输入选区预先保存，异步回写核对原输入值；图片转换为 PNG 后及时释放位图和画布。
- 菜单随页面、语言、账号或空间切换关闭，目标 DOM 失效也关闭；Android 返回优先关闭菜单。
- 增加账号/空间/代次绑定的标签页内存快照基础设施，供图库返回功能使用；不持久化私有图片。
- 新增中英文 `contextMenu` 命名空间，图标沿用 Element Plus。

## 实际验证

- 前端 `npm test` 全量 20 个文件、85 项测试通过；来源隔离测试包括错误来源、空间切换及登出清理。
- `npm run typecheck` 通过，生产构建含相同类型检查；最终产物结果见交付说明。
- agent-browser Chromium 中使用内存 API fixtures 检查输入框/密码框/只读框的菜单启用状态、移除目标时关闭、键盘唤起及英文菜单显示，结果符合预期。
- 中英文键集合核对：context-menu 78 键一致。

## 未验证内容

浏览器检查使用合成数据及 DOM 事件，不是生产数据端到端验收。实际操作系统剪贴板的权限授予/拒绝、各浏览器系统菜单差异及 Android/iOS 真机交互未完成实测；不支持剪贴板 API 的环境会禁用对应菜单操作，系统快捷键不被接管。没有新增原生桥接或原生权限。
