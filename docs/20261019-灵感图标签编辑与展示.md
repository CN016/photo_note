# 灵感图标签编辑与展示

## 改动目的

支持在灵感图详情中搜索、创建和移除标签，并在图库卡片上快速查看标签，减少手动维护标签 ID 的操作。

## 主要改动

- `GET /tags` 增加名称关键词 `q`，保留分页；详情页多选框支持搜索和输入新标签，变更后立即提交完整的 `tag_names` 数组。
- 后端按当前用户、去除首尾空格后的大小写精确名称复用或创建标签，并在同一事务中更新灵感图。保留旧客户端 `tag_ids` 更新，两个字段同时提交会被拒绝。
- 灵感图详情和列表响应新增与 `tag_ids` 顺序对应的 `tag_names`。图库卡片最多显示 3 个标签，其余以 `+N` 展示并可悬停查看名称。
- 新增迁移 `000017_dedupe_inspiration_tags.sql`，合并同一用户的重复标签、修正并去重灵感图引用，再添加 `(user_id, content)` 唯一索引。
- 更新 API 与部署说明、中英文页面文案；后端版本从 `2.7.1` 提升至 `2.8.0`。
