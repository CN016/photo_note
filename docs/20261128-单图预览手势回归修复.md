# 单图预览手势回归修复

## 改动目的

修复上一版为单图长按菜单包裹画布 pointer 事件后，单张灵感图预览、单击锚点及双指操作不正常的问题。

## 主要改动

- 撤销画布 `pointerdown / pointermove / pointerup / pointercancel` 的长按包装，恢复原有单击、拖动、裁切和双指全屏手势链。
- 单图长按菜单改为监听画布原生 `contextmenu`。手机长按与桌面右键仍可打开底部图片操作面板，但不再占用普通指针事件。
- 保留保存、复制、删除图片功能，以及返回键关闭底部面板。
- 备注占位、默认四列、紧凑间距和现代主题不受影响。

## 涉及文件

- `frontend/apps/web/src/views/EditorPage.vue`

## 验证方式及结果

- Web `pnpm typecheck`：通过。
- Web `pnpm test`：48 个测试文件、195 项测试全部通过。
- 代码路径确认单击画布继续进入锚点添加逻辑，双指手势继续由原生 `touchstart/touchmove/touchend` 处理。

## 尚未验证

- 当前未连接 Android 或 iOS 真机；仍需在设备上复核长按呼出菜单、单击加锚点和双指全屏的组合操作。
