# 图片开合完整比例统一

## 目的与范围
修复灵感图进入动画中图片铺满整个窗口导致裁切、屏占比大于返回动画的问题，仅涉及共享Web图片过渡层。

## 主要内容
- 进入快照从object-fit:cover改为contain，保持完整图片比例，不再以窗口比例裁图。
- 详情画布绘制完成时，使用画布真实边界设置进入快照的局部坐标；根节点正在缩放时按实际比例反算。该公式与返回快照相同。
- 动画结束只淡出交接，不再额外执行一次180ms图片尺寸变化。列表仍保留既有缩略图裁剪布局，不修改用户原始素材、工作图或编辑文档。

## 实际验证
- 全量Vitest：28个文件、120项通过，其中新增开合边界一致与contain回归；原有图片生命周期与可逆动画测试通过。
- 最终pnpm build包含vue-tsc检查、Vite生产构建及Android签名Web热更新资源生成，通过；已有大chunk提示。
- 隔离浏览器使用真实imageMotion模块和合成1200×720画布：进入和返回都为x=25/y=300/width=340/height=204；快照object-fit为contain，左上边缘像素[255,0,0,255]保留。
- git diff --check通过。
