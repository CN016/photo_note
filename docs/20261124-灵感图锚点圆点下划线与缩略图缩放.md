# 灵感图锚点圆点下划线与缩略图缩放

## 改动目的

统一灵感图详情、编辑画布、全屏预览和灵感图列表中的锚点视觉，固定黄色圆点与短横线的落点，避免新增或保存文字后锚点从头顶下移到额头；同时让列表缩略图按图片实际渲染宽度等比缩小锚点标题、圆点与短线。

## 主要内容

- 新增共享 `ImageAnchorMarker` 组件。圆点中心严格位于原图锚点坐标，黄色短横线从圆点中心向右展开；标题位于横线上方，详细描述位于下方。
- 编辑画布和全屏预览改用固定落点。标题换行、描述出现、进入编辑或保存备注均不再参与圆点定位；待输入状态的提示线也使用完全相同的圆点和短线。
- 灵感图列表移除固定 11px 字号和深色文字胶囊，改为黄色圆点、短横线与白色标题；标题、圆点、短线按图片渲染宽度等比缩放，并保留 60% 的可读下限。
- 列表锚点不再因数量超过四个而隐藏文字，标题只显示备注第一行；锚点坐标继续经过旋转、裁切和 `object-fit: cover` 补偿，保持原图位置。
- 中英文文案键集合未变化；未修改文档格式、接口、后端或数据库。

## 验证方式及结果

- `pnpm exec vue-tsc --noEmit`：通过。
- `pnpm test`：41 个测试文件、175 项测试全部通过，其中新增列表锚点视觉比例测试覆盖 420px 基准、缩小、放大、非法尺寸和可读下限。
- 使用真实 `ImageAnchorMarker`、`InspirationThumbnail` 组件和本地生成测试图，在无头 Chromium 的 1200×900 与 390×844 视口检查：编辑态、待输入态和列表缩略图的圆点中心相对锚点坐标误差均小于 0.01px；浏览器无运行时错误。
- `VITE_API_BASE_URL=http://127.0.0.1:8089 PHOTO_NINI_WEB_VERSION=2026.11.24 pnpm build`：通过，转换 4556 个模块；仅保留现有大分块提示。未配置安卓更新签名，构建按既有流程跳过 Android 签名热更新包。
