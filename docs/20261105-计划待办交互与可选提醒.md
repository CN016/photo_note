# 计划待办交互与可选提醒

## 目的与主要内容

计划改为待办列表，默认进入全部列表，保留今天（包含逾期）和已完成筛选。待办按计划时间升序，左侧勾选成功后变灰并添加删除线，移到列表底部，完成记录按完成时间倒序。请求失败保留待办并反馈错误。完成仍不可编辑或撤回，删除继续确认。

新建提醒默认为空，可添加最多三条提前提醒，移除全部提醒后保存即取消提醒。沿用站内消息与已启用 webhook 通知，不提供系统闹钟响铃；计划时间、封面及权限规则沿用现状。

## 接口与兼容

API 版本 4.8.0 → 4.8.1。POST /api/v1/plans 的 reminder_offsets 省略、null 或 [] 表示不提醒；PUT /api/v1/plans/{business_id} 显式 [] 取消提醒，省略保留原设置。响应未配置时返回 []。不迁移或删除历史提醒，旧客户端显式提交 [60] 仍启用提醒。先部署 API 再 Web，旧 API 不支持空数组新语义。无数据库结构或组织隔离策略变更，无新增迁移。
