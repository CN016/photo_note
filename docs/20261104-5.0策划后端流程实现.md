# 5.0 策划后端流程实现

## 目的与内容

在独立工作树中完成拍摄信息、持久化执行状态、自动档期、独立总结文档、作品集关联与文本 AI 生成接口，后端版本保持本批向后兼容的 `4.8.0`。迁移及完整字段说明见 [接口与迁移](20261104-5.0策划接口与迁移.md)。

- 保存事务根据正文和人工总结重新计算状态；旧客户端省略新字段时保留现值。列表分类与完整计数在数据库执行，不读取大文档正文。
- 拍摄信息完整后由保存接口自动处理档期；时间重叠候选需明确选择，也可明确另建。关联和新建均在既有用户事务锁内重新检查，只有本策划创建的单次事项可同步。同步失败不回滚正文保存；解除或删除日历事项不会破坏策划内容。
- 完成总结生成一次独立文档，使用独立修订号保存；来源删除后副本仍保留。作品集侧继续复用既有关联表，双端限定空间及作者。
- 文本 AI 读取私有配置，返回待用户采用的预览，使用请求超时、同策划防重和配置化并发限制。生成不写回策划；不读取媒体节点私有属性。连接限制为公网 HTTPS、固定已校验 DNS 结果，禁止重定向及环境代理，错误不记录密钥、远端正文或完整地址。
- 新增总结表登记租户回调及启动检查，迁移包含中文注释、必要索引与历史状态回填，无外键。Docker 编译默认限制为两个并行任务，复用原 AI 运行时。

## 实际验证

- 在独立、名称以 `_test` 结尾的 PostgreSQL 容器中执行全量迁移和随机 schema 集成测试；没有使用原服务数据库。
- `go test -p 1 -count=1 -json ./...`：156 项通过，3 项跳过。跳过项为需要额外配置的 Redis、计划及档期集成测试；随后设置独立数据库配置，补跑既有计划与档期两项集成测试，均通过。Redis 专项测试未运行；本批未修改认证或 token 存储。
- 新增真实数据库测试覆盖历史状态回填、Unicode 空白、完整状态分页、四类用户空间、旧字段保留、修订冲突、8 个并发副本创建、4 个并发档期重试、候选确认、已有档期不被改写、作品集双向关联、来源删除后副本保留。
- 接口与数据库联合测试验证：保存响应返回前处理自动档期、候选存在时不自动关联、独立文档幂等和修订冲突、非法查询及未认证请求、AI 未配置的安全响应，以及列表不返回正文。
- AI 受控客户端测试覆盖只发送必要文本、预览不回写、未配置、并发限制、旧修订和远端错误脱敏；私网地址检查和拍摄字段校验测试通过。后续小范围调整再次运行受影响 service、HTTP 和数据库测试。

## 交付和限制

本批需要 API 镜像、数据库迁移和配套 Web／Android 热更新资源。最终包、摘要和实际构建结果以根目录本批 `artifacts/` 说明为准；本记录不代表已部署。

真实外部文本 AI 服务未配置，未完成供应商联调或真实计费请求。原主工作区、数据库和运行服务没有修改、迁移或重启。独立总结暂不提供删除接口；回滚旧服务后重新升级需要评估状态回填，不能重复执行建表迁移。
