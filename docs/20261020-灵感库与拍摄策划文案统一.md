# 灵感库与拍摄策划文案统一

## 改动目的

统一 Web 界面中灵感图片集合和拍摄策划功能的中英文名称，让导航、列表、编辑、统计、消息与管理页面使用一致的产品文案。

## 主要内容

- 将中英文界面里的“灵感图”相关名称更新为“灵感库 / Inspiration Library”，并调整图片条目、保存、筛选、统计和消息提示的措辞。
- 将“项目 / Projects”用户可见名称更新为“拍摄策划 / Shoot Plans”，同步调整工作台入口、列表与编辑流程文案。
- 将图片处理 webhook 通知标题改为“灵感库处理通知”，并同步调整通知服务示例载荷。
- 后端版本递增为 `3.0.2`。API 路由、`projects` 语言命名空间和其他接口、数据库、存储标识保持原样。

## 验证方式及结果

- 中英文语言包 JSON 解析与键集合检查通过，共 17 组；语言包用户可见值中未发现“灵感图”“项目”或对应的旧英文名称。
- `pnpm build`：通过，包含 `vue-tsc --noEmit` 与 Vite 生产构建；构建仍提示既有超过 500 KB 的资源块。
- `go build ./...`：通过。
- `git diff --check`：通过。
