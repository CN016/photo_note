# 灵感图长按操作与批量管理

## 改动目的

让单张灵感图详情和灵感图列表都能通过长按完成常用图片操作，并支持在列表内连续勾选多张图片后统一处理。

## 主要内容

- 单张灵感图详情页长按画布时，从底部打开图片操作面板，提供保存图片、复制图片和删除图片。
- 保存图片直接复用现有导出流程，保持导出文件质量、命名和平台保存行为一致。
- 复制图片使用当前详情画布可见结果生成 PNG，不修改原始图片或灵感图文档。
- 删除图片复用当前用户与空间范围，并在离页前阻断已删除图片的自动保存；删除成功后返回灵感图列表，列表会移除失效卡片。
- 桌面右键和触屏长按共用详情操作面板；返回键可以优先关闭该面板。
- 灵感图列表长按菜单新增“管理”。进入管理模式后默认选中当前图片，可以继续点选其他图片，并批量下载、添加到策划或删除。
- 批量下载把所选工作图打包为一个 ZIP；批量添加在一次策划文档保存中写入全部图片，并在修订冲突时重试一次；批量删除逐张执行，失败项保留选中状态。
- 管理模式不允许再次打开单图长按菜单，筛选条件变化、页面停用或退出管理时会清理选择状态。
- 同步补充中英文界面文案和菜单顺序测试。

- `pnpm typecheck`：通过。
- `pnpm test`：48 个测试文件、196 项测试全部通过。
- 中英文 `context-menu` 与 `gallery` 语言包键集合比对：无差异。
- `pnpm build`：生产构建通过，共转换 4564 个模块。
