# 灵感库筛选与图片列表交互

## 改动目的

压缩灵感库手机页面的筛选占用和导航遮挡，提升颜色筛选反馈，并支持图片列表缩放与快速定位。

## 主要内容

- 将图片列表、拍摄统计作为灵感库的页面内切换；收紧页面标签间距，沿用全局底部导航。
- 颜色条件默认折叠，增加当前颜色预览、未选择状态、清除操作和简短提示；亮度标签及数值实时显示。文本搜索入口使用放大镜图标。
- 显示筛选命中数和清除入口；无结果时提供清晰空状态与恢复全部图片操作。
- 手机图片列表底部预留导航空间，将新增按钮上移；缩小列表中的图片标注。
- 支持双指缩放动态调整图片列数，并新增可拖动的纵向列表位置导航。
- 更新图库中英文文案。
