# 灵感图拍摄统计

## 改动目的

在灵感图列表旁新增拍摄统计子页面，帮助用户了解收藏数量、相机与镜头型号及拍摄参数偏好。

## 主要改动

- 新增需鉴权的 `GET /api/v1/inspirations/statistics`，服务端在 PostgreSQL 按 Access Token 对应的用户业务 UUID 聚合，只返回分类计数，不读取图片文件、不返回 GPS 或设备序列号。
- 统计总图片数、含拍摄参数的图片数、最近 12 个 UTC 日历月的收藏数，以及相机型号和镜头型号 TOP 5、焦段、光圈、ISO、曝光时间、闪光灯、画面方向、百万像素和色彩空间。
- 焦段统计优先采用 35mm 等效焦距；缺失属性不参与对应分组。功能复用 `000016_add_inspiration_image_metadata.sql`，不新增数据库迁移。
- 新增响应式统计页面和灵感图列表/统计二级导航；中英文文案分别维护并注册独立的 `statistics` 页面命名空间。
- 后端版本从 `2.6.0` 更新为 `2.7.0`，并在后端 README 记录统计 API 与口径。
