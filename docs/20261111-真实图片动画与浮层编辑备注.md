# 真实图片动画与浮层编辑备注

## 目的与范围

解决图片详情开合只有空白页面外框的问题，简化锚点与编辑调节操作，并支持整图文本备注在列表单行显示。本批仅涉及共享前端，无后端代码、接口或数据库迁移。

## 主要内容

- 列表点击时同步复制已经解码的预览像素，放入原 GSAP 窗口时间线一起展开；详情网络较慢时继续保留预览，真实画布绘制完成后平滑交接。尚未加载出预览的图片使用普通页面进入，不放大空占位框。
- 返回前在 Vue 清空画布之前复制当前详情渲染像素，保留旋转、裁切与色彩的实际结果。中途返回沿用正在展开的预览图，维持当前进度，不跳成完整窗口。普通离开和会话重置均释放快照。
- 快照长边最多1600像素，只在当前页面内存存活，不导出data URL、不持久化或重新上传私有图片。
- 开合统一700ms；中途返回根据当前时间线进度调整timeScale，避免剩余轨迹突然快速收回。仍使用同一条时间线倒放，保留列表缓存和滚动高度保护。
- 标签、锚点大小、色彩/变换及整图备注改用锚定底部按钮的 Element Plus 非模态浮层；属性仍为独立窗口。浮层没有遮罩，调节时直接观察图片效果。
- 点击锚点直接进入编辑和添加模式，同时打开大小调节浮层；可直接点图片填写锚点备注，保存后继续添加。打开其他编辑工具时退出添加模式。锚点文字输入仍使用文本对话框。
- 整图备注保存在既有扩展JSON的 `data.image_note` 中，最多500字符，使用原保存接口，支持撤销与取消编辑，保留其他文档字段。不是图片上绘制的文字图层。旧数据没有备注时不显示额外行。
- 列表图片下只显示新增整图备注一行，超出省略；保留鼠标悬停完整文本。开合起点按图片边框计算，不把备注行算作图片。人数角标移至图片左上，避免覆盖备注。
- 补充详情异步加载的卸载代次检查，迟到解码释放资源；新增editor中英文相同键，沿用既有依赖和核心文档版本。

## 实际验证

- `pnpm typecheck` 通过；最终 `pnpm build` 包含类型检查、Vite构建与安卓签名热更新资源生成，通过。已有大chunk提示仍存在。
- `pnpm test`：27个文件、115项通过，包括4项图片快照生命周期、2项整图备注兼容性与既有5项动画回归。
- `git diff --check` 与 editor/gallery 中英文递归键一致性检查通过。
- Chromium本地合成API/图片：详情下载延迟1.8秒，进入快照像素为[192,205,187,255]，850ms后仍显示预览，详情绘制后清理覆盖层。
- 将合成详情画布的像素设为[208,64,96,255]模拟已渲染结果，返回时动画快照像素完全一致；原画布已被清空为宽度0，快照仍有640像素宽；结束后无残留覆盖层。
- 140ms中断返回约702ms，完整打开后返回约712ms（受帧采样误差影响）；105/109个采样帧全部存在图片、列表滚动始终1300px且复用同一列表节点。
- 锚点直接打开后编辑/添加状态启用，没有模态遮罩，点图片填写锚点并保存成功，添加模式继续保留。
- 整图备注通过既有合成保存接口写入，返回列表内容一致，CSS为nowrap/ellipsis，长文本实际超出容器并单行截断。备注中的内部空格保留。
- 色彩浮层键盘调节红色通道，显示值从0变为1，画布采样像素红色从192变为195，浮层无模态遮罩，真实效果即时变化。

## 交付及限制

需发布业务Web及Android签名Web热更新，最终包与签名清单、README、SHA256SUMS放入本批根目录artifacts时间目录。独立官网、后端、数据库、Android/PC/iOS原生壳及微信小程序未修改，不制造空包。

本地验证使用合成接口/图片，未进行真实后端端到端、线上部署或Android/iOS/PC/微信小程序真机验收。图片未加载成功时无法生成真实预览快照，保留正常的加载/失败反馈与返回入口。整图备注需要点击保存，不是独立自动保存，也不参与服务端搜索。
