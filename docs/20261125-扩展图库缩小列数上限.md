# 扩展图库缩小列数上限

## 改动目的

让持续缩小图片网格时可展示更多列，并将网格切换限制为明确的列数档位。

## 主要内容

- 图片列数只在 1、2、3、4、5、10、15、20、25、30 列之间切换；双指缩放时吸附到最近档位。
- 扩大双指缩放范围，使手机和桌面布局都可到达全部档位。
- 网格超过 5 列时，点击图片先恢复到 5 列，将点选位置附近的五张图片组滚到列表前排并短暂高亮；不把首击推定为精确选中，用户再次点击目标图片后进入详情。
- 列数变化时通过卡片位移动画平滑过渡，遵循系统减少动态效果设置。
