# 安卓相册导出误报修复

## 改动目的

解决 Android 图片已经成功写入相册但网页仍提示“文件导出失败”的问题，并确保最新 Web 的“下载成功”提示和自动返回图片详情真正随可安装 APK 一起交付。

## 主要内容或涉及范围

- MediaStore `IS_PENDING` 最终更新即使返回 0，只要图片输出流已完整关闭并按成功处理，避免部分系统实现的返回值误触发失败。
- Android 9 公共 Pictures 文件完整写入后即视为保存成功；媒体扫描改为异步补充登记，不再因扫描回调迟到、为空或厂商行为差异撤销已保存照片。
- 原生导出先向网页返回成功，再清理临时缓存，保存后的清理不能覆盖成功结果。
- Web 固定扩展桥接保留原生业务错误码，不再把所有异常折叠成无法区分的 `native_failed`。
- Android 壳版本升级为 `1.5.1`、安装版本 `16`，Web 最低壳版本为 `16`；APK 内置最新 Web，安装后无需等待热更新即可使用原图质量导出、成功提示和自动返回。
- 独立官网随本批重新构建，Android 下载页提供 1.5.1 ARM64、ARMv7 安装包。
