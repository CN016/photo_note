# 策划媒体直接鼠标拖动

## 目的与改动

- 移除正文通用拖动柄和媒体工具栏拖动图标；PC 在编辑模式下按住图片或附件并移动超过 5 像素即可拖动，显示预览和落点，松开后在同一父容器内移动。编辑区域外释放取消移动。
- 保留单击选择、双击详情、尺寸控制和前后移动按钮；视频控件和缩放手柄不触发拖动。只读模式不允许拖动。移动端保留媒体块长按拖动，不再显示专用拖动图标。
- 媒体节点移动复用现有文档事务和撤销机制，不改变文档格式及服务端接口。

## 验证及限制

- `npm run typecheck` 及 Web 生产构建结果见交付说明；媒体移动和触摸交互测试 20 项通过。
- 隔离浏览器模拟数据验证图片与 PDF 附件直接鼠标拖动、落点提示、拖到编辑区外取消、撤销、双击图片详情以及只读模式禁止拖动；模拟触摸长按出现拖动预览。
- 未验证真实用户数据及在线部署；Android/iOS 真机长按、缩放和视频控件交互未验证。拖动只能在同一父容器的块之间进行。
