# 5.0 策划状态与复盘基础实现进度

## 本批内容

在隔离工作树中增加服务端策划状态判定、人工总结字段与编辑入口。状态计算只认任务项勾选及任务项内非空文字删除线，普通正文删除线不影响状态；总结与正文使用同一修订号，旧客户端未提交总结字段时保留原值。新增迁移 000027 和启动结构检查。

## 验证及限制

- `go test ./internal/projectstatus ./internal/service` 通过；`go test ./internal/store ./internal/database` 通过，但未配置独立 PostgreSQL 测试库时集成测试会跳过。
- 前端 `vue-tsc --noEmit` 通过。
- 本批仍为 5.0 未完成的开发基础：列表完整分组、拍摄信息、档期关联、总结文档、AI 与作品集联动尚未完成。列表目前由服务端读取正文计算状态，需后续解决大量长文档读取性能及完整状态筛选。
- 未运行独立 PostgreSQL 迁移、浏览器或真机验证；未构建部署包、部署或重启任何服务。禁止将本进度视为可交付的 5.0 版本。
