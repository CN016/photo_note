# 锚点编辑态落点与滚动修正

## 改动目的

修正图片锚点在编辑输入时缺少落点提示、空白编辑点击会继续创建新锚点、软键盘关闭后图片位置上移，以及图片备注占位文案过长和字号偏大的问题。

## 主要内容

- 新增锚点开始编辑时立即显示黄色圆点和短定位线，不再等待保存后才出现。
- 编辑草稿实时解析第一行标题和后续描述；输入标题后，下划线立即切换为与标题同宽的动态下划线。
- 空白草稿的点击遮罩改为在完整点击事件结束后关闭编辑条，并阻止事件透传，避免同一次点击继续在画布上创建新锚点。
- 聚焦锚点输入框时使用 `preventScroll`，并在打开和关闭编辑条时记录、分阶段恢复页面滚动位置，避免软键盘关闭导致图片上移。
- 中文图片备注占位改为“在这里记录布光思路、引导话术、拍摄参数”，英文同步更新；移动端占位字号从 15px 调整为 14px。
