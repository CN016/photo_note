# 取景台品牌与文案更新

## 改动目的

项目正式名称确认为“取景台”，统一更新应用展示名称和围绕品牌的主要文案。

## 主要改动

- 更新中英文界面的品牌名、产品副标题、标语、登录页、工作台与服务状态文案；英文界面沿用中文专名“取景台”。
- 更新浏览器页面标题、Web 文档、第三方许可说明、后端通知内容及图像元数据测试样例。
- 后端版本从 `2.10.0` 更新为 `2.10.1`。
- 为保持既有部署数据和客户端状态可用，数据库名称、容器镜像标签、上传目录、Go 模块路径、浏览器存储键及集成测试环境变量等技术标识继续沿用；既有日期化改动记录保留其历史表述。

## 验证方式与结果

- `pnpm build`（`frontend/apps/web`）：通过；Vite 提示现有 HEIC WASM 分块超过 500 kB，构建成功。
- `go build ./...`（`backend`）：通过。
- 已更新的中英文 JSON 文件均可解析；`common`、`login`、`register`、`workbench` 与 `maintenance` 语言文件的键路径一致。
- 本地浏览器检查登录页中英文切换：品牌名、标语、注册提示和页面标题均按预期显示。

## 尚未验证内容与限制

- 未进行管理工作台和维护页逐页浏览器检查、真实后端通知渠道投递或生产环境验证。
