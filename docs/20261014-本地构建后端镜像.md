# 本地构建后端镜像

## 改动目的

在本机生成适用于 Linux 服务器的 API 镜像归档，避免服务器在线构建时重复下载 Go 基础镜像和模块依赖。

## 主要改动

- 为 Compose API 服务指定 `photo-nini-api:local` 镜像标签，使 `docker load` 导入的镜像可直接供 Compose 使用。
- 将本地导出目录 `backend/dist/` 加入 Git 忽略规则。
- 补充本地构建、导出、服务器导入和启动说明。
- `goproxy.cn` 下载遇到 EOF 后改用 Go 官方模块代理构建成功；默认配置使用 Go 的失败回退分隔符，代理请求失败时继续尝试官方代理和 direct。

## 验证方式及结果

- 本地 `linux/amd64` Buildx 镜像构建成功，镜像使用 `photo-nini-api:local` 标签。
- 构建使用 DaoCloud 代理拉取 Go/Alpine 基础镜像；Go 模块先访问 `goproxy.cn` 时返回 `unexpected EOF`，切换到 Go 官方模块代理后下载及编译成功。
- `docker image inspect` 确认镜像平台为 `linux/amd64`，镜像大小为 40,793,681 字节。
- `docker save` 已生成 `backend/dist/photo-nini-api-linux-amd64-20261014.tar`，文件大小为 41,754,624 字节，SHA-256 为 `87A9176A14898B204C6119E41EB7622ED10CCA47C3E8332126219132D59E4565`。
- `docker compose config --quiet`、构建参数展开和 `git diff --check` 均通过。
