# 本地构建后端镜像

## 改动目的

在本机生成适用于 Linux 服务器的 API 镜像归档，避免服务器在线构建时重复下载 Go 基础镜像和模块依赖。

## 主要改动

- 为 Compose API 服务指定 `photo-nini-api:local` 镜像标签，使 `docker load` 导入的镜像可直接供 Compose 使用。
- 将本地导出目录 `backend/dist/` 加入 Git 忽略规则。
- 补充本地构建、导出、服务器导入和启动说明。

## 验证方式及结果

- 待执行本地 `linux/amd64` 镜像构建、导出及镜像架构检查后填写。

## 尚未验证的内容

- 尚未在目标 Linux 服务器导入归档并启动 Compose 服务。
