# 灵感图锚点交互与全屏缩放优化

## 改动目的

优化灵感库详情页的图片标注体验：减少锚点对图片内容的遮挡，修正新增锚点的落点偏差，允许详情态直接移动锚点，并改善锚点文字输入与图片放大手势。

## 主要内容

- 锚点圆点改为以点击坐标为中心的可聚焦触控按钮，标签独立定位；降低标签、圆点背景和边框的不透明度，保留必要的文字阴影与键盘焦点。
- 新增或编辑锚点不再打开全屏模糊对话框，改为无边框黑色底部遮罩；文字直接输入，右侧仅保留完成按钮。点按图片或按 Escape 可取消，已有锚点清空文字后完成按钮切换为删除。遮罩监听 `visualViewport`，软键盘出现时自动上移到可视区域底部。
- 详情态锚点由只读展示改为可直接拖动；拖动或键盘微调后在原记录上自动保存，编辑态仍遵循统一保存按钮。
- 全屏快照上方同步渲染锚点，使用反向缩放维持锚点的屏幕尺寸，避免图片放大后标签异常变大。
- 全屏层接管新的双指事件；收拢手势连续缩小图片，接近详情原尺寸时退出全屏，未达到阈值则回到全屏基准比例。
- 补充中英文“完成”文案和全屏收拢几何单元测试。

- Chromium `390×844` 移动端视口：新增锚点中心与点击坐标一致；黑色输入遮罩无外框、无输入框边框且无全局遮罩，模拟 `visualViewport` 收缩后位于键盘区域上方；点按图片会取消未提交输入；详情态拖动后写入 PATCH；全屏锚点正常显示；双指收拢在阈值前保持全屏、达到阈值后回到详情。
