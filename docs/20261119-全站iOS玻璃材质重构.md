# 全站 iOS 玻璃材质重构

## 改动目的

为取景台业务 Web 和独立官网建立统一的 iOS 风格光亮玻璃材质，让导航、卡片、表单、列表、表格、弹层、工作台与公开页面共享一致的通透表面、柔和环境光、内高光边缘和背景高斯模糊；同时保留业务状态色、图片内容、Canvas 像素和用户文档的原始呈现。

## 主要改动

- 新增 `frontend/apps/web/src/glass.css`，在现有基础主题之后加载，集中维护浅色和深色玻璃材质令牌、页面环境光、表面层级、描边、阴影、模糊半径和触控反馈。
- 桌面侧栏改为圆角悬浮玻璃岛，导航选中项使用内高光和强调色侧边；移动端底部导航改为安全区内的悬浮胶囊。
- 桌面右上角消息入口保持为独立圆形操作，不再为整条定位层绘制直角玻璃背景；侧栏底部主题与语言偏好改为内缩的圆角玻璃卡，避免压住侧栏圆角和出现越界边框。
- 修正 769px 附近仍按 226px 旧侧栏宽度计算的内容边距；创意拼图、计划、档期和项目编辑器与悬浮侧栏统一保留 20px 间距，不产生压边或裁切。
- 工作台、灵感库、作品集、项目、总结、计划、收支、档期、消息、账户、空间、组织、管理工作台、交付、拼贴、项目编辑器、上传页、公开预约和公开作品集使用统一半透明面板。
- 按钮、输入框、选择器、分段控件、标签、表格、分页、下拉菜单、对话框、消息框、抽屉和上下文菜单统一玻璃边缘、圆角和焦点反馈。
- 保留 Element Plus 组件及现有图标体系，没有新增运行时依赖；没有修改 API、权限、路由、数据模型、国际化键或后端版本。
- 图片缩略图、编辑器画布和导出内容不被滤镜覆盖，只对外框、背景和工具面板应用材质。
- 新增不支持 `backdrop-filter` 时的高不透明度降级，并处理 `prefers-reduced-transparency` 和 `prefers-reduced-motion`。
- 新增 `website/src/glass.css`，让官网首页与下载页复用相同视觉语言，同时保留独立官网的摄影画册排版和真实构建入口。

- `frontend/apps/web`：`pnpm typecheck` 通过；`pnpm test` 通过，31 个测试文件、132 项测试全部通过。
- `website`：`pnpm build` 通过，包含 Vue 类型检查、中英文键集合检查和配置检查。
- 使用 Vite 开发服务、合成 API 与合成图片，在 1440×1000 和 390×844 视口检查以下路由：工作台、灵感库、拍摄统计、作品集、拍摄策划、总结汇总、计划、收支账本、档期管理、消息中心、个人中心、空间、组织、管理工作台、组织图库管理和创意拼图。
- 额外检查交付列表与详情、灵感图新增与详情、作品集详情、项目编辑、总结编辑、公开预约、公开作品集和官网首页/下载页。上述主路由均未出现横向溢出；移动底栏圆角为 24px，路由页面背景层透明。
- 浅色主题和深色主题均完成截图检查；消息页深色模式玻璃卡片、边框和文字可读性正常。
- 打开 Webhook 渠道新增弹层，确认对话框为 `blur(32px) saturate(1.8)`，遮罩为 `blur(14px) saturate(1.3)`。
- `agent-browser a11y --tags wcag2a,wcag2aa`：业务工作台、消息中心深色模式和官网下载页均返回 0 项违规。
- `git diff --check`：执行提交前检查。

## 尚未验证及已知限制

- 浏览器验证使用 Chromium 和合成数据，不代表真实图片数量、超大项目文档、生产网络或长列表滚动下的低端设备帧率。
- 未在 iOS Safari、Android GeckoView 真机、PC 原生壳及微信小程序容器中验证高斯模糊、透明度和内存占用。
- 不支持背景模糊的浏览器会使用提高不透明度的静态玻璃降级，视觉效果会弱于 Chromium/Safari 的系统模糊。
- 本批仅修改业务 Web 与独立官网前端，不涉及后端、数据库迁移、Android APK 原生代码或原生签名。
