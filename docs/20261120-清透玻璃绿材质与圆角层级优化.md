# 清透玻璃绿材质与圆角层级优化

## 改动目的

将上一版偏深的鼠尾草主题调整为清透、低饱和但不发灰的淡玻璃绿，使用暖奶雾白承载内容叠层。同时增强透明玻璃的材质辨识度，清理方形底板与圆角控件叠加造成的视觉冲突。

## 主要内容

- 页面背景改为淡绿透光与暖奶白叠加的多层渐变，并增加低对比环境光斑，让玻璃层后的背景变化可被感知。
- 玻璃表面改为无色高透明材质，保留轻微暖白填充、顶部聚光、斜向反光、白色双边缘和极细 SVG 磨砂噪点；卡片、导航、输入框、弹层与面板共享同一材质，不再给框体添加绿色染色。
- 主操作色调整为更深一阶的海玻璃绿，保证浅色玻璃上的文字与控件对比度。
- 桌面图库搜索和筛选收进一个 20px 圆角玻璃面板；内部筛选区不再重复绘制底板。
- 移动端搜索框和筛选按钮独立排布，展开后的筛选区保持单独圆角玻璃面板。
- 图库卡片悬浮阴影只作用于圆角图片框，不再在整张方形文章容器上投射阴影；焦点轮廓也限定到圆角图片框。
- 将圆形“人数显示”按钮和抽屉偏好容器统一为明确的圆角控件，避免圆形、圆角和直角混杂。
