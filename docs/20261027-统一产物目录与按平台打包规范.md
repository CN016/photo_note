# 统一产物目录与按平台打包规范

## 目的与内容

按用户要求，将最终产物集中到根目录 `artifacts/`；每批修改按北京时间日期与时间新建 `YYYYMMDD-HHmmss/` 目录，涉及需要发布的平台均须提供本次最新部署压缩包。

规范补充在现有根目录 `AGENTS.md`，不另建含义重复的 `agent.md`。明确业务Web、安卓签名页面更新、原生安装包、独立官网及后端Docker镜像的发布范围；要求提供部署说明、版本/提交信息、SHA-256、迁移与验证边界，禁止用旧包改名或遗漏受影响平台。

新增根目录 `artifacts/README.md`，并在 `.gitignore` 忽略各批次目录及大体积产物，仅保留公共说明。已有模块中间输出、历史部署包不移动或清理。本批仅修改规范、目录说明和忽略规则，不涉及运行平台发布，创建文档批次交付目录说明，不生成空压缩包。

## 验证及限制

执行 `git diff --check`、检查Git忽略规则及时间目录命名；核对本批无平台需要发布。未修改业务代码、后端构建配置或数据库，不运行应用构建与业务测试、不递增后端版本。现有构建脚本仍输出到原模块目录，本批新增的是必须遵守的交付规范，未改造脚本自动汇总产物。实际交付包需在后续功能修改批次按规范生成并验证。
