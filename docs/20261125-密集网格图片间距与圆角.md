# 密集网格图片间距与圆角

## 改动目的

在灵感库图片列数超过五列时增加缩略图的有效显示面积。

## 主要内容

- 密集网格取消图片卡片之间的间距。
- 密集网格缩略图取消圆角；五列及以下仍保留原有间距和圆角。
- 网格密度切换继续沿用卡片移动过渡动画。

- `npm run build`：通过，Android Web 签名热更新资源已生成，发布号 `1795615291757`。
- `git diff --check`：通过。
