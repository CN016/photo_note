# 图片备注下划线与编辑交互优化

## 改动目的

修正灵感图详情中图片备注锚点的空白草稿、黄色下划线宽度和上下间距，并缩小编辑输入条及操作按钮。同时统一业务 Web 的字体栈，避免使用方正字体或来源不明的商业字体。

## 主要内容

- 新增锚点空内容判断；新建草稿未输入有效文字或仅输入空格时不显示黄色落点。
- 新建空白草稿点击“完成”会直接关闭；已有锚点继续保留显式删除入口，避免清空文字时误删。
- 编辑输入条增加全屏透明关闭层，点击输入条以外任意位置会退出当前编辑。
- 黄色下划线改由标题元素自身绘制，宽度与标题内容一致，并贴近标题底部；标题下方描述同步上移。
- 缩略图、详情画布和全屏查看层统一使用相同的动态下划线规则。
- 编辑输入字号由 17px 调整为 15px；“完成”和“删除”按钮的高度、字号、内边距和圆角同步收紧。
- 业务 Web 字体栈统一为 Noto Sans SC、思源黑体及系统字体回退，未引入方正字体或外部商业字体文件；水印预览和导出测量复用相同字体栈。

- 使用随桌面运行环境提供的 Node `v24.22.3` 执行 `pnpm test`：41 个测试文件、176 个测试全部通过。

- 检查生产 CSS，确认包含动态标题下划线、空白草稿关闭层和缩小后的编辑按钮样式。

- 未连接生产后端进行登录后的手工触屏回归；空白草稿、下划线宽度、间距和点击外部关闭已完成代码级与单元测试验证，仍建议在 Android 真机及 iOS Safari 上复核输入法弹起和视觉间距。
