# 移除文件导出误报弹窗

## 改动目的

修复文件已经保存、或当前没有导出动作时仍弹出“文件导出失败，请重试”的问题。

## 原因与范围

- 旧全局导出入口把所有未知错误都映射为通用“文件导出失败”提示。
- `export_busy`、页面切换后的迟到回包、原生桥接异常和读取竞态均可能落入该分支，不能据此证明文件没有保存。
- 现在只有文件超过平台限制或相册权限被明确拒绝时显示可操作错误。
- `export_busy`、`export_read_failed`、`export_failed`、超时等未知或竞态错误不再弹出通用失败提示，也不会被页面误判为保存失败。

## 涉及文件

- `frontend/apps/web/src/platform.ts`
- `frontend/apps/web/src/fileExportFeedback.ts`、`fileExportFeedback.test.ts`

## 验证方式及结果

- Web `pnpm typecheck`：通过。
- Web `pnpm test`：47 个测试文件、194 项测试通过。
- 新增测试确认仅“文件过大”和“相册权限拒绝”生成错误提示，忙碌、读取失败、未知导出错误和超时均不显示通用弹窗。

## 尚未验证

- 未在 Android 真机复现导出中途切页、系统权限弹窗和原生迟到回包组合场景。
