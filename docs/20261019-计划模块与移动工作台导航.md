# 计划模块与移动工作台导航

## 改动目的

新增单次计划管理和持久化提醒；调整移动端主导航以适配窄屏，并提供集中访问功能的工作台。消息中心在桌面和移动端统一放到全局右上角。

## 主要内容

- 新增 `/plans` 计划页、计划和提醒任务表、API、封面配置及每分钟提醒 worker。提醒通知复用现有站内消息与 webhook outbox。
- 计划页支持今天、逾期、本周、本年、其他和已完成分组；支持描述、emoji 或图片封面、最多三条提醒、完成和删除。
- 新增移动工作台，列出灵感图、收支、档期、计划、消息中心和个人中心；管理员可见管理工作台。
- 移动底栏固定显示“工作台、灵感图、收支、我的”。登录后移动端默认进入工作台，桌面端继续进入灵感图。
- 更新中英文页面语言资源、消息通知文案、`backend-design-v1.md` 和后端版本至 `2.9.0`。

## 验证方式与结果

- `go test -p 1 ./...`（`backend/`）：通过。
- 在临时 PostgreSQL 17 容器中按顺序应用 `backend/migrations/000001` 至 `000018`，迁移全部成功；`go test -p 1 ./internal/store -run TestPlanReminderPersistenceIsolationAndConcurrentDelivery -count=1 -v` 通过，覆盖用户隔离、已开始计划取消提醒、计划时间与提醒重排、完成后取消、16 个并发 worker 只创建一条站内消息及每个启用 webhook 各一条 outbox。
- `npm test -- --run`（`frontend/apps/web/`）：通过，6 个测试文件、21 项测试。
- `npm run build`（`frontend/apps/web/`）：通过；Vite 提示现有大于 500 kB 的 chunk，构建成功。
- `git diff --check`：通过。
- 浏览器使用模拟 API 数据检查 375、768、1024、1440 px：文档和 body 宽度均未超过视口；移动底栏为四项；工作台菜单可见；消息中心在全局右上角。
- 浏览器检查已登录状态进入登录路由后的默认落点：375 px 为 `/workbench`，1440 px 为 `/inspirations`。计划页的逾期/今天/本周/本年/其他/已完成样例分组显示正常；375 px 新建对话框的底部操作按钮位于视口内。
- `plans` 与 `workbench` 中英文 JSON 的递归键集合一致。
- 计划封面 service 单元用例覆盖有效 PNG、公共 storekey 拒绝、错误图片内容拒绝，以及当前公开 emoji 配置校验。

- 浏览器使用模拟 API 数据；未连接真实账号、文件存储、通知渠道或生产服务。
- PostgreSQL 验收使用临时 PostgreSQL 17 容器完成，未连接项目现有数据库；数据库服务不可用后的自动恢复仍未做故障注入验证。
- 图片通过 service 单元用例验证了服务端内容校验，真实浏览器上传链路未端到端验证。
- 本次只验证共享 Web 桌面与移动视口；Android、iOS 和微信小程序壳未验证。
- 按现有文件存储规范，替换或弃用的封面可能留下未引用文件。
