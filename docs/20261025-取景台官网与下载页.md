# 取景台官网与下载页

## 改动目的

新增独立官网，介绍取景台摄影工作台的现有能力，集中呈现 Web 访问入口及客户端发布状态。

## 主要内容

- 新增 website/ Vue 3、TypeScript、Vite 静态多页工程：首页与 /download/。包含产品演示、六项功能、使用流程、FAQ、下载平台状态及中英文切换。
- 使用淡蓝白布局、本地 CSS 场景和 Element Plus 图标，不使用用户图片或外部图像服务。产品展示明确标为演示。
- Web 地址和正式域名采用公开构建配置；发布项提供类型、版本、架构及地址校验。未配置入口、未发布平台不产生虚假链接。
- 新增官网 AGENTS.md、README、设计维护说明及许可文件；更新根规范的目录和国际化职责，忽略构建产物及本地环境文件。
- 不涉及后端、数据库和业务 Web 应用代码；不部署上线。

- `pnpm install --frozen-lockfile`：通过，显式允许构建依赖 esbuild 的安装脚本。
- `pnpm build`：通过，包含 vue-tsc 类型检查、中英文命名空间同键检查、配置边界检查和生产构建。
- 配置检查覆盖空地址、HTTP/脚本协议/带凭据地址拒绝、有效 Web 地址、完整发布条目及缺少版本/架构的条目。
- 本地 Chromium 检查：首页与下载页可访问，下载页刷新成功；首页中英切换、下载页偏好延续和切回中文成功；手机菜单可展开，键盘 Tab 可聚焦链接。
