# 图库默认四列调整

## 改动目的

按最新反馈，将灵感图列表进入时的默认列数从五列调整为四列。

## 主要内容

- 图库默认列数和窗口基准列数统一改为 4 列。
- 列数吸附步骤、非法缩放参数回退值及 CSS 初始列数同步改为 4。
- 缩略图 3px 小圆角、移动端 4px/桌面 6px 间距保持不变。

## 涉及文件

- `frontend/apps/web/src/views/galleryGridLayout.ts`、`galleryGridLayout.test.ts`
- `frontend/apps/web/src/views/GalleryPage.vue`

## 验证方式及结果

- Web `pnpm typecheck`：通过。
- Web `pnpm test`：47 个测试文件、194 项测试通过。
- 图库布局测试确认默认列数和非法缩放回退值均为 4。

## 尚未验证

- 未连接移动真机检查四列在不同屏幕宽度和设备像素比下的最终观感。
