# LightNote 图标居中与全平台打包

## 改动目的

修正 LightNote 图标中 `L` 与小写 `n` 组合视觉不居中的问题，并移除图片内部预先制作的圆角、边框和外边距。图标母版保持满幅直角矩形，实际圆角由 Web CSS 或 Android Launcher 掩膜决定。

## 主要内容

- 按字形真实边界将 `Ln` 整体水平右移 27 单位、垂直下移 72 单位，使组合中心与 1024 × 1024 画布中心重合。
- Android、业务 Web 和官网共用同一份满幅矩形矢量母版，背景 `#001D34`，文字 `#2FA3F7`。
- Web 和官网继续通过 CSS 圆角裁切；Android Adaptive Icon 由 Launcher 掩膜，旧版方形入口保持满幅，圆形入口在资源生成阶段裁圆。
- Android 版本更新为 `1.4.2` / `versionCode 13`，Web 版本更新为 `5.1.1`。

## 验证方式及结果

- 重新生成业务 Web、官网 180/192/512 图标和 Android 全密度、自适应、单色、圆形及启动屏资源。
- 检查母版与 Android 方形资源无外边距、无预烘焙圆角；512px 母版蓝色字形边界为 `(74,141)-(438,371)`，中心精确为 `(256,256)`。四角与四边像素均为 `#001D34`。
- 重新构建业务 Web、官网、Android APK 和 Android Web 热更新资源。
- 已通过 Web 36 个测试文件、150 项测试、TypeScript 与生产构建，Android `assembleDebug`、`lintDebug`，以及官网类型检查、国际化、配置和生产构建。
- 后端运行时代码未改动，复用现有 `4.12.1` 镜像；最终交付前校验压缩包完整性和 SHA-256。
