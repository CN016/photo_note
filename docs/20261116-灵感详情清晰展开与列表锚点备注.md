# 灵感详情清晰展开与列表锚点备注

## 目的与内容
- 查阅20261111真实图片动画记录，将列表缩略图展开改为等待详情工作图下载、解码并应用旋转、裁切及颜色调整后，以详情像素执行既有700ms开合动画。
- 点击后在对应图片位置显示加载遮层，重复点击同图不会重复提交；失败保留列表并通过既有本地化错误入口重试。组织或会话变化、离开页面和新点击以代次检查阻止迟到导航；临时画布在完成和失败时释放。
- 预加载完成时重新读取卡片坐标，避免等待期间滚动造成来源错位。保留修饰键新标签页行为及系统减弱动态设置。
- 列表继续显示已有整图备注，并增加按文档顺序编号的锚点备注；无备注不显示额外内容，文本采用Vue插值，不解析HTML。复用已有中英文加载和错误文案，无新增语言键。
- 不涉及后端、接口、数据库或原生桥接。

## 发布及限制
- 本批发布业务Web和Android签名Web热更新，统一产物目录包含部署ZIP、Android更新资源及签名清单、README和SHA256SUMS。不涉及独立官网、后端、PC/iOS/Android原生壳及微信小程序安装分发。
- 未执行浏览器视觉验收、真实后端端到端、移动设备与PC壳真机验收或线上部署。详情页面仍通过原有鉴权流程重新读取记录及工作图，预加载像素仅用于动画；网络失败时保留原有详情错误反馈。快照长边沿用1600像素上限，不持久化私有图片。
