# 灵感详情 Genie 漏斗开合

## 改动目的
图片详情开合改用 macOS Genie Effect 风格的弯曲漏斗，绑定实际来源图片，保留详情预加载、完整图片比例和同路径返回。

## 实现与范围
- 核验 GSAP Flip 官方文档及 MIT 开源 BCGenieEffect 源码。Flip 提供矩形定位与缩放，不直接提供 Genie 曲面；参考 BCGenieEffect 的两阶段算法，以 0–40% 收窄贝塞尔边界、30–100% 沿曲线滑入目标，打开时反向执行。
- WebGL 将临时详情图片与页面底色纹理绘制为 8×96 连续网格，单次 drawCall；没有增加 npm 依赖。保留上游许可与来源。
- 根据来源框在屏幕上方或下方选择漏斗方向；虚拟滑道解决卡片与详情重叠导致的曲线翻折。起点使用详情预加载完成时重新读取的真实图片框，并保存对应列表滚动位置。
- 开合共用原有 700ms GSAP 时间线和同一进度；中途返回只倒放，收回途中再次进入恢复正常播放速度。来源列表保留至开合结束，目标框处末段淡交接，避免详情留白硬切到列表裁图。
- 详情图保持 contain，进入和返回仍按同一真实画布边界；底部菜单与右划抽屉不变。
- 纹理及输出长边不超过 1600 像素，输出比例不超过 1.5；仅导航期间使用，不保存、不导出、不传输用户像素，结束和会话切换时释放 GPU 资源。
- GPU 不可用、上下文丢失或动画中窗口尺寸变化时恢复 DOM 与原有可逆 Flip，不阻断详情访问。系统减弱动态效果继续跳过共享动画。

## 验证与结果
- 几何测试覆盖：真实开合端点、上下方和部分超出屏幕的卡片、重叠目标下的有限坐标与不翻折、非线性曲边、正反向同进度一致与口部连续。
- 来源捕获测试覆盖左上、右下和预加载期间位置改变，确认不是固定屏幕起点；无详情像素时不生成占位起点。
- Chromium 浏览器使用真实导航、图片交接与 WebGL 模块，配合 1200×800 合成图片、390×844 视口。左上来源 (18,110) 与右下来源 (207,610) 呈不同漏斗方向。
- 左上来源正倒放同进度截图像素一致；右下截图每通道最大差异 1 色阶，平均差异小于 0.00003。完整展开画布为 x=25/y=300/340×226.656，沿用完整图片比例。
- 浏览器检查完成后返回、中途返回、会话清理均无残留网格；模拟上下文丢失后 DOM 透明度恢复；模拟无 WebGL 时返回 false 并保留原 DOM。
- `pnpm.cmd --dir frontend/apps/web test`：30 个文件、127 项测试通过。
- `git diff --check`：通过。`pnpm.cmd --dir frontend/apps/web build`：vue-tsc、Vite 生产构建及 Android 热更新签名自检通过；保留已有大 chunk 提示。交付包完整性结果见本批交付说明。

## 发布与限制
发布业务 Web 和 Android 签名 Web 热更新；不涉及 API、数据库、官网、原生壳及微信小程序分发包。
参考开源算法实现 macOS 风格，不宣称与苹果闭源窗口合成器逐像素等价。变形纹理包含图片与底色，不抓取按钮、输入框等整个 DOM；真实控件在结束时交接。卡片位于屏幕内部时使用本项目的重叠目标适配，而不是 macOS 固定 Dock 布局。
未完成 Android/iOS/PC 壳或微信小程序真机、真实后端端到端及低端移动 GPU 性能验证。GPU 不可用时采用普通开合。仅构建打包，未上传、部署或线上验收。
