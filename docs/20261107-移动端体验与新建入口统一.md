# 移动端体验与新建入口统一

## 改动目的

- 按移动端“内容优先、操作精简”的原则重整业务 Web 的导航、列表页、筛选与新建流程。
- 安装并参考 `Leonxlnx/taste-skill`，并遵循项目既有 Element Plus、多语言、无障碍和跨平台规范。
- 解决顶部工具与按钮过多、搜索与筛选占用首屏、说明性文字重复、底部导航过载以及新建入口分散的问题。

## 主要内容

- 移动端顶部工具收敛为一个“更多”入口，消息、语言和主题在同一面板内；桌面端主导航按“创作与交付、日程与记录、管理”分组，并补齐工作台和消息入口。
- 移动端底部导航由 6 项减为 5 项；账本归入工作台区域，顶部不再同时展示主题、语言、反馈和消息四组按钮。
- 新增统一 `CreateFab`：灵感库、计划、档期、拍摄策划、作品集、账本、组织管理、配置中心、Webhook 渠道和交付任务均使用右下角 `+` 新建；页头与空状态不再重复放新建按钮。
- 反馈入口移入“我的”页面；登录和公开页继续保留无账号场景下的反馈兜底入口。
- 灵感库先显示搜索和筛选，再显示图片内容；“存图目标与筛选”降至列表底部。账本默认只显示搜索框和一个更多筛选按钮，其余筛选项按需展开。
- 作品集搜索与标签筛选合并为单行；拍摄策划状态筛选改为单行横向滚动；组织搜索在手机上使用输入框回车提交。
- 移动端隐藏常驻 eyebrow、页面说明和重复空状态解释，工作台卡片不再展示逐项说明；桌面端保留必要标题层级。
- 增加全站跳到主要内容链接、路由标题播报、当前栏目语义、统一主内容 ID、按钮与表单可访问名称、表格列标题和触控焦点。
- 修正移动端拍摄策划新建图标、作品集与公开作品集标签语义、个人中心头像上传嵌套交互、日历对比度与少量错误色对比度。

## 涉及范围

- `frontend/apps/web/src/components/`：全局壳、反馈、顶部工具、交付工作台、灵感工具和新增 `CreateFab`。
- `frontend/apps/web/src/views/`：登录、注册、工作台、灵感库、统计、账本、档期、计划、策划、作品集、消息、个人中心、组织、管理台、交付及公开页面。
- `frontend/apps/web/src/i18n/`：公共、灵感库、账本、计划、作品集和个人中心中英文资源。
- 未修改后端代码、接口、数据库迁移或后端版本。

## 验证方式及结果

- `npm run typecheck`：通过。
- `npm test -- --run`：23 个测试文件、98 项测试通过。
- 中英文 i18n 键集合比对：通过。
- 使用本地 Vite 开发服务与模拟 API 数据，在 390×844 视口检查 17 个业务及公开路由：axe 可访问性违规均为 0。
- 在 320×700 视口检查上述 17 个路由：无横向溢出；右下角新建按钮保持在底部导航上方或独立页安全区域内。
- `npm run build`：生产构建通过，Web 发布号 `1794000001000`；已生成签名 Android Web 热更新资源 `web-1794000001000.zip`。
- 实际点击验证：计划 `+` 打开新建弹窗、灵感库 `+` 进入新增页、顶部更多菜单可打开、个人中心反馈按钮可打开反馈抽屉。
- 登录与注册页在同步调整 H1 层级后通过 axe 可访问性检查。

## 尚未验证的内容或已知限制

- 浏览器检查使用模拟业务接口与本地静态数据，未连接真实账号、生产后端或真实图库/账本数据。
- 未在 Android 真机、iOS、微信小程序或低端设备上复测键盘、触控、长列表和内存表现。
- 未执行线上部署、服务器验收或真实 webhook 投递。
- 本批为共享 Web 改动，需重新构建业务 Web 与 Android Web 热更新资源；原生壳版本不变。
