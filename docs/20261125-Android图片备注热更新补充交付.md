# Android 图片备注热更新补充交付

## 改动目的

使用用户提供的 Web 更新签名私钥，补齐上一批图片备注交互修正所影响的 Android 签名热更新资源。

## 主要内容

- 将私钥保存到业务 Web 构建脚本默认读取的仓库外目录 `%USERPROFILE%\.photo-nini\keys\web-update-private.pem`。
- 将私钥文件访问权限限制为当前 Windows 用户，未将私钥写入 Git、Web 部署包或 Android 更新包。
- 使用 RSA-SHA256 重新生成发布号 `1795578481905`、显示版本 `2026.11.25-r1` 的 Android 热更新包、签名清单和版本记录。
- 将完整 `android-updates/` 纳入本批业务 Web ZIP，并在交付目录单独保留一套可核验资源。

## 验证方式及结果

- 私钥为 RSA 3072 位，与 `frontend/apps/android/assets/web-update-public.pem` 公钥匹配。
- `latest.json` 的 RSA-SHA256 签名验证通过。
- 热更新包实际为 19,688,741 字节，SHA-256 为 `91f9f7c35a6ea4015489c3780dd3fb83fa6ffe6f62911da772d597e481a3a2f1`，与签名载荷一致。
- 签名载荷包含 439 个文件，更新 ZIP 入口和全部文件流完整性读取通过。
- 完整 Web ZIP 包含 443 个文件和 3 个目录条目，已确认包含 `index.html`、`web-release.json` 和完整 `android-updates/`，完整性检查通过。

## 尚未验证或已知限制

- 尚未上传生产服务器，未验证线上 HTTPS、清单缓存、更新下载和回退流程。
- 未在 Android 真机完成本轮热更新的下载、验签、启停和页面验收。
- 本批未修改 Android 原生壳、后端、官网、PC、iOS 或微信小程序代码。
