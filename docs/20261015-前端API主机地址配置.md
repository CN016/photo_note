# 前端 API 主机地址配置

## 改动目的

将 `VITE_API_BASE_URL` 明确为后端服务主机地址，使环境配置只决定服务部署位置，API 版本路径由前端代码维护。

## 主要内容

- `VITE_API_BASE_URL` 仅接受带 `http://` 或 `https://` 的主机源，可包含端口，不允许包含 `/api/v1` 等路径、查询参数或片段。
- Web API 客户端在代码中拼接 `/api/v1`；健康检查请求同一主机根路径下的 `/healthz`。
- 开发环境通过 Vite 代理请求 `/api/v1` 和 `/healthz`，代理目标默认复用 `VITE_API_BASE_URL`；`VITE_DEV_API_PROXY_TARGET` 可选用于单独覆盖目标。
- 更新 `.env.example`、前端 README 和本地 `.env` 的地址格式；本地 `.env` 已加入忽略规则，不纳入提交。
- 本记录描述当前配置约定；一期实现记录保留当时的配置说明，不回写历史内容。

## 验证方式及结果

- 使用本地 host 级 `.env` 执行 `pnpm build`，`vue-tsc --noEmit` 与 Vite 生产构建均通过。
- 构建提示 HEIC WASM 相关分块超过 500 kB；构建成功，本次未调整分包策略。
