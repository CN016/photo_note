# 调整图库缩放列数与侧边进度条

## 改动目的

反转图片缩放手势与网格列数的对应关系，并修复右侧列表导航拖动和按住反馈。

## 主要内容

- 双指放大时减少图片列数，双指缩小时增加图片列数。
- 右侧导航滑块根据整个页面的滚动比例实时定位，拖动时滚动页面并同步滑块。
- 按住导航时放大轨道和滑块，释放后延迟恢复。
