# Android 锚点热更新补充交付

## 改动目的

在已有业务 Web 交付基础上补充本轮锚点修正的 Android 签名 Web 热更新资源。重新打包时使用与 APK 内置公钥匹配的外部私钥，生成新的、单调递增的发布号，避免继续使用不含 Android 更新的旧 Web 包。

## 主要内容

- 用户提供的 RSA 3072 位私钥移动到仓库外的用户私有目录，作为本机默认更新签名私钥；私钥内容、路径文件均不进入 Git、业务 Web 包或 Android 更新资源包。
- 以 `https://photo.016imcn.love` 为生产 API 主机，构建新的业务 Web 版本 `2026.11.24-r2`，发布号为 `1795528010602`。
- Android 更新清单地址为 `https://photo.016imcn.love/android-updates/latest.json`，最低壳版本保持 11。
- 完整业务 Web ZIP 内含 `android-updates/`，交付目录同时单独保留更新 ZIP、SHA-256、签名清单和版本记录。
- 未修改前端业务代码、Android 原生壳、后端接口或数据库。

## 验证方式及结果

- 使用 Node.js 读取外部私钥和 `frontend/apps/android/assets/web-update-public.pem`，确认私钥为 RSA 3072 位且公钥完全匹配。
- `pnpm build` 通过，转换 4556 个模块，并成功生成 `web-1795528010602.zip`。
- 解码 `latest.json` 后使用 APK 内置公钥执行 RSA-SHA256 验签：通过。
- 发布载荷中的 API 主机、更新 URL、发布号、显示版本和最低壳版本均正确。
- Android 更新 ZIP 大小和 SHA-256 与签名载荷一致，文件清单共 439 项并包含 `index.html`。
- 完整业务 Web ZIP 共 443 项，逐项读取完整性检查通过，确认包含 Android 更新包和签名清单。

## 尚未验证的内容或已知限制

- 尚未上传生产服务器，未验证线上静态目录权限、HTTPS、缓存控制、清单原子替换和 CDN 刷新。
- 尚未在 Android 真机执行更新下载、验签、本次启动启用和异常回退流程。
- 本批没有原生壳改动，因此没有新增 APK；Android 1.4.0 及以上可接受该热更新，旧壳仍需先安装新版 APK。
