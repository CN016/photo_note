# 灵感图导出锚点合成与相册直存

## 改动目的

导出灵感图时保留当前可见的锚点标注，并把结果作为一张新照片直接保存到 Android 系统相册，不再要求用户自行选择文件夹。

## 主要内容或涉及范围

- 共享 Web 导出画布在完成旋转、裁切和 RGB 调整后，继续绘制当前可见锚点，包括黄色落点、标题下划线、标题和详细描述。锚点位置复用编辑核心的旋转/裁切坐标映射，文字按导出宽度和当前锚点显示比例缩放。
- 生成图片仍使用当前文件名语义，普通导出追加 `-export`，水印导出追加 `-watermark`；锚点只写入导出图片，不改写原图、缩略图或项目文档中的锚点数据。
- Android 图片 MIME 导出改为直接写入系统相册 `Pictures/LightNote`，同名文件自动追加序号，确保每次导出都是新照片。Android 10 及以上使用 MediaStore 分区存储；Android 9 仅在公共 Pictures 写入时申请 `WRITE_EXTERNAL_STORAGE`。
- 非图片文件继续使用原有“保存/分享”菜单与 SAF 文件保存，避免扩大文件导出的行为变更。相册写入完成后页面提示“照片已保存到相册”，权限拒绝使用独立的中英文错误文案。
- Android 壳版本升级为 `1.5.0`、安装版本 `15`，Web 最低壳版本同步为 `15`；旧安装包必须覆盖升级才能获得相册直存能力。

## 验证方式及结果

- Web `pnpm typecheck`：通过。
- Web `pnpm test`：42 个测试文件、179 项测试通过；新增测试覆盖锚点导出字号换算、逐字换行、标题/下划线/落点/描述绘制。
- 生产 Web 构建：`pnpm build` 通过，转换 4558 个模块。构建后处理因当前 PATH 无 Python 首次失败，使用项目支持的 `PHOTO_NINI_PYTHON` 指定本机 Python 3.14 后成功生成 Android 签名 Web 更新包。
- Android 签名 Web 更新：发布号 `1795675025556`、版本 `2026.11.26-r1`、`minShellCode=15`；RSA-SHA256 验签通过，ZIP 长度和 SHA-256 与签名载荷一致。
- Android Java 主代码与 instrumentation 测试代码：使用 JDK 21、Gradle 9.5.0、AGP 9.3.1 编译通过。
- Android `assembleDebug` 与 `lintDebug`：通过，Lint 为 0 个错误、8 个既有警告；三个 ABI 的调试 APK 均已生成。
- 新增仪器测试会验证图片导出不弹保存面板，并可通过 MediaStore 查询到新照片；当前 `adb devices` 无连接设备，未执行仪器测试运行验收。

## 尚未验证的内容或已知限制

- 当前环境没有连接 Android 模拟器或真机，不能宣称相册 UI、厂商图库索引、权限弹窗和实际照片内容已完成运行验收；需要在 Android 9 与较新系统分别检查。
- 当前环境没有正式 APK 签名材料，只能交付调试签名 APK。若设备已安装正式签名包，调试包不能覆盖升级，需使用正式签名材料重新构建 1.5.0 包后再安装。
- iOS、微信小程序、PC 壳未修改；普通浏览器仍遵循浏览器下载能力，无法绕过浏览器策略直接写入系统相册。
- 导出仍使用当前最长边 1800 像素的工作图，不是重新读取原图完整分辨率；该限制沿用现有实现。
