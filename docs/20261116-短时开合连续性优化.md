# 短时开合连续性优化

## 目的与范围

修正快速开合看起来像跳帧的问题，保留从实际点击图片位置展开、返回原位和列表主动预加载的行为。

- 将 240ms 窗口缩放由前段位移较快的回弹曲线改为对称缓入缓出，避免先冲出再回弹。
- 固定过渡圆角、取消动态模糊阴影并启用三维变换提示，减少大面积逐帧重绘。
- 详情画布异步就绪时，不再直接跳改快照边界；在剩余开合时间内连续插值图片位置和尺寸，几何运动结束才交接真实画布。
- 正常时序仍为 240ms 位置动画和 40ms 图片交接。若详情画布迟到，沿用保留快照的处理，再用至少 40ms 对齐，不能把异常慢加载也声明为 300ms 内完成。

## 验证

- 自动化测试覆盖开合生命周期、位移曲线、无逐帧阴影动画和详情就绪时不直接改写边界；最终测试数量见交付说明。
- agent-browser 使用 Chromium 390×844，加载真实 navigationMotion/imageMotion 模块与合成画布，检查展开和返回。详情就绪延迟为 0、80、180ms；5 次热运行位置动画完成耗时约 240–242ms，展开宽度单调，清理后无快照残留，采样最大帧间隔约 6–14ms。
- 首次冷运行出现约 100ms 采样间隔；未将合成场景热运行结果宣称为真实设备帧率保证。未验证真实列表、后端端到端、低端设备及 Android/iOS/PC 真机。
- 正式类型检查、构建、Android 签名热更新生成与 ZIP/SHA256 校验结果记录于本批交付 README。
