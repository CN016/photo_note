# 图库与管理工作台

## 改动目的

改善 Photo Nini 的导航、灵感图库和整体页面视觉，并提供由服务端权限保护的管理工作台。

## 主要内容

- 使用 Element Plus 图标与组件，修复菜单头像读取和加载失败回退，移除侧栏“新建”入口；图库内仍可添加灵感图。
- 将图库卡片预览统一为 4:5，增加文件名搜索、多标签任一/全部匹配、收藏时间和编辑时间排序，查询条件与分页由后端执行。
- 新增 `/atelier-7f3c9a2e` 工作台及 `/api/v1/atelier-7f3c9a2e/...` 接口，提供用户角色、配置、全站灵感图只读浏览和反馈处理功能。后台 API 每次请求核验管理员身份，并防止移除最后一位管理员。
- 为用户、配置和反馈增加管理员标记、秘密配置标记及处理状态；新用户默认不是管理员。秘密配置只返回是否已配置，并从公开配置接口排除。
- 后端版本更新至 `2.4.0`，更新 API 文档、中英文文案及页面主题和响应式样式。首次管理员授权使用 `backend/migrations/ops/20261016_first_console_operator.sql` 中的占位运维模板。

## 验证

- `go test ./...`：通过。
- `pnpm test`：通过，6 个测试文件、19 项测试。
- `pnpm run build`：通过；构建工具提示有单个较大的既有资源包。
- `docker compose -f backend/docker-compose.yml build api`：通过。容器 `/healthz` 返回 `2.4.0`；未登录访问工作台 API 被拒绝；公开配置读取不包含三项标记为秘密的配置；数据库默认值为 `users.is_admin=false`、`app_configs.is_secret=false`、反馈状态 `new`，且无外键约束。
- 使用模拟 API 在 375、768、1024、1440px 检查图库和工作台布局；中英文文案键集合一致；路由和 API 路径未使用 `/admin`。

## 未验证与限制

- 本地 Docker 数据库没有用户，因此未执行管理员登录后的数据库端到端操作，也未实际验证角色撤销后的下一次请求。相关服务和路由测试覆盖权限检查及角色更新规则。
- 界面尺寸检查使用模拟 API，不代表真实图片和反馈附件均已通过生产存储验证。
- 验证期间工作区还包含用户明确要求保留的独立图片元数据改动；构建和测试针对当时的完整工作区执行，该独立改动不属于本变更提交。
