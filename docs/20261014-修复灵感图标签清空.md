# 修复灵感图标签清空

## 目的

修复灵感图 PATCH 使用 `tag_ids: []` 清空标签时返回 503 的问题。

## 改动范围

- service 将待更新标签数组转换为 `pq.StringArray`，由 PostgreSQL 驱动明确编码为空数组 `{}`，避免空 Go 切片变成 SQL `NULL`。
- 不改变接口字段和语义：`tag_ids: []` 仍表示清除全部标签。

## 验证

- PostgreSQL 17.11 上复现原实现写入 `NULL` 并违反 `tag_ids NOT NULL` 约束；修复后 API PATCH 返回 200，灵感图列表、详情及删除均通过。
- 完整 32 项 HTTP smoke 通过；临时用户、标签、灵感图和本地上传文件均已清理。
- `go test ./...` 通过并完成所有 Go 包编译；仓库当前没有 Go 测试文件。
