# 全局缩放边界与颜色筛选图标

## 改动目的

阻止全局界面通过双指手势放大缩小，同时保留图片网格和文档编辑内容已有的局部缩放；让颜色筛选入口显示为色相圆环。

## 改动范围

- 移动端 viewport 禁止整页手势缩放；通用 `ContentZoom` 默认关闭，仅灵感图网格和项目文档编辑内容显式启用。
- 编辑器画布自有缩放交互不变。
- 色系筛选入口由准星改为 CSS 色相环。
- 拖动色环或明度条时按固定间隔实时更新图库排序；请求未完成时合并为最新颜色，避免拖动产生请求堆积。

## 验证方式及结果

- `npm run build`：通过，包含 `vue-tsc --noEmit` 和 Vite 生产构建；Android 签名 Web 热更新资源已生成。
