# 安卓策划编辑交互修复

## 改动目的

修复安卓版拍摄策划编辑时媒体选择、工具栏位置、媒体误聚焦、触屏排序与键盘遮挡问题。

## 主要内容

- 将上传图片/视频与文档附件分为独立入口。图片和视频调用 AndroidX Photo Picker；没有系统或回移照片选择器时使用相册 ACTION_PICK。PDF、Word、Excel 附件继续使用 ACTION_OPEN_DOCUMENT 文件管理器。保留已有灵感库选图入口。
- 选择器回传内容在后台复制到随机私有缓存目录，保留安全文件名与扩展名，再按单选/多选分别确认 Gecko 文件提示，使网页能够读取文件并进入原上传流程。启动时清理一天前的选择缓存，不修改相册原件。
- 上传媒体按钮调整到工具栏首位；移动端隐藏应用导航头，保留策划返回入口、标题与保存状态。编辑工具栏移至底部，可横向滚动查看格式按钮。
- 工具栏与媒体操作条随 visualViewport 调整底部位置；原生容器仍负责系统栏和输入法占位，避免重复计算原生键盘高度。正文保留底部滚动空间，输入光标接近遮挡区时滚动页面。
- 媒体节点设为不可编辑，点击只选中媒体并撤去正文焦点；移动排序不再主动唤起移动端输入法。媒体表面及专用手柄支持长按 350ms 后拖放，短滑动继续滚页；激活后显示虚线反馈。拖放仅允许同父级完整块边界，保留节点属性和单次撤销事务。
- 补充上传媒体按钮的中英文文案。安卓安装版本递增至 1.0.1 / versionCode 2，无后端和数据库变更。

## 验证方式及结果

- `pnpm --dir frontend/apps/web test`：11 个文件、42 项测试通过；新增拖动跨多个块到首尾、节点属性及选择保留、无效来源及目标拒绝测试。
- `node frontend/apps/android/scripts/build.mjs`：包含 Web 类型检查和生产构建、安卓 assembleDebug 与 lintDebug；生成 ARM64、ARMv7、x86_64 三种 1.0.1 调试 APK 及 SHA-256 文件。构建产物仅保留在忽略目录中。
- projects 中英文 JSON 递归键集合检查通过；`git diff --check` 通过。

## 尚未验证与限制

- `adb devices` 无已连接设备；未执行仪器测试或真机交互验收。必须在安卓设备验证相册单选/多选回传后的实际上传、键盘展开/收起、长按拖动和输入光标滚动；桌面浏览器、iOS、小程序未进行运行验证。
- 旧系统相册的 ACTION_PICK 多选能力由相册应用决定，可能一次只返回一个媒体。支持的图片/视频格式沿用现有上传规则，没有扩展 MOV 等格式支持。
- Photo Picker 或文件供应商读取失败时取消当前选择；网页上传大小和类型限制沿用既有校验。
- 构建存在既有大包体提示、Gradle/SDK 兼容提示与 lint 警告；不代表真机验证通过。
- 未发布、未部署、未上传 APK 到官网，也未修改官网的下载版本配置；本地 Git 提交不包含推送。
