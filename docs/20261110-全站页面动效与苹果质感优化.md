# 全站页面动效与苹果质感优化

## 改动目的

为共享业务 Web 建立统一的页面切换体验，重点实现列表卡片进入详情、详情返回原卡片的连续动画，同时改善快速连续返回时的动画中断，并将全站视觉令牌调整为接近 Apple 系统界面的中性色、系统字体、半透明材质和克制阴影。PC 与移动端复用同一套页面和动画实现。

## 技术选型

- 动画库：GSAP 3.15.1，使用 `Flip` 插件及 GSAP Timeline。`Flip.fit` 根据点击卡片的真实布局尺寸和完整视口建立缩放关系，Timeline 负责进入、返回和中断。没有自行实现缓动曲线或 DOM 尺寸插值。
- 路由：继续使用现有 Vue Router 4。全局 `router.beforeEach` 判断列表与详情关系，`App.vue` 的原生 Vue `Transition` 提供进入/离开生命周期，业务页面仍由 Vue Router 正常挂载和销毁。
- 动画层：在路由内容外增加统一的 `.route-page-frame` 页面帧，解决多个页面组件以“导航 + 内容”多根节点渲染、Vue Transition 无法直接获取动画根节点的问题。
- 兼容和降级：系统启用 `prefers-reduced-motion: reduce` 时直接完成切换，不执行缩放；直接打开详情、缺少来源卡片位置或同路径查询参数变化时使用短淡入/上移过渡。GSAP 不依赖 View Transition API，因此普通 Chrome、Edge、Safari 和 Android GeckoView 共用同一运行路径。

## 主要改动

- 新增 `frontend/apps/web/src/motion/routeMotion.ts`：集中维护详情路由与列表父路由关系，并输出 `shared-forward`、`shared-back`、`page`、`none` 四类动画计划。
- 新增 `frontend/apps/web/src/motion/navigationMotion.ts`：在点击捕获阶段记录卡片位置、圆角、阴影、滚动位置；通过 `Flip.fit` 从点击区域放大到完整视口，返回时缩回原位置；新导航会终止前一动画并从当前视觉状态反向缩放。
- 灵感库、拍摄策划、项目复盘、作品集、交付任务、消息中心和营运管理工作台中的详情入口增加 `data-shared-transition` 标记。
- 返回后恢复原列表滚动位置，并在列表异步布局完成后再次校准；账号、组织或会话代次变化时清除动画历史，避免跨空间复用旧位置。
- 全局视觉令牌改为 Apple 系统式中性色阶：浅色页面 `#f5f5f7`、白色内容面，深色页面 `#000`、`#1c1c1e` 内容面，主操作色使用系统蓝；系统字体优先 `SF Pro`、`PingFang SC`，其他平台回退到 Segoe UI 和微软雅黑。
- 桌面侧栏、顶部栏和移动底栏改为半透明模糊材质；按钮、输入框、卡片、弹层统一更圆润的圆角和轻量双层阴影，加入按下缩小反馈，同时保留键盘焦点和 44px 触控尺寸。
- 新增 GSAP 许可说明及 `public/licenses/gsap-STANDARD-LICENSE.txt`，依赖版本锁定在 `pnpm-lock.yaml`。

## 验证方式及结果

- `pnpm exec vue-tsc --noEmit`：通过。
- `pnpm exec vitest run src/motion/routeMotion.test.ts`：1 个测试文件、5 项测试通过，覆盖前进、返回、直达详情、查询参数变化和路由关系。
- 使用 Vite 开发服务和 agent-browser 合成 API 验证桌面 `1264×569` 与移动 `390×844`：
  - 从拍摄策划列表点击卡片时，详情页面帧从卡片区域扩展至完整视口；
  - 返回时页面帧缩回原卡片矩形，最终约为原点击区域 `388×86`；
  - 在放大动画进行中调用浏览器返回，动画从当前约 `1146×504` 的中间帧反向缩回，最终移除详情帧并只保留列表帧；
  - 动画结束后页面位置恢复为 `static`，内联样式清空，不残留 `fixed` 定位或滚动锁。
- 截图检查了桌面与 390px 移动视口：中性页面底色、系统字体、半透明导航、圆角卡片和移动端底部标签均正常，页面无横向溢出。

## 尚未验证

- 未在 Android 真机 GeckoView、iOS Safari、PC 原生壳或微信小程序中验证动画帧率、系统返回键、滚动恢复和低端设备内存表现。
- 浏览器自动化使用合成 API 和单个策划卡片，不代表真实后端数据量、超长列表、图片解码或生产网络下的全部页面行为。
- 未进行生产部署、真实用户验收或低端 Android 设备性能采样。
