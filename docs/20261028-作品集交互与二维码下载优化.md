# 作品集交互与二维码下载优化

## 目的与范围

让作品集以照片和明确操作为主，减少页面文字与重复入口；补齐二维码下载。涉及共享业务 Web、安卓共享页面及公开作品集共用图库。未修改后端接口、数据结构或原生壳。

## 主要内容

- 作品集列表以封面卡片展示，无封面时提供统一占位；搜索无结果可直接清除筛选。
- 修复桌面固定侧栏遮挡主体的问题；移动端双列照片并为底部导航预留空间。
- 移除作品集与分享弹窗的常驻说明、状态与风险提示。照片优先展示，拍摄参数分析置于照片下方默认折叠；空列表直接提供新建或添加照片按钮。
- 灵感库添加改为授权缩略图多选，按钮展示所选数量；支持搜索、分页、取消，搜索迟到响应按请求代次与空间丢弃。
- 编辑取消后重新打开恢复已保存标题、简介、标签及策划关联。照片信息保存失败保留草稿，成功才关闭弹窗；保存期间限制关闭及重复操作。
- 分享链接生成后提供复制、打开作品集和下载二维码按钮，不再并排显示重置操作。分享生成与二维码编码均校验原始路由/空间代次，防止迟到回填。二维码以960像素PNG导出，复用平台适配接口：Web下载，Android调用现有系统保存/分享面板。
- 更新AGENTS.md中的页面交互规范及二维码下载要求；补齐中英文同键文案和Element Plus组件声明。

- `npm run test -- src/views/portfolioPublicBase.test.ts ../../packages/platform-adapters/index.test.ts`：2个测试文件、5项测试通过。
- 双语递归键集合检查：portfolio及public-portfolio中英文键一致；`git diff --check`通过。
- 使用agent-browser和临时本地测试入口挂载真实页面，以内存API替身验证：1440px桌面主体在侧栏右侧；390px手机页面及选图弹窗无横向溢出；取消编辑重新打开恢复原标题；选图按钮由0更新为1；中英文切换；二维码按钮触发portfolio-qr.png下载且二维码原始宽度为960px。

## 发布与限制

本批需发布业务Web及Android签名热更新；无需后端迁移、API镜像、独立官网包或新APK。共享图库变化会影响公开作品集的照片布局与参数分析位置。

浏览器验证使用模拟API，不代表真实后端上传、复制、删除、分享令牌生命周期及线上访问验收。Android系统保存面板、Android/iOS真机、PC壳及微信小程序未运行验证。未上传、部署或完成线上验收。PC、iOS、微信小程序未构建独立安装包，独立官网与后端不涉及发布。
