# 5.0 解除档期关联回归修复

## 目的与范围

修复主动解除档期关联或删除已关联档期后，重新打开策划时前端再次触发自动关联的问题。仅在服务端返回 pending 或 candidates 时执行自动联动，保留服务端以拍摄信息指纹记录的解除决定；用户仍可手动点击关联。未修改后端、数据库或原生壳。

## 验证结果

- 独立本地 API 与 PostgreSQL 环境，通过真实浏览器在 375px、深色、英文界面解除关联，重新加载同一策划后仍显示 Link schedule，没有自动创建或弹出候选选择。
- 最终生产构建包含 TypeScript 检查；Web 与安卓签名热更新重新生成，最终发布号、签名和校验结果见本批 artifacts/20261104-224047/README.md 与清单。先前发布号 1793806117209 的构建为本次修复前的中间包，不用于交付。
- 前批已执行后端 156 项通过，独立档期与提醒集成测试另行通过；前端 20 文件 85 项通过。此处两行条件修复另以真实浏览器回归及生产构建检查。

## 限制

未部署生产、未执行生产数据库迁移；未验证 Android 真机、PC 原生壳、iOS 或微信小程序。外部 AI 供应商未配置真实凭据，已验证未配置及模拟生成/采纳流程，不声明真实模型联通。
