# 灵感图锚点文字样式与图片导出

## 改动目的

按参考图重做灵感图详情页的锚点标注样式：去掉圆点，改为“下划线标题 + 小号详细描述”的纯文字块；点击锚点可编辑文字并显式删除。同时补齐图片属性面板的导出能力，包括直接导出和先放置、拖动、缩放水印再导出，并让属性面板在手机返回时先回到图片详情而不是直接离开页面。

## 主要内容

- 锚点改为纯文字块：备注第一行作为标题，使用下划线代替原来的圆点；第一个换行之后的内容作为详细描述，字号略小于标题。文字块始终从锚点位置向右展开，空间不足时自动换行，不再切换左右两侧。
- 新增或编辑锚点时使用多行输入框，回车插入换行而不是直接保存；第一行生成标题，其余行生成描述，`Ctrl/Cmd + Enter` 或“完成”提交。编辑条在已有锚点上提供独立的“删除”按钮，清空文字后完成仍保留原有删除兜底。
- 点击已保存锚点即进入文字编辑；编辑中的锚点使用黄色下划线和轻微文字高亮标明当前选中项。编辑态不再显示任何圆点，新增锚点未输入文字时用一段黄色短横线提示落点。
- 每个锚点新增可选 `label_scale` 字段（0.75–2，按 5% 对齐），用于单独调整该条标题与描述的字号。编辑中的锚点右下角显示拖动手柄，也可聚焦手柄后用方向键调整；详情态自动保存，编辑态仍由统一保存按钮提交。旧文档没有该字段时按 1 处理，未知字段继续原样保留，`schema_version` 保持 1。
- 拖动锚点改为按指针位移计算位置，避免按下文字块时锚点跳到手指所在的绝对坐标。
- 图片属性面板新增“导出”区域：
  - “导出图片”按当前旋转、裁切和色彩调整渲染后导出。
  - “添加水印并导出”进入临时水印模式：点击图片选择位置，拖动水印微调位置，使用滑杆调整大小，再导出；水印只存在于页面内存，不写入图片文档。导出成功后自动退出，取消保存面板时保留预览以便继续调整。
  - 源文件名是 PNG/WebP/GIF/AVIF/BMP 时导出 PNG，其余使用 JPEG（质量 0.92）；文件名追加 `-export` 或 `-watermark`。水印文字固定使用品牌名 `LightNote`。
- 属性面板在详情态同步为 `?panel=properties`：打开时新增一条历史记录，系统返回键或浏览器后退会先关闭面板并回到图片详情；关闭时通过后退移除该记录，直接打开带参数的地址时改用替换清理，避免留下重复的后退步骤。编辑态和新图上传不写该参数。
- 锚点列表与无障碍标签只展示标题，完整备注保留在悬停提示中；全屏查看层同步使用标题下划线和描述结构，并维持反向缩放后的屏幕字号。

## 验证方式及结果

- `pnpm exec vue-tsc --noEmit`：通过。
- `pnpm test`：41 个测试文件、172 项测试通过，其中新增锚点标题/描述拆分、文字宽度、水印几何与绘制用例。
- Chromium `390×844` 移动视口，使用临时本地 Service Worker 模拟登录、灵感图记录和 SVG 工作图进行页面验收（模拟文件已删除，未提交）：
  - 锚点标题带下划线、描述字号更小，文字始终从锚点右侧展开并自动换行；点击后出现黄色下划线和选中高亮，画布上无圆点。
  - 编辑条为多行输入框，包含“删除 / 完成”；删除后锚点数量减少，首行/后续行分别更新标题和描述并自动写回 `data.anchors`。
  - 拖动手柄可调整文字倍率（100%→150%），字号与换行实时变化，`label_scale` 写回服务端文档；拖动文字块按位移移动，按下时不再跳位。
  - 属性面板可通过 `?panel=properties` 直接打开；浏览器后退关闭面板并回到 `/inspirations/mock-image`；直接打开参数地址也能恢复面板。
  - 水印模式可点选位置、拖动水印、滑杆调整大小；导出得到 1200×800 PNG，水印位置存在白色文字像素；普通导出得到无水印 PNG；取消水印模式不写入文档。
- `pnpm build`：见本批交付目录的 README 与验证记录。

## 尚未验证或已知限制

- 未在 Android、iOS 真机上验证软键盘、系统返回手势和输入法换行行为；Chromium 合成触摸事件不能替代真机验收。
- 导出使用当前工作图（解码长边上限 1800 像素）渲染，不是原始文件的完整分辨率；如需原尺寸导出需要额外读取原图，本批未实现。
- 水印文字固定为品牌名，暂不支持自定义文案或图片水印。
- 旧锚点只有一行文字时只显示下划线标题；多行旧备注会按第一个换行自动拆分为标题和描述。
- 本批未修改后端、数据库、独立官网、PC/iOS 原生壳或微信小程序。
