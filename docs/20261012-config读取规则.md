# 后端配置读取规则

## 改动目的

统一后端配置的存放和读取方式，避免业务配置分散在多个来源。

## 主要内容

- 在 `AGENTS.md` 中规定：PostgreSQL 和 Redis 自身的连接配置除外，后端其他需要配置的值统一存储在 `config` 表。
- 配置值通过统一配置服务按 key 获取，业务模块不直接查询配置表，也不在独立配置文件、环境变量或硬编码常量中另行维护。

## 验证方式及结果

- 人工核对 `AGENTS.md` 新增规则与本记录内容一致。
- 本次为文档改动，未运行代码检查或测试。

## 尚未验证的内容或已知限制

- 配置表结构及配置服务的具体接口实现不属于本次改动范围。
