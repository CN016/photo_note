# 官网安卓下载精简

## 改动目的
简化下载安装选择，根据浏览器 UA 推荐安卓版本。

## 主要内容
- 官网仅分发 ARM 64 位、32 位 APK；移除 x86_64 分发、清单及下载校验要求，安卓壳构建能力不变。
- 两列下载卡片使用 64 位、32 位名称，保留版本、Android 最低要求、包大小及折叠校验入口。
- 移除浏览器内核和安装流程长说明；保留测试版标识，中英文同步调整。
- Android UA 明确包含 armv7/armeabi/armv6/i386 等 32 位标识时推荐 32 位；有 64 位标识或未暴露架构时推荐 64 位；推荐项排在前面，非 Android UA 不显示推荐。UA 仅作提示，始终允许手动选择。

## 验证结果
- pnpm --dir website build：默认同源打包模式因项目版本 1.0.1 与本地现有 1.0.0 APK 不匹配被校验阻止。
- 临时设置 VITE_ANDROID_BUNDLED_DOWNLOADS=false 后执行同一构建：类型检查、中英文键校验、配置校验及 Vite 构建通过，未修改环境配置文件。
- 对源码中的推荐表达式执行 Android 64 位、32 位、精简 UA、Windows 和 iPhone 五组断言，全部通过。
- agent-browser 检查本地 /download/ 页面及中英文切换通过；由于关闭同源打包，浏览器未覆盖安卓卡片的实际展示及下载。
- git diff --check 通过。

## 限制
- UA 无法保证准确识别设备真实架构，未暴露架构的安卓设备默认推荐 64 位。
- 尚未验证两份 1.0.1 安装包的完整构建、浏览器卡片布局、移动真机安装及线上部署。
- 未纳入工作区其他 Web 编辑器与安卓壳并行修改。
