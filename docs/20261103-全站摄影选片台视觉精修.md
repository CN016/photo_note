# 全站摄影选片台视觉精修

## 目的与方向

用户确认对全部业务页面与独立官网执行保留品牌的视觉精修。产品名称、蓝色品牌、功能与页面内容顺序保持现有语义，采用沉静、准确、有画册感的摄影选片台方向：中性界面承托用户图片，强调色用于操作与选中状态。

## 初审发现与处理

| 范围 | 问题 | 本批处理 |
| --- | --- | --- |
| 共享界面 | 偏蓝底面、彩色阴影与半透明顶栏同时强调 | 明暗主题改为中性色阶，保留蓝色操作色、语义状态色，取消主要按钮彩色阴影 |
| 登录、注册 | 装饰圆环、倾斜拼贴和重字重争夺注意力 | 去除背景圆环与拼贴倾斜，摄影示意使用收敛的自然色，登录标题中英文改为明确操作上下文 |
| 导航与工作台 | 导航行偏高，部分内容区贴近侧栏 | 桌面导航行调整为 36px，工作台、个人中心与消息中心增加侧栏外留白，移动端保留触控高度 |
| 图库与编辑界面 | 卡片逐项入场、图片悬停缩放、信息小字密集 | 去除装饰性入场与缩放，名称、尺寸、日期使用统一信息条与间距，尺寸采用等宽字体 |
| 方案、项目、上传、账本、档期 | 局部样式存在重字重、紧字距与不一致留白 | 修整共享样式及对应局部样式，调整卡片、筛选、表单、附件预览和正文工具栏；不修改用户文档数据与画布几何 |
| 统计 | 单组比较也使用多种分类颜色，部分轴标签过小 | 柱状、条形、散点比较统一强调色；饼图与树图保留区分类别所需颜色，雷达标签增至 12px |
| 独立官网 | 重字重、过宽字距、按钮与太阳光晕装饰 | 保留淡蓝白摄影画册与原有 CSS 场景，收敛字重、间距、阴影，优化下载卡片与移动端按钮换行 |
| 档期星期 | 用字符串翻译 API 读取数组，将翻译键逐字符绘制成日历列 | 使用 `tm` 读取既有双语星期数组并检查数组类型 |

按 unslop 九轮顺序处理间距、颜色、图标、文案、字体、布局、细节、视觉、动效。图标继续复用 Element Plus，移除不必要的星形装饰显示，保留有语义的图标和真实加载反馈。未新增字体、外部素材、依赖、图片生成或演示业务功能。透明棋盘、色板和用户内容颜色不作为装饰移除。

共享样式覆盖 21 个业务页面文件：登录、注册、维护、工作台、图库、上传、灵感详情、统计、账本、档期、计划、项目列表、项目编辑、消息、个人中心、空间、组织、管理控制台、作品集、公开作品集、公开预约。组织与平台管理复用现有控制台页面。官网覆盖首页、下载页。

## 验证

- 业务 Web：执行 `pnpm build`，包含 `vue-tsc --noEmit`、Vite 生产构建和 Android 热更新后处理。
- 业务 Web：执行 `pnpm test`，18 个文件、78 项测试通过。
- 官网：执行 `pnpm build`，类型检查、中英文键检查、下载配置检查与 Vite 多页构建通过。
- 递归对比业务应用 22 对、官网 3 对语言 JSON 的键集合（包含数组索引），全部一致。
- 执行 `git diff --check`，无空白错误。
- 使用 agent-browser 的独立会话检查界面。登录后布局使用仅存在浏览器内存的验收账号与空数据／不可用状态，不创建服务器账号，不提交业务写入。覆盖桌面约 1264px、手机 390px；主要列表与表单路由未发现页面级横向溢出。官网手机菜单可展开，首页与下载页中英文切换后无页面级横向溢出。
- 截图抽查登录页、工作台、统计页、手机账本、明暗主题档期、官网首页及下载页；最终生产构建另行复核工作台内容区留白与日历中英文星期：正确显示周一至周日、Mon 至 Sun，390px 下无页面级横向溢出。
- 早期统计验收数据缺少数组字段，导致临时预览失败；修正验收数据后统计页正常显示。此现象不作为应用缺陷或通过依据。

## 发布范围与限制

- 需要发布：业务 Web、配套 Android 签名热更新资源、独立官网；统一交付于本批 `artifacts/` 北京时间目录，包名、发布号、源码提交、摘要、部署顺序及最终验证见该目录 README。
- 本批未修改后端、接口、数据库、原生壳、桥接及内核，不需要 API 镜像或新 Android APK。官网包沿用当前配置所指定的既有 APK 下载资产，不宣称重新构建 APK。
- PC、iOS、微信小程序未改动平台壳，也未构建或真机验收；共享界面的 Web 检查不能代替这些平台验证。Android 仅构建、签名与校验热更新资源，未完成设备安装及在线更新验收。
- 浏览器检查不代表生产账号、真实私有图片、大量数据、所有对话框、导出与上传流程的完整端到端测试。公开分享页使用不可用链接状态检查，未访问真实用户分享。
- 未执行上传、部署或线上验收；生产构建存在体积超过 500 kB 的分块提示，本批未开展无关的依赖拆分。
