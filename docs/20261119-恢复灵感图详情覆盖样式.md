# 恢复灵感图详情覆盖样式

## 改动目的

恢复 `cff2224` 中已经验收的灵感图详情视觉。后续 `d6530bf` 新增的全站 `glass.css` 使用较宽的 `body .image-edit-dock`、`body .image-tool-popover`、`body .el-dialog` 等选择器并带 `!important`，覆盖了详情页最初设定的页面底色、图片环境光、透明 Dock、标签设置框和编辑工具材质。

## 主要内容

- 新增 `frontend/apps/web/src/inspiration-detail.css`，在 `glass.css` 之后加载。
- 所有覆盖均限定到 `body.image-detail-route`，不改变其他页面的全站玻璃主题。
- 恢复浅色 `#f5f5f7`、深色 `#000` 的详情页底色，移除详情页上的全站蓝色环境光斑。
- 恢复 `cff2224` 的图片主色环境光、透明磨砂 Dock、顶部高光/底部细阴影和移动端 32px 饱和模糊。
- 恢复图片详情工具浮层、属性/确认弹层、消息提示、标签输入框和主按钮的详情页材质优先级。
- 避免详情工具面板在玻璃 Popover 内再次叠加一层不透明玻璃。
- 新增加载顺序测试，确保后续修改 `main.ts` 时详情专用覆盖仍位于 `glass.css` 之后。

## 验证方式及结果

- `pnpm.cmd --dir frontend/apps/web typecheck`：通过。
- 390×844 Chromium 浅色与深色检查：页面底色、图片舞台、标签行、Dock 和标签选择框恢复为 `cff2224` 效果；无横向溢出。
- 标签选择框和备注工具浮层计算样式确认使用图片主色环境光、透明背景和详情页专属内高光。
- axe 检查：0 个 violation；剩余 incomplete 为图片叠层和伪元素背景导致的自动对比度无法判定。
