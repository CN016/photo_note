# 图库关联策划、返回恢复与编辑菜单

## 改动目的

从灵感图直接查看已引用的策划，阅读后回到原来的图库位置，并按策划内容提供适用的右键操作。

## 主要内容

- 图片卡片右键或静止单指长按 500ms 打开关联列表；移动超过 10px、滚动、多指、取消及卸载终止长按，成功后吞掉一次后续点击。
- 关联列表按需分页，提供加载、空列表、失败重试及适用的复制图片操作；请求代次及会话范围隔离迟到响应。
- 进入现有策划详情时使用临时阅读模式，不因打开页面修改默认模式；主动切换后沿用既有保存及修订保护。
- 内存快照绑定账号、组织、会话代次及来源历史项，恢复筛选、已加载分页、记录、滚动、图库工具视图、Android 主体缩放及关联浮窗；浮窗重新核对服务器关联。
- 返回按钮仅在来源有效时使用历史返回，其余入口回落策划列表；刷新不承诺保留内存快照。
- 策划文字菜单复用现有样式、标题、列表、链接及撤销重做；表格按命令可用性显示行列、合并拆分和表头操作。
- 图片/附件菜单复用授权查看、详情、下载与尺寸操作；移除仅删除当前正文引用。阅读模式不提供修改动作。
- 富文本粘贴由当前 schema 解析，保留安全任务列表属性、剔除私有资源认领属性和事件处理器；剪贴板文件进入既有上传链。异步操作核对原文档，避免迟到修改。
- 图片节点取消空的右键屏蔽，节点处理器优先于正文；上传占位及不兼容文档不提供正文修改菜单。

## 实际验证

- `npm test`：20 个文件、85 项测试通过，包括长按 500ms 边界、10px 抖动、取消、重启定时器、点击吞并、浮窗视口边界及快照隔离。
- `npm run typecheck` 通过；最终生产构建再次执行类型检查。
- Chromium、内存 API fixtures 与 DOM 事件验证：40 张已加载图片进入策划，临时阅读模式的保存次数为 0；返回后图片数仍为 40，滚动值与快照同为 3857，关联浮窗重开。
- 同一浏览器验证文字选区长度 5，菜单加粗仅影响这 5 个字符，撤销恢复；图片菜单将宽度调整为三分之一；通过菜单插入表格、再插入行后行数由 3 变为 4；阅读模式资源菜单不含修改动作。
- 390×844 视口下，合成 TouchEvent 验证长按显示且后续点击被阻止；移动、多指及滚动取消均不打开菜单；浮窗位于视口内。
- gallery 中英文 115 键、projects 中英文 123 键一致；键盘与英文菜单检查通过。
- 浏览器复测发现后台标签页会暂停 requestAnimationFrame，因此改为等待工具区数据及 Vue 更新后直接恢复布局和滚动，不依赖动画帧。
