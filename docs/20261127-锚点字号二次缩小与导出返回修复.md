# 锚点字号二次缩小与导出返回修复

## 改动目的

上一版锚点仍显得过大、过粗，且照片导出后在部分 WebView 会话中没有离开照片详情。本批进一步缩小锚点视觉，并移除导出返回对不可靠浏览器历史位置字段的依赖。

## 主要内容或涉及范围

- 锚点标题基准字号由 12px 调整为 10px，详细描述由 10px 调整为 9px。
- 标题字重由 600 调整为 500，减弱文字阴影，黄色下划线由固定至少 2px 调整为至少 1px，圆点比例由 0.56 调整为 0.48。
- 详情、编辑画布、全屏、列表缩略图和图片导出继续共用相同基准常量，避免预览与导出字号不一致。
- 修复导出返回：属性面板导出固定回退两层，不再要求 `history.state.position` 存在或达到固定值。
- 回退后若 400ms 内仍停留在同一张照片，自动替换到灵感库，覆盖浏览器将 `router.go(-2)` 收敛为只退一层或无法回退的情况。
