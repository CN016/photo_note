# 安卓创作引擎启动提示与1.1.1交付

## 改动目的与范围

将安卓原生启动提示“正在启动内置浏览器…”调整为更贴合图片创作产品的“正在启动创作引擎…”，英文同步为“Starting the creative engine…”。失败提示也统一使用“创作引擎 / creative engine”，保持中英文键一致，不改变启动流程或内核实现。

安卓版本由1.1.0递增为1.1.1，安装版本由4递增为5，package-lock同步。原生资源文案需要安装新版APK，签名Web热更新不能替换这段原生资源。官网重新构建以分发1.1.1，仍标明调试签名；没有切换生产签名。

## 产物与部署范围

按根目录AGENTS规范，本批统一交付到 `artifacts/20261027-125819/`：

- `android-1.1.1-debug.zip`：ARM64、ARMv7、x86_64 APK、各自校验文件及安装说明。
- `website-android-1.1.1.zip`：完整官网及ARM64/ARMv7下载包，解压到独立www站点根目录。
- 本批部署说明、源码提交及SHA-256记录位于同目录；构建日志在其logs子目录，产物不提交Git。

业务Web无页面代码变更；安卓构建中重新生成的共享Web只用于APK基线，不要求更新photo业务站。后端、PC、iOS及微信小程序未涉及发布，无数据库迁移、无Docker镜像更新，不移动或清理历史产物。

## 验证方式及结果

- `npm --prefix frontend/apps/android run build`：共享Web类型检查/生产构建、三个ABI的assembleDebug及lintDebug通过，并输出APK与SHA-256。
- XML解析检查中英文键集合一致，启动及失败提示已同步；aapt2读取编译后的ARM64 APK资源，确认包含新的中英文提示、不含旧启动提示，版本为1.1.1。
- `pnpm --dir website build`（启用内置安卓下载）：类型、语言键、配置检查及构建通过，下载元数据为1.1.1，构建插件完成两份APK复制前后的哈希校验。
- 两份最终ZIP的CRC完整性检查通过，SHA-256已记录；实际打包校验结果保存于产物目录。`git diff --check`通过。

本批为原生文案及版本调整，未新增业务测试，未重复进行模拟器交互或实体设备安装验收；未上传官网或部署生产。三架构构建通过不等于三架构真机运行均通过。生产签名及商店发布仍未覆盖。
