# 全局淡蓝白深黑主题与交互优化

## 改动目的

为取景台共享 Web 界面建立统一的淡蓝白与深黑主题，采用简洁的工作台视觉，并改善手机触控、操作提示和提交反馈。覆盖现有 17 个路由页面及公共组件。

## 主要内容

- 将页面、卡片、弹层、文字、描边、品牌色和成功/警告/危险状态集中为全局语义令牌；浅色页面为 `#F3F7FE`、卡片为白色、品牌色为 `#2563EB`，暗色页面为 `#08090B`、卡片为 `#111318`、弹层为 `#191C22`、品牌色为 `#5B9CFF`。
- 同步 Element Plus 暗色类、完整组件库暗色样式和浏览器 `theme-color`，让日期选择器、菜单、消息、抽屉等挂载到 body 的浮层使用相同主题；移除 JavaScript 中独立的橙色和圆角硬编码。
- 控件、卡片、弹层分别采用 8px、12px、16px 圆角，统一主次按钮、焦点、按下、加载及禁用反馈；保持圆形头像与用户内容图形的既有含义。全局支持系统减少动态效果偏好。
- 产品入口改用已有 MIT 许可图标库的 `CameraFilled`；统一功能图标大小，将项目翻页字符改成组件库箭头。企业微信、钉钉、飞书的官方图像保持原色与比例，调整容器和留白。
- 登录注册画板、工作台、灵感库及统计、消息、个人资料、管理台、日程、计划、拍摄策划、预约页和编辑器共同使用主题变量。账本移除独立绿白配色和单独暗色表，收入与支出仍使用有业务含义的状态色。
- 账本月报与对比图片改为固定淡蓝白报表，不随界面暗色模式变为黑底；保留收入与支出的区分及原有数据计算。

## 交互调整

- 手机顶栏提供品牌入口、主题、语言和消息入口，解决侧栏偏好选项在手机上隐藏后无法访问的问题；多个主题切换入口共享响应状态。
- 手机常用操作区域至少 44px；计划卡片的操作移到正文下方，项目资源操作条放在底部编辑工具栏上方，避免挤压正文或超出窄图片范围；日程与计划在 769–900px 仍为桌面侧栏预留空间。
- 桌面矮屏仅滚动侧栏菜单，账号、主题与语言入口保持可见；账本与侧栏之间补齐 42px 留白，与主要页面的内容边界对齐。语言选择器明确内层宽度，避免只显示箭头而隐藏当前语言。
- 修复手机账本隐藏上传输入框被通用子元素宽度覆盖后产生的 9px 横向溢出；年度图表仍在自身容器内横向滚动，不扩展页面宽度。手机反馈按钮隐藏文字时仍保留明确的图标字号。
- 上传区域支持整块点击、Enter 和 Space，并显示处理中状态；翻页加载时禁用重复操作；图标按钮补充双语用途提示和无障碍标签。
- 日程、计划、预约提交增加重复提交保护，提交期间禁止关闭弹窗和修改表单内容，正常取消仍可关闭；错误仍通过原有路径反馈。
- 反馈入口采用次要按钮样式，打开抽屉后聚焦文本输入；关闭保留草稿，提交期间冻结输入及取消按钮，成功图形使用组件库图标。
- 日程、账本选中日期和筛选模式补充选中状态；账本保存与加载状态可被辅助技术读取；项目时间随当前语言格式化。

## 兼容性与数据边界

- 保留 `photo-nini.theme` 偏好键和首次使用默认浅色；保留现有路由、API、持久化结构及图片处理规则，本批不修改后端版本。
- 不覆盖用户图片、图片分析色板、画布锚点颜色、文档自选文字/高亮颜色和用户封面 emoji。
- 继续使用现有 Element Plus 和图标依赖，没有新增运行时依赖。
