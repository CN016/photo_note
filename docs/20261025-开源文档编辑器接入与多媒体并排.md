# 开源文档编辑器接入与多媒体并排

## 改动目的

上一轮媒体移动和任务列表修复缺少浏览器验收，用户实际使用仍无法拖动且任务项错行。本次采用现成 Vue 文档编辑器组件，保留业务资源和保存契约，补充真实鼠标、任务输入及窄屏验收。

## 主要内容

- 锁定 `tiptap-vue-pro-element-plus@0.2.6`，复用其 Element Plus 工具栏、任务列表和正文基础样式。`ProjectDocumentEditor` 负责编辑器适配，页面保留 API、上传、revision 保存及状态提示。
- 显式覆盖默认扩展，仍使用 V1 文档与 `inspirationImage`、`projectAttachment` 私有资源节点。运行时确认未注册默认斜杠菜单和未知节点；关闭公共图片 URL 入口。
- 使用 `@tiptap/extension-drag-handle-vue-3@3.32.0` 提供浮动块把手，媒体节点内补齐官方 `data-drag-handle`；额外提供前移/后移，使用当前 ProseMirror 文档快照交换同层节点，保留撤销和完整属性。
- 恢复媒体 inline-block 布局，百分比宽度包含左右间距，缩小后自动并排、宽度不足自动换行；不持久化临时 blob URL。
- 任务项复用上游布局。针对 Tiptap 3.32 新增隐藏无障碍标签与组件旧 checkbox 视觉样式之间的不兼容，局部恢复原生 checkbox，保留无障碍说明。
- 删除上一轮强制独占一行与斜切 transform，编辑区允许字体合成斜体。字号沿用受限渲染，并继承官方字号命令供新工具栏使用。
- 初始正文与保存响应分离，防止请求期间产生的新编辑被旧响应覆盖。打开旧文档不触发无意义保存；不使用组件自带自动保存或本地草稿。
- 新增 schema 兼容检查：未知节点、标记、属性或非法嵌套时暂停编辑和保存，保留原始数据；标题也禁止继续修改。
- 中英文新增移动操作和兼容提示；补充依赖来源与 MIT 许可副本。业务自有图标继续使用 Element Plus；上游工具栏保留其开源图标。

## 验证方式及结果

### 静态与自动化

- `pnpm typecheck`：通过。
- `pnpm exec vitest run`：10 个测试文件、37 项测试全部通过。其中新增 6 项文档兼容检查与 4 项真实 ProseMirror 排序事务测试，覆盖图片、附件和文字相邻交换、连续首尾移动、内容完整性及未知内容拒绝编辑。
- `pnpm build`：通过，包含 `vue-tsc --noEmit` 和 Vite 生产打包；编辑器页面 JS 约 1,198.28 kB（gzip 371.29 kB），生产打包包含若干超过 500 kB 的 chunk，现成组件也带入了未启用功能的运行时代码，后续可按实际加载性能评估拆包。
- 中英文 JSON 键集合一致且无重复，共 98 个键；`git diff --check` 通过。提交前另核对暂存范围。

### 浏览器验收

使用 agent-browser 启动独立 Chromium 会话，在本地 Vite 中挂载真实编辑组件及真实 `ProjectEditorPage`，API 用本地夹具模拟，未访问或修改用户项目。验收夹具只用于本次运行，交付前删除。

| 场景 | 实际结果 |
| --- | --- |
| 三个宽度 30% 的图片/媒体 | 桌面与 390px 窄屏均可同行排列 |
| 图片把手拖到相邻图片之后 | 真实鼠标按下、移动、释放后顺序由 A/B 变为 B/A |
| 附件拖到两张图片之间 | 真实鼠标拖放后 JSON 顺序正确，撤销/重做恢复预期顺序 |
| 宽度滑杆 30% → 100% → 30% | 大图自动换行，缩小后恢复并排 |
| 前移/后移按钮 | 窄屏操作可交换相邻媒体，节点数量和属性完整保留；事务测试补充首尾与文字交换 |
| 任务勾选、新增和嵌套 | 勾选框可见且与首行文字对齐；Enter 新增、输入中文、Tab 嵌套成功，最终三项任务保存一致 |

| 未知节点 | 页面显示兼容提示，未挂载编辑器，保存请求数为 0 |
| 明暗主题、中英文 | 工具栏和业务提示切换正常，390px 页面无横向溢出，移动按钮为 44px 触控区域 |

## 兼容与未验证范围

- 不变更服务端 API、数据库结构、文档版本或私有文件授权；本批次仅前端改动，不递增后端版本。
- 浏览器使用模拟 API，不能证明真实服务端数据库持久化、上传、鉴权和组织隔离流程已联调通过。
- PC 壳、Android、iOS 和微信小程序真机未验证；手机验收为 Chromium 390px 视口，不能视为触摸真机验证。
- 媒体并排由现有宽度自然流式布局实现，未新增持久化列容器或多列文档格式。
