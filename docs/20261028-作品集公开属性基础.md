# 作品集公开属性白名单基础

## 目的与内容

为独立作品集的公开接口准备拍摄属性白名单，仅提取焦段、光圈、快门、ISO、相机镜头名称和尺寸；不返回 GPS、设备序列号、扩展字段或未来新增的未知字段。无效 JSON 返回错误。后端版本更新为 4.3.1。

## 验证与限制

- `go test ./internal/service -run '^TestPortfolioMetadataForPublic$'`：通过，验证公开字段、敏感及未知字段过滤和错误处理。
- 本批只提供基础函数，尚未接入公开接口；作品集管理、上传、分享、统计、前端及文件清理均未实现，不能作为完整功能部署。
- 原始公开图片可能包含 EXIF 定位等敏感信息；API 白名单不会移除图片中的元数据，公开副本策略须在完整实现时单独处理。
- 未执行数据库迁移、租户隔离集成测试、构建镜像及线上部署。
