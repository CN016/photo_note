# 低饱和现代界面视觉调整

## 改动目的

降低默认绿色主题的饱和度、光斑和厚重玻璃感，缩小信息字号，使图库和整体界面向简约、现代、轻量的方向调整。

## 主要内容

- 浅色绿色主题改为低饱和暖灰绿底色，移除多重彩色光斑，仅保留平滑线性渐变。
- 页面表面改为近白中性色，边框和文字对比更柔和，阴影从大范围厚重模糊改为轻描边与低强度扩散。
- 圆角收紧为控件 10px、卡片 14px、浮层 22px。
- 全站基础字号由 15px 调整为 14px。
- 图库搜索输入由 16px 调整为 14px；筛选标签、结果数量和排序控件同步降低字重与视觉尺寸。
- 图库工具栏由高光玻璃胶囊改为轻量分段控件和平面输入框。
- 手机底栏降低模糊、阴影和激活底色强度，导航文字缩小至 11px，图标缩小至 19px。
- 新增视觉层最后加载，避免被既有 `glass.css` 的高优先级材质覆盖。

## 涉及文件

- `frontend/apps/web/src/refined-ui.css`
- `frontend/apps/web/src/refinedUiStyles.test.ts`
- `frontend/apps/web/src/main.ts`

## 验证方式及结果

- Web `pnpm typecheck`：通过。
- Web `pnpm test`：48 个测试文件、195 项测试全部通过。
- 新增测试确认现代视觉层在 `glass.css` 和详情专用样式之后加载。

## 尚未验证或已知限制

- 当前未连接真机进行最终屏幕观感验收；不同设备的色彩管理、屏幕亮度和设备像素比可能影响实际表现。
- 暗色主题和用户自行选择的其他浅色色盘保持原有配色，本批重点调整默认绿色主题。
