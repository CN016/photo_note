# 拍摄策划工作流优化

## 改动目的

把拍摄策划从“正文编辑器加零散关联”整理为可持续执行的工作流：创建时补齐拍摄要素，列表直接按未完成、已执行、已完成归类，编辑页集中提供灵感库、手机图库、档期、总结和选片入口。

## 主要内容

- 新建拍摄策划时可同时填写开始时间、结束时间、地点、人物称呼和照片/视频类型；关键信息完整时显示自动档期名称预览，并由既有服务端逻辑创建或关联档期。
- 策划列表按灰、红、绿三种状态分组展示，补充拍摄时间、地点、人物、类型和下一步入口。
- 编辑页标题区显示拍摄摘要，工作流面板增加状态进度、下一步提示和素材与选片快捷入口。
- “从灵感库选择”和“从手机图库添加”复用现有文档插入与图片入库流程；“选片与交付”会携带策划标题、人物称呼及拍摄摘要打开交付新建页。
- 总结汇总页增加已归档数量和明确的打开入口；总结文档仍由既有“完成复盘并归档”接口幂等创建。
- 服务端状态判定、档期同步、总结文档和 AI 分析接口未改变，保持旧客户端及现有数据兼容。

## 验证方式及结果

- `pnpm typecheck`：通过。
- `pnpm test`：34 个测试文件、140 项测试通过；其中新增工作流展示测试 5 项。
- `pnpm build`：通过，生成 Web 完整部署资源和签名的 Android Web 热更新资源。
- 使用模拟 API 在 Chromium 中检查策划列表、创建弹窗、编辑工作流、总结汇总页及选片预填；策划列表与创建弹窗另覆盖 390px 移动端，整体检查了浅色/深色和中英文界面。
- 对策划列表与编辑页执行 axe-core WCAG 2 A/AA 范围检查，未发现违规项。

## 尚未验证或已知限制

- 当前只重新构建业务 Web 与 Android 共享 Web 热更新资源；Android 原生壳、iOS、微信小程序和 PC 原生壳未做真机验收。
- 浏览器验收使用模拟 API，未连接生产 PostgreSQL、真实 AI 服务或真实档期数据。
- 选片入口目前只预填新建交付表单，交付任务与原策划之间尚未新增持久化关联字段。
