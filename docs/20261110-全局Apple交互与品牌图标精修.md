# 全局 Apple 交互与品牌图标精修

## 改动目的

在不改变业务结构的前提下，统一全站控件、弹层、列表和品牌标识的 Apple 系统式质感，并保持此前 GSAP 页面共享动画的连续性。

## 技术选择

- 继续使用现有 Element Plus 及其 `@element-plus/icons-vue`，没有新增 UI 框架。
- 品牌标识改用 Element Plus 官方线性相机图标 `Camera`，保留组件库原始比例与路径，不自行绘制 SVG。
- 页面级共享动画继续使用 GSAP Flip/Timeline；按钮、滚动、焦点和弹层使用原生 CSS 过渡与组件库状态。
- 移动端 Element Plus 对话框统一呈底部面板形态，桌面端继续居中显示。

## 主要内容

- 品牌图标由实心相机改为更轻量的线性相机，并统一蓝色底、白色图标、内高光和轻量投影。
- 按钮统一使用 Apple 式短按反馈：实体按钮按下缩至 `0.97`，文本按钮按下降低透明度。
- 输入框、选择器、表格、分页、Tabs、Card、Popper、Dropdown、Dialog 和 MessageBox 统一圆角、边框、阴影与焦点状态。
- 系统滚动条改为细窄圆角样式，选区和焦点轮廓继续使用当前主题强调色。
- 移动端 Dialog 改为底部抽屉：顶部大圆角、最大高度 `90dvh`、正文独立滚动、底部包含安全区留白，并使用 320ms 的进入动画。
- 半透明遮罩与弹层阴影跟随明暗主题，减少厚重黑色蒙层。

## 验证方式及结果

- `pnpm exec vue-tsc --noEmit`：通过。
- agent-browser 在 `390×844` 移动视口检查登录页：新线性相机 Logo、系统字体、按钮和输入框正常显示，页面无横向溢出。
- 移动端标题区移除、全局导航持久化和详情动效验证沿用本日已有结果。
