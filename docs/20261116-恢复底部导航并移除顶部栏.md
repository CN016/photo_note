# 恢复底部导航并移除顶部栏

## 改动目的
恢复移动端原有五项底部导航，移除重新出现的顶部品牌 banner，并保留工作台统计与右划抽屉。

## 主要内容
- 底部恢复工作台、灵感库、作品集、项目、个人五个入口，复用现有双语文案。
- 底栏独立固定在抽屉外，适配底部安全区域；打开抽屉时禁用底栏焦点与点击，避免穿透。
- 保留编辑页及独立交付页原有底栏排除规则，桌面不显示移动底栏。
- 工作台底栏归属包含账本、档期、计划、消息和空间；抽屉仍显示各模块的独立选中状态。
- 移动端隐藏顶部品牌栏，桌面消息入口不变。

## 验证
- `pnpm.cmd --dir frontend/apps/web test`：28 个文件、120 项测试通过。
- `pnpm.cmd --dir frontend/apps/web build`：类型检查、生产构建及 Android 热更新签名自检通过；保留已有大 chunk 提示。
- `git diff --check`：通过。
- 本次未新增或修改语言键，复用原有底栏中英文键。
