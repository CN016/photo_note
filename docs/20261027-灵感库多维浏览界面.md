# 20261027 灵感库多维浏览界面

## 目的与范围

图库新增每日目标卡片和设置、年度存图热力图、日历每日缩略图、标签/项目/人数/空镜/颜色六种浏览方式，保留原有图片卡片和数据库分页。颜色圆盘提供12色相以及黑白灰入口，未知/失败单独分类及手动重试。目标弹窗从服务器原子确认，同空间同日只成功领取一次；切换空间后旧响应丢弃并关闭旧提醒。

图库筛选使用服务端参数，不加载全库。热力图独立于图片筛选，历史删除不回减。首屏存在处理中图片时可见页面每30秒刷新，其他分页保持用户阅读位置；目标/分组轻量刷新。中英文gallery/common/messages同键补齐，Element Plus图标、CSS色轮及既有主题变量适配手机和深浅主题。

## 验证

- `npm run typecheck`、`npm run test`：59个用例通过；`npm run build`成功。构建仍有既有大chunk警告，不影响构建结果。
- gallery/common/messages中英文键集合分别111/66/96个，逐项一致。
- agent-browser在真实独立API下登录测试账户，验证10张图片显示、人数3+筛选只返回2张、色轮计数和分类、手机390×844布局、桌面1264px布局、深浅主题及英文切换。
- 通过真实界面把每日目标15改为16，服务端保留10张当日计数；后台到点发布通知后，英文手机界面弹出提醒，选择Later完成确认，未重复弹出。截图位于忽略的backend/dist/library-*.png交付证据。
