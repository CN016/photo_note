# 收支日历多记录预览与多维分析

## 改动目的

参考用户提供的 `E:/work/WWW/jz.html` 和营收日历截图，增强现有 `/ledger`，保留现有收入、支出、正式记录及自动保存草稿规则。

## 主要内容

- 日期格保留收入、支出、结余及笔数，新增最多三笔备注/分类/方式与带正负号金额预览；超出显示剩余笔数，点击日期查看完整明细。
- 增加月份选择。窄屏提供可横向滚动的完整月历，并保留每日列表。柱条按当日总流水归一化，避免多笔合计被单笔最大值截断。
- 延用星期、每日趋势、分类、支付方式、年度月份和年度热力分析；星期柱条明确表示收入加支出的总流水，避免收入与支出抵消。
- 补齐跨年收入/支出/结余对照、历史最佳月份（按结余降序，点击切换月份）、单笔平均金额、最高收入日、月度收入增长和分类经营洞察。
- 扩展结余率、记录日覆盖率、累计结余及可展开精确值表格、标记分布。周期对比补充记录天数、日均结余、单笔均值、最高日收入。
- 日均以有记录天数计算；单笔均值为总流水除以笔数；收入为零时不计算支出比例和结余率，上月收入为零时不计算增长率。历史汇总与当前筛选一致，草稿不进入统计。
- 初次加载复用既有全日期范围账本接口，确保历年对比和历史排行不会只统计已浏览年份。修复银行卡方式对应语言键。中英文同步。
- 不修改后端、数据库及接口；原有 JSON/CSV 和图片导出继续保留，新增分析面板不扩充现有报告图片版式。
