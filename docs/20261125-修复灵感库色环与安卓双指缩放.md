# 修复灵感库色环与 Android 双指缩放

## 改动目的

修复灵感库颜色筛选入口无法显示色环，以及 Android 图片网格双指缩放被页面内容缩放抢占的问题。

## 主要内容

- 点颜色条件入口时切换至颜色搜索类型并展开色环。
- 将颜色、标签和人数面板改为互斥的显式条件渲染，颜色面板收起时不再落入人数面板兜底分支。
- Android `ContentZoom` 跳过图片网格，由图库手势处理器接收双指操作并更新列数。

## 验证方式及结果

- `npm run typecheck`：通过。
- `npm run build`：通过，Android Web 签名热更新资源已生成，发布号 `1795613174184`。
- `git diff --check`：通过。
