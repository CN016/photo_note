# 项目编辑器资源交互修复

## 改动目的

修复项目编辑器新附件立即预览时的短暂 404，减少资源块常驻按钮，并完善同一行排版、尺寸调整、拖动和灵感图详情交互；同时修复无效的格式工具命令。

## 主要内容

- 附件上传后立即保存项目文档；项目附件内容读取仅对附件关联尚未落库时的 404 做有界重试。正文只预取图片和视频，PDF、Office 等文件在双击预览时再读取。
- 资源块单击选中后显示紧凑工具条，保留拖动手柄、宽度和移除；宽度滑杆在指针或键盘操作结束后一次性提交。资源块使用行内块布局，缩窄后可与相邻资源并排，节点支持拖动调整位置。
- 附件双击打开预览；视频使用原生播放器。灵感图双击显示图片、文件名、标签、尺寸和创建时间，并可进入灵感图编辑页。
- 工具栏改用 Element Plus 图标及中英文提示，并显示当前格式状态。核对格式命令与 Tiptap 扩展；当插入链接时没有选中文本，会直接插入带链接的 URL，避免命令执行后页面看不到结果。
- 更新项目编辑器中英文提示，移除未使用的资源尺寸快捷按钮文案，并修正无法预览文件和无效链接地址的提示语。

## 验证方式及结果

- `npm run build`：通过，包含 `vue-tsc --noEmit` 与 Vite 生产构建。
- `npm test`：通过，6 个测试文件、21 项测试全部通过。
- 项目中英文 JSON 键集合检查：通过。
- `git diff --check`：通过。

## 尚未验证的内容及限制

- 未在真实账号浏览器中执行上传后立即双击、资源块拖动和多资源同行的端到端操作；这些交互仍需在部署环境复测。触屏拖动行为也未验证。
- Vite 构建仍提示部分既有运行时资源超过 500 KB；本次没有调整分包策略。
