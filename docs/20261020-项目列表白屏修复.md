# 项目列表白屏修复

## 改动目的

修复打开项目列表时因分页响应字段名不匹配触发的前端白屏，并让错误响应显示可重试状态。

## 主要内容

- `GET /api/v1/projects` 将 service 分页结果映射为 API 约定的 `items`、`page`、`page_size` 和 `total` 小写字段，避免直接输出 Go 结构体字段名。
- 项目页面兼容尚未更新的后端所返回的首字母大写分页字段；响应缺少有效列表或总数时进入现有加载错误状态，不再因读取 `length` 而白屏。
- 项目 API 文档补充分页响应示例；后端版本从 `3.0.0` 升至 `3.0.1`。

## 验证

- `go test ./internal/httpapi ./internal/service`：通过，包含项目分页字段序列化回归检查。
- `pnpm typecheck`：通过。
- `git diff --check`：通过。
