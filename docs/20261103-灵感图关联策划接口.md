# 灵感图关联策划接口

## 改动目的

为图库长按和右键浮窗提供最小、隔离的策划引用查询，复用已保存的正文引用关系。

## 主要内容

- 新增 `GET /api/v1/inspirations/:business_id/projects`，复用标准分页，返回策划业务 UUID、标题、更新时间。
- 图片归属先行校验；图片、引用关系、策划联查显式限制组织及用户，过滤软删除并稳定排序。
- 后端版本从 4.6.0 递增为 4.7.0；无需新增表或迁移，旧客户端接口行为不变。
- 同步更新 `projects-api-v1.md`，新增 HTTP 参数/响应测试及 PostgreSQL 隔离测试。

## 实际验证

- `go test ./...`：通过；未配置 DSN 的其他集成测试仍按原规则跳过，不将其计为数据库验证。
- 创建独立临时 PostgreSQL 17 容器和数据库，成功应用现有 26 个版本迁移，未使用日常业务数据库。
- 设置独立测试库 `PHOTO_NINI_TENANT_TEST_DSN` 后执行 `go test ./internal/store -run 'TestTenantStorePostgres|TestInspirationProjects' -v`：通过。覆盖个人空间、两个组织、同组织不同用户、缺失/不一致上下文、系统上下文不能替代用户身份、越权图片和关联、删除过滤、分页稳定性、空数组。
- `go test ./internal/httpapi -run TestInspirationProjectsHTTP -v`：通过。覆盖未认证、非法 UUID、非法分页、不可访问图片、最小响应字段及分页偏移。
- 关联查询沿用已有 `(orgid,user_id,inspiration_business_id)` 与策划组织用户更新时间索引，本次未引入额外索引或数据迁移。

## 限制与交付
