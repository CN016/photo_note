# Git 提交规范

## 改动目的

补充仓库协作规范中缺少的 Git 提交约定，让提交边界、提交说明和验证结果便于审阅与回滚。

## 主要内容

- 在 `AGENTS.md` 增加按最小逻辑单元拆分提交的要求，并要求提交前核对暂存区范围。
- 规定提交标题使用中文并写明类型、范围和目的；正文记录背景、变更行为、兼容性或限制，以及实际运行的验证结果。
- 明确禁止在提交消息中写入密码、令牌、密钥或个人配置，并禁止通过 `git add -A` 纳入归属不明的文件。

## 验证方式及结果

- 对照仓库现有代码注释、改动记录和凭证保护要求完成规范核对；本次为纯文档修改，未运行应用构建或测试。

## 尚未验证的内容或已知限制

- 后续提交仍需逐次检查暂存区和提交内容；本规范不会自动拆分或校验 Git 提交。
