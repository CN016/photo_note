# 前端跨平台目录结构

## 改动目的

按项目确定的单仓库、多平台独立构建方向，建立前端平台目标和共享能力目录。

## 主要内容

- 在 `frontend/apps/` 下建立 `pc/`、`web/`、`android/`、`ios/` 和 `wechat-mini-program/`。
- 在 `frontend/packages/` 下建立 `editor-core/`、`image-processing/` 和 `platform-adapters/`。
- 更新根目录 `AGENTS.md`，说明平台目录是代码组织边界，不强制每个平台复制一套完整业务实现；应用入口应服从最终选定框架的构建方式。

## 验证

- 检查目录树和 `AGENTS.md` 中的路径说明。
- 当前目录尚无应用代码或构建配置，未运行构建或测试。

## 限制

- 具体跨端框架及其多目标工程组织方式尚未确定；后续可依据框架实际要求调整应用入口，但应保留平台适配和共享核心的边界。
