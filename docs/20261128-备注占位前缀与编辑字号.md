# 备注占位前缀与编辑字号

## 改动目的

为整图备注输入增加明确的待输入提示，并保证进入编辑状态后提示文字不会突然放大。

## 主要内容

- 中英文整图备注占位文案前增加 `| `。
- 非编辑状态继续使用原有 12px、常规字重占位样式。
- 点击进入编辑状态后，textarea 占位文字明确保持 12px、常规字重；用户实际输入正文保持正常字号。

## 涉及文件

- `frontend/apps/web/src/i18n/editor.zh-CN.json`
- `frontend/apps/web/src/i18n/editor.en-US.json`
- `frontend/apps/web/src/views/EditorPage.vue`

## 验证方式及结果

- Web `pnpm typecheck`：通过。
- Web `pnpm test`：48 个测试文件、196 项测试通过。
- 中英文占位键保持同步。
