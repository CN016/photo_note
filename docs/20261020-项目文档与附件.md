# 项目文档与附件

## 改动目的

在取景台增加独立的项目文档能力，支持项目列表、正文编辑和标题/正文搜索，并把项目灵感图引用与非灵感图资源按业务关系记录。

## 主要变更

- 新增 `projects`、`project_inspiration_usages`、`project_attachments` 三张无外键业务表及中文表/列注释；项目软删除时保留正文和关联。
- 新增项目列表、创建、读取、自动保存、软删除、封面压缩上传和项目范围附件预览 API。正文以版本 1 ProseMirror JSON 保存，保存时事务同步灵感图和附件关联。灵感图删除与项目保存通过行锁协调。
- 新增项目列表、新建弹窗和共享 Web 编辑页面。编辑器提供文本样式、字体颜色/背景、高亮、链接、标题、列表、任务、引用、代码、表格、对齐、灵感图选择、附件块调宽和移动控制；移动端工具栏固定在底部横向滚动。列表只加载项目摘要，正文仅在打开项目后读取。
- 正文静态图片沿用灵感图库新建/选择流程并保存 `inspiration://<business_id>` 引用。封面单独上传并压缩。GIF 和视频在正文内展示；PDF、Word、Excel 点击后在弹窗预览。
- 采用 `@zrimo/viewer` 在浏览器本地预览 Office、PDF 和图像，使用 Video.js 播放视频，GIF 以内嵌图片展示；预览所需 WASM、worker 和字体通过 `predev`/`prebuild` 从依赖复制到忽略的静态资源目录。补充中英文页面文案、API 文档和依赖许可说明。
- 后端版本从 `2.10.1` 升级至 `3.0.0`，将本次项目文档能力作为主版本发布；同时把 `files.max_upload_bytes` 标记为公开配置，供前端上传前校验，后端仍执行实际大小和内容校验。

## 验证结果

- `go test ./...`：通过。
- `pnpm run typecheck`：通过。
- `pnpm run build`：通过；查看器与 WASM 增加了较大的异步构建块，编辑页与 Office/PDF 预览依赖按需加载。
- `pnpm test`：通过，6 个测试文件共 21 项测试通过。
- 中英文 JSON locale 键集合检查：通过，`common`、`projects`、`workbench` 三组键集合一致。
- `git diff --check`：通过；仅有 Git 对工作区换行符的提示。

## 未验证与限制

- 未连接真实 PostgreSQL 实例执行 `000020` 迁移，未运行端到端接口流程。
- 未在浏览器、PC 壳、Android、iOS 或微信小程序容器执行交互验证；小程序 WebView 的文件选择、Video.js、WASM worker 和资源 URL 需要真机验证。
- `@zrimo/viewer` 的密码保护文档不支持，复杂旧版 Office 文档可能降低保真度；Video.js 播放能力受浏览器支持的编码限制。
- 项目正文以版本化 JSON 为权威数据；受控节点可渲染成 HTML，但本批未提供任意 HTML 源码编辑。
