# 作品集标签并发保护

## 目的及内容

防止标签删除与作品集创建、作品集及照片编辑并发时留下失效标签 ID。标签删除先锁定标签；作品集创建及编辑按相同顺序锁定并再次核验关联标签，作品集关联策划也先锁定策划再锁定作品集，避免反向锁序。此修正属于 4.5.0 同一未交付批次。

## 验证与限制

- 独立 PostgreSQL 16 上的 `go test ./internal/store -run '^TestPortfolioPostgresScope$'` 通过：包含删除持锁时并发创建必须等待、删除后拒绝失效标签。
- `go test ./internal/store ./internal/httpapi` 在独立 PostgreSQL 测试库通过；生产数据库及高并发负载未验证。
