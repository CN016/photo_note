# 5.0 策划界面与验证

## 目的与内容

为 5.0 策划流程接入共享 Web 界面，沿用摄影选片台的中性表面、蓝色操作色、系统字体和 Element Plus 图标，不新增依赖。

- 策划列表提供全部及灰／红／绿三类状态筛选，显示完整分类数量和明确文字。请求代次避免旧搜索响应覆盖新结果。
- 编辑页增加北京时间拍摄信息、人工复盘、AI 分析预览及采用、档期候选确认与重试、作品集关联入口。新字段复用原修订保存管线，离页前排空保存；生成不会自动覆盖已有分析。
- 新增总结汇总与独立编辑页面，分别注册中英文命名空间，副本以自身修订号保存，冲突时保留草稿并提供重新加载入口。
- 手机标题、模式、状态分行显示；拍摄输入和按钮保持触控尺寸。编辑复盘或拍摄信息时隐藏正文格式工具栏，避免误作用到正文；短清单正文自然增长，不再强制占据大半屏。深色选中按钮使用主题前景色修正对比度。

## 设计参考

使用用户指定的 unslop 与 UI/UX Pro Max；额外下载并阅读 anthropics/skills 的 frontend-design 和 theme-factory（modern-minimalist）作为参考，不改变已确认品牌。通过公开上游恢复本机失效的 UI/UX Pro Max scripts/data 参考资源，并执行 design-system 及 Vue 指南检索；自动生成的营销页、婚礼配色不符合本应用，未采用。

参考来源：[frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)、[theme-factory](https://github.com/anthropics/skills/tree/main/skills/theme-factory)、[UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)。本批未安装全局技能、复制技能代码或引入外部字体素材。

## 实际验证

- `vue-tsc --noEmit` 通过；`vitest run` 为 20 个文件、85 项测试通过；全部业务应用中英文 JSON 键集合一致。
- `pnpm build` 通过，包含类型检查、生产构建和 Android 热更新后处理。Web 版本 `5.0.0`，发布号 `1793806117209`；签名资源包约 19.5 MB。以 APK 固定公钥复核 RSA-SHA256 签名、资源 ZIP SHA256 及 414 个文件摘要，均通过。
- 独立浏览器和 API／数据库实际验证：状态分类、编辑人工总结、创建副本、副本独立编辑、作品集关联、未配置 AI 的反馈。使用受控浏览器响应验证 AI 生成预览、已有分析保留、明确采用确认及保存；该测试不代表真实外部模型联调。
- 编辑页在 375、768、1024、1440 CSS 像素宽度下，文档和页面宽度未超过视口。总结编辑页 375 宽度检查通过；中英文和明暗主题均检查。拍摄信息及复盘区域 axe 检查为零违规；修复了检查发现的深色选中按钮对比度问题。
- 浏览器使用独立 QA 账号和测试数据库，未读取真实用户照片，未发布或发送客户内容。开发中出现的 Vite 依赖预优化重载及自动化点击时序问题经重新加载后恢复，不计为功能通过依据。

## 交付范围与限制

需要业务 Web、配套 Android 签名热更新资源及 API 镜像；迁移与部署顺序见 [接口与迁移](20261104-5.0策划接口与迁移.md) 和本批根目录 `artifacts/` 说明。没有修改官网、原生壳、桥接或内核，不生成新 Android APK；PC、iOS、微信小程序没有独立构建或真机验收。

生产构建仍有超过 500 kB 的分块提示，本批未做无关依赖拆分。未验证真实外部模型、Android 实机键盘和更新安装、超大真实用户文档或生产部署。代码在独立分支提交，没有更改主工作区或运行中的主服务。
