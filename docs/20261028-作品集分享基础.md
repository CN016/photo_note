# 作品集分享基础

## 改动

按用户确认，作品照片及其已有 EXIF 均允许公开，包含 GPS 和设备序列号；公开属性保留完整 JSON 对象。新增分享令牌的生成、摘要保存、撤销和解析服务，以及作品集存储层对应方法。公开令牌定位后恢复记录所属可信空间。后端版本为 4.3.2。
