# 消息中心空投递兼容修复

## 目的

修复消息中心在通知没有对应 webhook 投递记录时白屏的问题。线上截图的异常为读取 `item.deliveries.length` 时值为 `null`。

## 改动范围

- 后端消息列表将无投递记录的 `deliveries` 序列化为空数组，保持 API 数组字段稳定。
- 前端读取消息及渠道列表时对旧版或异常响应进行数组归一化，并对消息 payload 做对象校验；异步更新投递状态时也兼容缺失的 deliveries。
- 新增后端回归测试，验证通知无投递记录时响应为 `"deliveries":[]`。
- 后端版本由 `2.3.0` 递增为 `2.3.1`。

## 验证

- `go test ./...`、`go vet ./...`（目录 `backend/`）。
- `npm run build`（目录 `frontend/apps/web/`）。

## 限制

- 本次修复针对截图中导致消息页白屏的空值异常。截图里同时出现的 `/api/v1/files` 404/500 是独立文件接口响应；消息页不请求文件内容，需结合请求发生时的 API 服务端日志另行定位。
- 未连接线上环境做登录后浏览器回归。
