# 用户中心、响应式导航与反馈改造

## 改动目的

调整 Web 用户相关页面和账号流程，增加个人中心与反馈提交能力，并统一控件外观和桌面、移动端导航布局。

## 主要内容

- 使用 Element Plus 组件实现常规按钮、输入框、表单、上传、滑块、菜单和弹层；画布编辑交互保留专用实现。Element Plus 与站点中英文、明暗主题联动，控件圆角收至约 4px，卡片和面板不超过 8px。
- 桌面端导航位于左侧；移动端在图库、编辑器和个人中心显示底部导航。移动端反馈入口只显示线框图标，触控区域为 44×44px；登录、注册和维护等无底部导航的页面将入口放在屏幕底边附近。点击后移动端打开单个底部反馈弹层，桌面端打开侧边反馈面板。
- 注册使用两步流程：填写 11 位手机号、密码和昵称，再上传并预览必需头像。登录只接受 11 位手机号，继续兼容旧客户端的 `+86` 加 11 位输入。新增个人中心，可修改昵称、头像和密码。
- 新增 `POST /api/v2/auth/register` multipart 头像注册、`POST /api/v1/users/me/password` 密码修改，以及游客可用的 `POST /api/v1/feedback`。密码修改保留当前设备会话并撤销其他设备会话。反馈支持 2000 字和最多 5 张图片，按可信代理链解析 IP 并使用 Redis 按 IP 每小时限流 5 次。
- 新增 `feedbacks` 表和私有运行配置。仓库已有 `000007_add_inspiration_async_version.sql`，因此本批手机号与反馈迁移编号为 `000008_user_phone_feedback.sql`，避免复用版本号。迁移会在改写手机号前检查非 `+86` 11 位值和归一化重复；异常时事务回滚并要求人工映射。后端版本升至 `2.0.0`。

## 验证方式及结果

- `pnpm test`：通过，2 个测试文件、4 项测试。
- `pnpm build`：通过。构建仍提示 HEIC WASM 包约 2.04 MB，超过 Vite 的 500 kB 分块提示阈值。
- 初次 `go test ./...`：通过。随后在同一工作区检测到未跟踪的 `backend/internal/store/ledger.go`，第 159 行存在函数外多余右花括号；之后的包级重跑因此失败。本批未修改该文件。
- 使用独立临时 Redis 调用真实 `TokenStore.CheckFeedbackLimit`：同一隔离 IP 前 5 次获准，第 6 次拒绝；临时 Redis 容器和测试 key 已清理。HTTP handler 的 2000/2001 字、5/6 张图片和 5/6 次限流响应由 Go 测试覆盖。
- PostgreSQL 开发库应用了 `000008` 反馈与手机号迁移；迁移前该库没有用户记录。另在隔离数据库验证非 `+86` 号码和归一化重复均触发回滚，原始手机号保持不变。开发库还补跑了此前缺失的 `000007_add_inspiration_async_version.sql`，使本地 API 满足启动 schema 检查。
- API 镜像构建成功，本地 `/healthz` 返回 `status=ok` 和 `version=2.0.0`。临时账号端到端验证通过：带头像注册、旧 `+86` 登录、密码修改、新旧密码验证、保留当前会话、撤销另一设备会话，以及旧注册接口返回 `426`。临时账号和头像文件已清理。
- 浏览器在 375×812 视口检查了注册表单和反馈入口：入口只显示图标，点击后出现一个底部反馈弹层；关闭后入口仍位于右下方。

## 尚未验证内容及限制

- 真实 Redis 限流函数已在独立实例验证；尚未从生产拓扑或实际代理链路端到端验证反馈 HTTP 接口的客户端 IP 解析和第六次 `429` 响应。
- 浏览器尚未覆盖 768、1024、1440px 以及登录后图库、编辑器、个人中心、明暗主题和英文视图；PC/iOS/Android 原生壳、小程序和生产环境未验证。
- HEIC/HEIF 转换逻辑已纳入构建，尚未在 iOS 真机验证选择与上传流程。反馈文件上传和生产代理 IP 配置也尚未进行真实部署联调。
